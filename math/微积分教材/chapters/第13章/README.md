## 两个自编入门例题

例1：r(t)=(cos t,sin t,t)，0≤t≤2π。速度r′=(−sin t,cos t,1)，速率恒为√2，所以弧长2π√2。位移r(2π)−r(0)=(0,0,2π)，位移长度与弧长不同。

例2：同一螺旋线r″=(−cos t,−sin t,0)，r′×r″=(sin t,−cos t,1)，模√2，故曲率κ=|r′×r″|/|r′|³=1/2。公式要求速度非零；不能在静止点直接除以速率。
