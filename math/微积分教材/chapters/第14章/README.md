## 两个自编入门例题

例1：f(x,y)=x²+2y²，在(1,−1)处梯度(2,−4)。沿单位向量u=(3/5,4/5)的方向导数是∇f·u=−2。若方向向量不是单位向量，先归一化，不能直接点积。

例2：同一函数在(1,−1)的切平面为z=3+2(x−1)−4(y+1)。当Δx=0.01、Δy=0.02时，线性预测Δz=−0.06；真实变化多出(0.01)²+2(0.02)²=0.0009。线性近似不是精确等式。
