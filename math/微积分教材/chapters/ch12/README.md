例1：a=(1,2,0)、b=(0,1,1)。点积为2；叉积为(2,−1,1)，模√6。平行四边形面积是√6；夹角满足cosθ=2/√10。检验叉积与原两向量点积均为0，而不是只背行列式排版。

例2：过P=(1,0,0)，法向量n=(2,−1,1)的平面。由n·(X−P)=0得2(x−1)−y+z=0。点Q=(0,0,0)到平面距离为|−2|/√6=2/√6，分母必须用法向量的模。
