# 数学环境：少配置，先动手

## 阅读与手算

打开[数学专题与可视化](../workbench/calculus.html)，选一个专题开始。所有观察在浏览器本地计算，不访问外部网站，不上传教材，不保存进度。纸笔推导优先，答案对照前写出自己的条件与结论。

## VS Code

打开仓库根目录/workspaces/math.code-workspace，只显示数学目录；不要把整个D盘当工作区。个人笔记在math/notes；各题组work.md、extra-work.md独立保留，Ctrl+Shift+V预览。这个工作区不安装插件，也不改变其他工作区的扩展状态。网页版VS Code仍使用同一文件，见[网页版手册](../guide/VSCode网页版使用手册.md)。

## 选做程序

数学 `work.md` / `extra-work.md` 用来写推导，不需要运行。下面仅针对[欧拉法选做程序](projects/ode-euler/README.md)：自己的代码写在 [work.cpp](projects/ode-euler/work.cpp)，示例输入在 [input.txt](projects/ode-euler/input.txt)。先写代码，再运行观察输出，最后检查。其余选做项目需要时再打开。

程序复用原有 C++ 工具链；只有 OpenCV 选做项目使用现有 OpenCV。无需为数学阅读另装工具。

```powershell
# Windows，在仓库根目录
python tools/study.py run math/projects/ode-euler/work.cpp --input math/projects/ode-euler/input.txt
python tools/check-math.py --project ode-euler --work
```

```bash
# WSL，在仓库根目录，还是同一份源码
python3 tools/wsl-study.py run math/projects/ode-euler/work.cpp --input math/projects/ode-euler/input.txt
python3 tools/check-math.py --project ode-euler --work
```

**上面的两组命令都运行、检查自己的 `work.cpp`。** `--work` 表示检查自己的实现；尚未补全时未通过是正常的。检查结果在终端显示，只检查选做程序，不批改数学推导，也不修改学习进度。

想先看示范时，才把运行命令中的 `work.cpp` 换成 `reference.cpp`；参考程序不能替代个人作答。维护用的参考验收及其报告不属于日常学习步骤。

Windows终端python和WSL的python3是不同环境；网页终端先确认在哪一边，Windows 终端输入 `wsl -d Ubuntu-22.04` 进入本次学习使用的 Linux；接着执行 `cd 仓库根目录`，再用上面的 WSL 命令。已在 Ubuntu 终端时直接 `cd 仓库根目录`。编译器找不到、路径错、DLL错误先看[环境手册](../guide/环境使用手册.md)，不要反复复制项目或随意增加PATH。

OpenCV选做不读取个人图片，不开摄像头，不写检测结论；只用合成浮点矩阵验证内点Sobel比例。数学梯度与图像行向下的符号区别已经写在题目中。
