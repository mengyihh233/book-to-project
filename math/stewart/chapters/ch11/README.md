## 两个自编入门例题

例1：几何级数Σ从n=0到∞的(1/3)^n。先写前N项Sₙ=(1−3^(−N))/(1−1/3)，再令N→∞，得3/2。项数N与末项下标N−1不同；不能因为通项趋0就直接宣布任意级数收敛。

例2：用三阶麦克劳林多项式估计e^0.2。多项式为1+x+x²/2+x³/6，得到1.221333333…。在[0,0.2]上，拉格朗日余项绝对值≤e^0.2·0.2⁴/24<0.000082。这里先给出误差界，再比较数值，不把小数接近当成证明。
