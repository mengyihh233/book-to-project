## 两个自编入门例题

例1：F=(2x,2y)=∇(x²+y²)，在R²上从(0,0)到(1,2)的任意分段光滑路径，线积分F·dr=5−0=5。这里是向量场的做功积分，不是标量弧长积分。

例2：F=(−y,x)，沿单位圆逆时针一周。参数化r=(cos t,sin t)，F·r′=1，积分为2π。也可用格林定理：∂Q/∂x−∂P/∂y=2，乘单位圆面积π得2π。反向走一周结果为−2π。
