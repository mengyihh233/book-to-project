# 视觉结果 → Linux核对 → C++复盘

这是已有零件检测与数据集盘点项目的联合实操，不是新增原书题。本轮增加只读report-metrics.py，使用Python标准库，不再安装一套视觉环境。先用现有检测器生成report.json，再核对其内部一致性。

## 任务与操作

在Linux/WSL终端进入学习区根目录。把下面路径替换成自己实际生成的报告；可同时传入多份，含空格或中文的路径使用引号。

```bash
cd 仓库根目录
python3 linux/projects/dataset-audit/report-metrics.py 'opencv/output/我的检测01/report.json'
```

Windows也可在PowerShell用现有Python解释器运行同一脚本。报告来源和检测命令见[零件检测项目](../../../opencv/projects/parts-inspector/README.md)。输出CSV列为file、count、total_contour_area_px2、mean_contour_area_px2。需要保留时重定向到自己新建的CSV文件，放在输入报告之外；不要让输出路径覆盖报告原件。

所有报告都合法才输出CSV；任一文件无效，stdout为空、stderr说明原因，退出2。输入必须为普通报告文件，单份最多8MiB、一次最多1000份；重复输入会拒绝，防止重复累计。工具不修改原图、报告或学习进度。

## 六个练习

1. 手算两件零件面积80与120，预测count=2、总轮廓面积200、平均100，再运行核对。
2. 空白图报告count=0、objects=[]时，本工具总面积与均值都输出0；明确这是空集合的展示约定，不证明“空数据有统计均值”。
3. 在自己的临时副本中只把count改大，观察退出码与stdout；恢复副本，再把一个包围框放到图外。
4. 给报告路径加入空格、中文或逗号；用Python csv模块读取，不能简单用awk -F,处理任意CSV，因为引号内也可能有逗号和换行。
5. 将面积数列复制到C++第5章均值题的输入协议中，比较均值；浮点输出可能有格式差异，先比较同一数值与容差。
6. 比较不同threshold的三份报告，记录检测数、总轮廓面积和失败场景。先预测粘连是否导致计数变化，再看结果。

保存CSV后，可用标准CSV解析器汇总，而不是手工按逗号切开：

```bash
python3 - '我的核对.csv' <<'PY'
import csv, sys
with open(sys.argv[1], encoding='utf-8-sig', newline='') as f:
    rows=list(csv.DictReader(f))
print('reports=', len(rows), 'objects=', sum(int(r['count']) for r in rows))
PY
```

## 结论边界与参考答案

count必须等于objects长度；包围框必须在图内，质心在自己的包围框内，轮廓面积应正且不超过包围框面积。工具能抓住这些内部矛盾，但并未重读原图验证分割正确性。图像漏检、粘连、错误阈值仍可能生成完全自洽的错误报告。

轮廓面积是像素坐标下的几何面积，可能含小数，不等于前景像素数量，更不能直接说成真实物体面积。多图求平均时，“每图均值再平均”与“所有零件面积合并后平均”通常不同，应按总面积/总零件数计算后者。源报告、参数与原图应一起保留用于复盘。

参考实现就在report-metrics.py；先读输入约定与手算结果，再阅读实现。脚本的CLI测试使用隔离临时副本，不替你记录项目已完成。
