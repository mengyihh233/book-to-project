# 解析

路径变量必须双引号保护，`find ... -print0`与`read -r -d ''`配对，保留空格、反斜杠及换行。%q只用于人读的Shell转义展示，不能当通用CSV。

循环通过进程替换读取find结果，不放在管道子shell中，因此计数在循环后仍然有效。NUL模式仅把文件名写stdout，把摘要写stderr，便于重定向后用于后续程序。

仅按扩展名筛选，无法识别假PNG、压缩炸弹或相机元数据；后续应通过解码器验证。默认不跟随符号链接，避免扫描意外扩展到其他目录。

进程替换不会自动把find退出码传播给主循环，因此追加一个空路径NUL标记及OK/ERROR状态。真实find输出是绝对非空路径，故不会与标记冲突。遍历失败返回2，stderr提示丢弃已有的部分列表，不输出成功摘要。下游必须检查退出码，不能仅凭拿到部分文件名判断成功。
