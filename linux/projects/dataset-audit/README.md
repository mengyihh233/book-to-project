# Linux实践：只读图像数据集盘点

配合机器视觉项目，练习路径引用、find、NUL分隔、read循环、大小写转换、stdout/stderr与退出码。这是Linux教材配套实践，不是原书题目复刻。

`bash reference.sh '图像目录'`递归列出PNG/JPG/JPEG/BMP文件并统计其他文件；以扩展名判断候选图片，不保证它可解码，不跟随子目录符号链接。原图完全只读。

`bash reference.sh '图像目录' --null > manifest.bin`导出NUL分隔的机器清单，摘要写stderr。**不要用cat或普通文本编辑器把清单当逐行文本**；文件名可能包含换行。不要把输出清单放进被扫描目录，否则它也可能被盘点。图像检测项目当前批处理第一层，本脚本递归；使用时注意范围差异。

Windows里运行VS Code任务「Linux: 数据集盘点示例」，使用已有Git Bash；在Ubuntu终端则用对应的/mnt/d路径。没有删除或改动原始文件的操作。

## 练习

1. 为什么find输出不能写成`for f in $(find ...)`？构造含空格文件名验证。
2. 用含换行的文件名，比较换行分隔与NUL分隔。
3. 添加.PNG/.JpG扩展名，解释大小写归一化。
4. 区分候选图片数与成功解码数，解释为什么扩展名不能验证图像格式。
5. 创建空目录，期望images=0 others=0；坏路径应返回2。
6. 写自己的work.sh，在不修改输入的情况下产生等价报告。
