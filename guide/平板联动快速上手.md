# 平板联动快速上手：先完成一次完整学习

适用于当前OPPO Pad 6与电脑lsy。电脑保存文件并执行程序，平板显示网页和接收你的输入；不需要把教材或C++环境再安装到平板。

## 1. 连接与收藏

1. 电脑开机并登录Windows，保持联网、不休眠。已配置当前用户登录启动；本轮没有实际重启电脑验证。
2. 平板打开Tailscale，使用与电脑相同的账号和网络，打开连接开关。设备列表应能看到lsy。
3. 浏览器打开[学习工作台](https://lsy.tailaa8c77.ts.net:8443)，建议收藏。保持Tailscale连接。
4. 页面连接条应显示“平板 / 远程学习”，网页作答按钮就绪后即可使用。若提示尚未就绪，先看本页第7节。

平板里的127.0.0.1指平板自身，不能把电脑本机地址直接拿来用。当前私有网址只适用于这次Tailscale网络；以后切换账号或网络，需重新核对地址。

## 2. 用两个页面学习

| 页面 | 做什么 | 保存在哪里 |
|---|---|---|
| 学习工作台（8443） | 看教材、题目、提示、互动实验；保存复盘与状态 | 电脑guide/学习进度.csv |
| 网页VS Code（8444） | 编辑work.cpp、input.txt、自己的笔记；开终端编译 | 电脑D:\Book-Learning对应文件 |

建议横屏，使用浏览器两个标签切换；系统支持时也可分屏，一侧题目，一侧编辑器。浏览器若把编辑器显示得过于拥挤，可尝试菜单中的“桌面版网站/电脑模式”，具体名称取决于浏览器。长代码输入适合配外接键盘；不用键盘也可通过编辑器左上角菜单操作。

## 3. 第一次从题目进入代码

1. 在工作台选C++主教材，搜索题号，例如roberts-ch05-12。
2. 打开题目，先读中文说明与input.txt约定，手算输出；卡住时再展开提示。
3. 点击题目里的“在网页VS Code作答”。新页面应打开ex12目录，而不是整个杂乱盘符。
4. 首次若显示Restricted Mode（受限模式），确认是自己的Book-Learning工程后，选择Trust Folder & Continue（信任文件夹并继续）。不认识的工程不要按这个步骤信任。
5. 在Explorer（资源管理器）里点work.cpp，自己编码。reference.cpp、lesson.h和solution.md是参考内容，不用它们覆盖自己的work。
6. 通过File → Save（文件 → 保存）保存。若有外接键盘，先点代码区再按Ctrl+S；标签上的未保存标记应消失。

信任后若提示内置Git扩展未加载，可重新加载编辑器页面一次；本机曾遇到并验证过这种恢复方式。

## 4. 打开终端并检查当前题

左上角菜单Terminal → New Terminal（终端 → 新建终端）。当前网页版默认托管在Windows；看到PS D:\...表示PowerShell。

在Windows终端执行：

```powershell
cd D:\Book-Learning
& 'C:\Users\lsy08\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools/check-current.py cpp/主教材/章节学习/第05章 集合类/课后习题/第12题 用栈逆序输出整数/work.cpp
```

要练Linux C++，先在Windows终端输入：

```powershell
wsl -d Ubuntu
```

```bash
cd 仓库根目录
```

同一份源码无需复制，按这次实际使用的环境检查即可。更多命令与例子见[网页版VS Code手册](VSCode网页版使用手册.md)。

## 5. 回到工作台复盘

代码保存与复盘保存是两件事。在工作台写“我原先的错误假设、哪个反例暴露了错误、下一步做什么”，再点“保存学习记录”。参考程序通过不自动改变你的进度。

换设备时点“复制本题链接”，在另一端打开同一道题。“刷新共享进度”只刷新记录，不会替你保存当前输入框。若出现记录冲突，先复制自己的未保存文字，再重新打开题目并合并；不要反复点保存覆盖。

关闭网页或网络断开前，先保存代码和复盘。不能把编辑器里尚未保存的内容、后台终端会话或浏览器历史当作可靠备份。暂时掉线时保留页面，恢复网络后等重新连接，再确认文件与记录确实已保存。

## 6. 第一次可做的小验证

如果还不熟悉编译，先按[网页版手册的连通小实验](VSCode网页版使用手册.md)运行cpp/主教材/运行产物/pad-link/main.cpp。它只打印LEARNING_LINK_OK 5，不是原书答案，不改变学习进度。运行成功后再回原题写自己的代码。

## 7. 打不开时按顺序排查

| 看到什么 | 先做什么 |
|---|---|
| 平板列表只有自己 | 核对两端账号、网络与连接开关 |
| 电脑lsy离线 | 检查电脑是否休眠、关机或断网 |
| 工作台能读，编辑器未就绪 | 在电脑运行联合启动入口，等首次下载完成后刷新连接 |
| 编辑器出现空文件夹或感叹号 | 从题目按钮重新打开；不要手动拼Windows文件夹参数 |
| python或g++找不到 | 先判断Windows还是WSL，使用对应命令，不重装全部环境 |
| 改了代码运行结果没变 | 保存文件、核对文件路径，再重新编译；不要只运行旧exe |

电脑可双击workbench/检查联合学习.cmd，它只读取状态，不修改网络配置、源码和进度。详细原理与恢复命令见[联合学习说明](平板与电脑联合学习.md)。
