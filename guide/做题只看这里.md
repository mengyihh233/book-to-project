# 从读教材到完成一道题

**学科 → 章节/专题 → 题目 → 自己的作答。** 网页和VS Code使用同一套关系。

## 一次只做一道题

1. 从学科首页选章节，先阅读教材。
2. 选“章内综合练习”或一道“原书课后题”。这是两类练习，按需选，不必重复全做。
3. 在题目里点“写在这里”，打开自己的作答文件。问题、输入输出与样例也在代码开头。
4. 写完保存，按Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**，观察程序。
5. “任务：运行任务” → **本题：检查作答**。最后对照解析。

若当前打开的是章节目录，先进入具体题目，不能把整个章节直接当作一道题检查。独立打开题目文件夹与打开完整学习工作区时，日常任务名称相同。

## 运行、检查、参考分别是什么

| 操作或文件 | 含义 |
|---|---|
| 本题：运行作答 | 编译/运行自己的C++或运行Shell；不是评分 |
| 本题：用样例输入运行 | 读取本题input.txt运行；不会比较正确答案 |
| 本题：检查作答 | 自动识别题目规则；文本题比样例，图形题走专项，无自动规则时提示自检 |
| README.md | 本题题目、写在哪里、输入输出和完成标准 |
| work.cpp / main.cpp / work.sh | 写代码的位置；以题目中的链接为准 |
| work.md / extra-work.md | 在对应题目下写数学解答；人工核对 |
| input.txt | 一份手动输入，可以修改来测试 |
| 检查数据中的.in / .out | 检查工具的输入与预期输出，不是答案填写处 |
| solution.md / reference.* | 做完再看的解析与参考，不是自己的判分入口 |

## 检查范围

当前主教材78道文本课后题使用固定样例，3道图形题使用专项检查。章内综合练习、小课、库练习与OpenCV章节等没有独立自动评分，按各题要求自测。数学文字作答也没有自动判分。通过有限样例不等于所有情况正确。

检查由tools/check-current.py统一分派；作答位置与检查类型登记在answer-cards.json，文本样例在book-tests.json，图形规则由专项工具提供。日常不用寻找这些后台文件。Windows与Ubuntu用相同任务名称和同一份作答，工具按系统选择实际构建方式。
