## 每次学习的顺序

读原题和README → 手算一个例子 → 在work独立实现 → 检查当前题 → 对照solution → 写反例和复盘。不要每天重跑所有参考验收，不把参考通过当自己完成。

每题的README给出输入、输出与约定。reference和lesson.h是答案；input.h是可复用输入工具；tests.cpp多为参考接口检查。个人笔记与学习状态保留。

## VS Code

Windows打开workspaces/cpp.code-workspace或桌面“重点学习（Windows）”；Linux用“重点学习（WSL Ubuntu）”。当前文件编译、文件输入和作答检查从“终端→运行任务”选择。F9设断点，F5选Windows调试；F10逐过程，F11进入函数。先保存当前源码再运行。

具体命令、环境位置、F5配置与常见错误见[环境使用手册](环境使用手册.md)。[工作台](http://127.0.0.1:18765)可查看章节、答案与复盘；只在你自己确认掌握后标记完成。
