# C++：从原书阅读到代码练习

## 在工作台中学习

从C++任务点“阅读本章教材”，现在进入按章连续阅读器。本章正文、复习与原书习题可以一路向下读，不需要逐页翻转识别稿。

1. 用顶部选择框切换章节；用“本章目录”定位小节。平板目录默认收起，展开后选中小节会自动收起。
2. 字号可选标准、大字、更大。阅读位置只记在当前浏览器：重新进入本章后点“继续上次”。换设备、清理浏览器数据不会同步保留这个位置。
3. 读到想实操的内容，点“返回本章选题”，在现有章节说明里选例题实验、核心练习或课后题。“章内综合练习”打开本章核心任务；题目与自己的代码在前，参考答案仍需单独打开。
4. 发现断句、公式、代码或图示有疑问，点正文前的小字“原页”，打开扫描件对照；此处也可看待核对记录。按章阅读保留原页分界，不自行补齐跨页代码。

## 在VS Code与实际文件夹中学习

推荐打开 `仓库根目录/workspaces/cpp.code-workspace`，Ubuntu中使用已有WSL工作区。学习源文件仍是同一套，不需要复制一份教材工程。

每章最常用的三个入口：

- `原书阅读.md`：连续原文。打开后按 **Ctrl+Shift+V** 预览，图片使用本地资源，离线也能看。无需开启工作台服务；其中“原页”网页对照入口需要启动服务并选择对应设备可访问的工作台地址。
- `README.md`：本章说明、知识点、讲解与已有练习链接。按需要选做，避免一口气打开所有资料。
- `章内练习/`、`课后习题/`：自己的核心练习与原书题作答。原有文件位置、任务ID和运行方式保留。

解析与阅读注释从题目内按需打开，日常目录已收起；“原书阅读.md”保持独立可见。`roberts/original/`中的逐页稿与JSON供程序维护，不是第二套学习主线，不需要删除。

## 原文范围与当前限制

20章阅读稿覆盖PDF第16—638页，共623页，包含章节正文、复习、原书习题。书前内容和书后索引仍可通过原版PDF或原页阅读器查阅。原书页稿已经校对，但仍有登记疑点，不能把“已校对”当成零错误。

这是阅读形式与入口的整理，没有把原书所有题目都变成可运行项目。第6—20章仍有尚未逐题整理的内容，章节目录会如实标明；“原书习题可阅读”和“已有作答项目”分开理解。

维护时由 `tools/build-cpp-reading.py` 从现有校对稿重新生成20份阅读稿；不要把个人笔记直接写进这份派生原文，自己的想法写进既有“我的C++笔记”或题目笔记。
