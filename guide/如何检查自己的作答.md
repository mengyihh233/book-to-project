第2章16—18题也选“本题：检查作答”，统一入口会自动选择图形专项，不用自己挑脚本。
打开对应题目录的work.cpp，完成后运行任务“本题：检查作答”。工具会编译你的文件，输入固定样例并比较输出与退出码。
参考答案的输出格式在solution.md中列出。交互题只检查最后一行时，会在测试定义中明确标记。
通过固定样例仍要补充自己的边界测试；此工具不会自动将学习进度改为已完成。

PPP参考教材保留原有样例与独立工具，但尚未接入本页统一作答入口；本页日常检查范围是当前主教材，不把旧参考数据称为新入口已完成。

## 读到文件末尾的题

已登记文本检查的原书题提供input.txt（第一个样例）与cases目录中的更多输入/期望输出；SVG题按图形专项说明查看输出，不套用文本样例约定。
在题目源码上运行“本题：用样例输入运行”，程序会从文件读取数据，不必手动输入EOF。
输入文件可自行修改，后续生成工具会保留已有input.txt和work.cpp。

## 手动命令

```powershell
Set-Location '仓库根目录'
$studyPython = 'C:/Users/lsy08/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
& $studyPython tools/check-current.py cpp/主教材/章节学习/第05章 集合类/课后习题/第19题 摩斯码与双向Map/work.cpp
& $studyPython tools/study.py run cpp/主教材/章节学习/第05章 集合类/课后习题/第19题 摩斯码与双向Map/work.cpp --input cpp/主教材/章节学习/第05章 集合类/课后习题/第19题 摩斯码与双向Map/input.txt
# 只在检查第2章16—18题时使用，替换为自己正在做的题：
& $studyPython tools/check-current.py cpp/主教材/章节学习/第02章 函数与库/课后习题/第16题 六色彩虹/work.cpp
```

在 WSL Ubuntu 终端使用 Linux Python 和同一份源码：

```bash
cd 仓库根目录
python3 tools/check-current.py cpp/主教材/章节学习/第05章 集合类/课后习题/第19题 摩斯码与双向Map/work.cpp
python3 tools/wsl-study.py run cpp/主教材/章节学习/第05章 集合类/课后习题/第19题 摩斯码与双向Map/work.cpp --input cpp/主教材/章节学习/第05章 集合类/课后习题/第19题 摩斯码与双向Map/input.txt
# 第2章图形专项也支持在WSL检查当前work：
python3 tools/check-current.py cpp/主教材/章节学习/第02章 函数与库/课后习题/第16题 六色彩虹/work.cpp
```

选择自己当前的题目路径，不需要把两套环境都跑一遍。检查工具按已登记的题目目录识别样例，请在该题原有 `work.cpp` 作答；把源码移到另一个目录会找不到对应样例。

章节配套题暂未统一提供用户作答自动评分，不要把reference中的assert直接粘进work就当作独立完成。先明确验收标准，自己实现，再观察差异。

## 验证记录怎么看

- 学习区审计.json：文件、链接与参考源哈希检查。
- book-verification.json：已覆盖原书参考答案的输入输出验收。
- verification.json：原有章节参考实现验证。
- OpenCV验证记录.json：新增OpenCV23章验证。

某个旧记录为通过，只能证明记录当时的文件与环境结果。代码修改后需重跑受影响的检查。
