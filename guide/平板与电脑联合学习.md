# 平板、电脑与WSL共用一套学习区

先按[平板联动快速上手](平板联动快速上手.md)完成一次练习，再查[网页版VS Code详细手册](VSCode网页版使用手册.md)。工作台连接条已提供暖白排版的帮助入口，可直接复制代码块；复制不会自动执行。

电脑负责保存工程、编译运行；平板负责浏览器阅读、编辑、终端与复盘。源文件只有D:\Book-Learning这一份，WSL中对应仓库根目录。工作台与网页版VS Code是两个页面，用平板分屏或浏览器标签切换即可。

## 日常只做这些

1. 电脑开机登录，保持联网且不休眠；联合学习启动入口会在本机启动工作台和网页编辑器。
2. 平板连接Tailscale同一网络，打开[私有学习工作台](https://lsy.tailaa8c77.ts.net:8443)，建议收藏。
3. 选题、读中文指引、先手算。在题目中点「在网页VS Code作答」，打开这道题所在目录。首次进入若出现工作区信任提示，确认是自己的D:\Book-Learning工程后再信任。
4. 先保存代码，再在编辑器终端检查；回工作台填写复盘和状态，点保存。所有设备写的是电脑上的同一份学习进度.csv。
5. 点「复制本题链接」把同一道题交接到另一设备；「刷新共享进度」更新列表，保留当前尚未保存的复盘。若另一页已保存本题，旧页面会提示冲突；先复制当前文字，再重新打开题目后合并保存。

不建议两端同时编辑同一源文件。VS Code文件保存与工作台复盘保存是两件事。浏览器关闭后，下次仍从服务器读取已保存内容；未保存的文字不能当成已同步。

## 网页VS Code终端：先判断在哪个环境

当前网页编辑器运行在Windows电脑上。打开菜单Terminal → New Terminal（终端 → 新建终端）。如果工程只打开某题目录，先切回学习区根目录。

Windows PowerShell：

```powershell
cd D:\Book-Learning
& 'C:\Users\lsy08\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' tools/check-current.py cpp/主教材/章节学习/第05章 集合类/课后习题/第10题 含中心的3×3邻域地雷计数/work.cpp
```

学习Linux C++或Shell，在同一个终端输入：

```powershell
wsl -d Ubuntu
```

随后是Linux终端，使用Linux命令与路径：

```bash
cd 仓库根目录
pwd
python3 tools/check-current.py cpp/主教材/章节学习/第05章 集合类/课后习题/第10题 含中心的3×3邻域地雷计数/work.cpp
python3 tools/wsl-study.py run cpp/主教材/章节学习/第05章 集合类/课后习题/第10题 含中心的3×3邻域地雷计数/work.cpp --input cpp/主教材/章节学习/第05章 集合类/课后习题/第10题 含中心的3×3邻域地雷计数/input.txt
```

退出Linux终端用exit。这里的WSL是通过终端进入；网页编辑器本身仍托管在Windows，并不自动变成WSL扩展宿主。Linux端的图形调试和GUI窗口需用原有电脑WSL工作区或后续远程桌面。OpenCV/OpenGL图形窗口也不能直接当成浏览器页面看。

## 一次性配置与重启

Tailscale Serve已使用后台持久配置：8443转工作台18765，8444转网页编辑器18766；只在当前私有网络中可访问。编辑器仅绑定127.0.0.1，访问控制依靠Tailscale私有网络，电脑本机程序也可访问。只把自己的可信设备加入此网络，不开启Funnel公开访问。

若登录时启动未生效，可手动运行：

```powershell
& 'C:\Users\lsy08\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' D:\Book-Learning\workbench\start.py --remote
```

首次网页编辑器需要下载Microsoft服务器组件，看到准备中可稍后刷新。无需重装桌面VS Code。配置和缓存放在D盘.remote-vscode与.remote-vscode-cli；不属于教材资料，不在工作台中提供浏览。

切换Tailscale账号/网络可能改变地址。此时需要同时检查Serve和workbench/access.json中的精确地址，不能只改收藏。关闭私有编辑入口可执行tailscale serve --https=8444 off；移除登录启动可删除Windows启动文件夹中的“联合学习后台”快捷方式。关闭后本地教材与工程仍保留。

## 排查顺序

- 平板看不到lsy：检查两端账号、网络和连接开关。
- 网页打不开：电脑先访问http://127.0.0.1:18765，确认本地服务正常，再检查tailscale serve status。
- 编辑器尚未就绪：运行联合启动入口，等首次下载完成，再点刷新连接；查看workbench/editor.log。
- 提示保存冲突：先复制复盘，再打开本题合并；不要反复点击保存。
- 电脑休眠或关机：无法访问，Tailscale不能让关机电脑自动运行工程。

官方资料：[Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)、[VS Code CLI](https://code.visualstudio.com/docs/configure/command-line)。
