# 文件夹与工作区的关系

**只记一条：学科 → 章节/专题 → 题目 → 自己的作答。**

“重点学习区.code-workspace”只是将几门学科放进同一个VS Code窗口，侧栏每门学科只有一个根目录。它不是课程，也不是另一份项目。

| 层级 | 你要做什么 | 示例 |
|---|---|---|
| 学科 | 选章节 | C++学习 |
| 章节 | 先读教材，再选练习 | 第02章：函数与库 |
| 题目 | 看要实现什么和格式 | 原书第01题：温标换算 |
| 作答 | 在指定文件实现 | work.cpp |

C++的章内练习是本章综合题；课后习题按原书题号排列；语法小课用于按需补概念。三者不是三本教材，也不是三遍必做任务。

## 打开方式

- 电脑日常：双击[重点学习区](../重点学习区.code-workspace)。需要切换已有窗口视图时，重新打开此文件。
- Ubuntu：继续使用已有WSL学习入口，左下角确认Ubuntu-22.04。层级与任务名称一致。
- 平板：[学习工作台](../workbench/directory.html)选内容，需要写代码再打开网页VS Code。

中文目录连接同一份现有文件，兼容路径在后台保留。不要把隐藏的旧路径当作另一份待做课程或垃圾删除。
