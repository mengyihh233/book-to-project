# 工作台与VS Code的日常用法

**网页与文件使用同一条路：学科 → 章节/专题 → 题目 → 自己的作答。**

1. 首页选学科，再选章节。C++先阅读，再选章内综合练习或一道原书课后题；其他专题进入本章说明与练习。
2. 题目页先看要求与代码，点“打开本题作答”进入对应文件；参考解析另行查看。
3. 保存后Ctrl+Shift+B运行；“本题：检查作答”核对登记规则。Shell静态检查用“Shell：检查语法”，不是判题。
4. 题目顶部可返回所属章节/学科。“学习记录与复盘”按需展开，只有点保存才写入共享进度。

## VS Code只打开一个学习工作区

[重点学习区](../重点学习区.code-workspace)侧栏为C++、机器视觉、高数、Linux四个根目录。C++直接进入教材章节根目录，语法小课从首页按需查阅。

现有窗口需要重新打开该工作区，才能看到新的根目录。具体题目独立打开时也有相同的日常任务。

README.md在章节层负责带路，在题目层写要求；work.cpp/main.cpp/work.sh是指定作答；input.txt是手动输入。参考、辅助与检查数据从题目中的链接按需打开，日常目录已收起。

题名目录与原兼容路径指向同一份文件。不要当成两份题重复做，也不要删除隐藏的兼容目录。

## 草稿与跨设备

复盘草稿保存在当前浏览器；点“保存学习记录”才同步。代码以实际文件为准，网页代码预览读取这份文件，保存后可刷新预览。
