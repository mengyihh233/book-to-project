## 4 · 怎么做

先弄清这几点：

常量模板可能导致归一化退化；本练习用固定种子的非恒定纹理。匹配分数不等于通用目标识别准确率。

阅读时回答三个问题：输入是什么类型与形状？函数输出代表什么？哪些条件可能导致失败？
