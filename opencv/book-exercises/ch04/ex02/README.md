# Learning OpenCV 第4章习题2：积分图

[原书第4章 Exercises](../../../../导入教材.md#这两份文件为什么不在仓库里)；本题为该节第二个顶层编号题。中文概述，不替代原书全部题干。

- a：随机生成高100、宽200的单通道uchar图与同尺寸float积分图。
- b/c：填充前缀矩形和，并用已计算结果将构建降为一次扫描。
- d：用四个前缀值计算任意轴对齐矩形的像素和。
- e：讨论45度旋转矩形的快速求和表示。

reference.cpp实现a-d，并测试505个矩形、两个非法ROI，与OpenCV积分图交叉检查；e提供算法讨论，未提供专门旋转积分图API实现。

在work/main.cpp独立完成；先对3×3手算再上随机图。Ctrl+Shift+B编译运行，默认不弹窗、不下载图片。原书使用OpenCV3，本区在已配置的OpenCV4运行；保留题意，说明API表示差异。
