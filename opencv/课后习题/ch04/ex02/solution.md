# 中文解析

定义S(y,x)为从(0,0)到(x,y)，两端都含的像素和。

`S(y,x)=I(y,x)+S(y-1,x)+S(y,x-1)-S(y-1,x-1)`，越过上边/左边的项视作0。先清零，行优先遍历时依赖值都已算出，构建O(HW)。

矩形半开范围[x,x+w)×[y,y+h)的和，用右下角总和减去上、左两块，再加回重复减掉的左上块，单次查询O(1)。空矩形或越界在函数入口拒绝。

本题100×200 uchar的和不超过5100000，小于float可精确表示连续整数的2^24界。更大图像不要照搬float，应改double/足够宽整数，并重新评估溢出与精度。

OpenCV的integral通常比输入多一行一列，首行首列为0；原书要求的同尺寸定义与它有一格偏移。参考实现保留原书尺寸，并用官方函数的最后一个元素独立交叉检查。

e的一个可行算法：将像素中心映射到u=x+y、v=x-y，给v加H-1偏移使非负。创建坐标变换后的格点图，原像素放在相应格点，其余格点为0，再构建普通二维积分图。边与原坐标轴成45度的矩形在u/v空间成为轴对齐范围，可通过四次前缀读取求离散像素中心之和。奇偶性不同的格点为空，不应补成实际像素；明确边界是否包含在区域内。此法解释清晰但空间可达O((W+H)^2)，不是OpenCV紧凑tilted积分布局的直接替代。专门的倾斜积分图可减少额外空间，这是后续扩展。
