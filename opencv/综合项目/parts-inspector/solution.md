# 解析与易错点

1. imdecode IMREAD_COLOR得到CV_8UC3且通道顺序BGR。cvtColor用COLOR_BGR2GRAY，gray与mask均为CV_8UC1。
2. 二值图中非零作为前景，黑零件需反相。浅色物体配invert=0。阈值100是样例参数，真实环境先看亮度分布再调参。
3. 阈值变化会使边界或阴影进入前景。若区域粘连，即使面积区间合理也不能恢复真实物体个数；需要更好的照明、背景建模或分水岭等后续方法。
4. 线性尺寸缩小一半，面积约缩为四分之一；轮廓面积是多边形几何面积，不等于countNonZero的精确像素数。
5. RETR_EXTERNAL只取最外层轮廓，孔洞不计件；连接的前景通常只产生一个外轮廓。带层次模式会取孔洞，若全部计数会误计。
6. moment的m00为零时不能除；质心为m10/m00、m01/m00。对象按x再y排序以便重复运行对比，ID是本图顺序，不是跨帧跟踪ID。

将主程序拆为读图、分割、提取、过滤、输出五个职责，才方便分别测试。当前参考实现使用JSON请求输入与PNG/JSON文件输出；文件路径走UTF-8 JSON和filesystem::u8path，避免Windows窄字符命令行破坏中文。
