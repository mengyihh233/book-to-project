# Roberts 教材与本机工具

日常使用已安装的D:/c++/MYSYS2/ucrt64/bin/g++.exe，独立练习按C++17编译。无需再装一套编译器。

| 书中/概念 | 标准C++练习常用对应 |
|---|---|
| getInteger/getReal | 检查std::cin，必要时getline后解析 |
| Vector | std::vector，方法名和边界语义不完全相同 |
| Stack/Queue | std::stack/std::queue，top/front和pop分离 |
| Map/Set | std::map/std::set，遵循STL查找与遍历接口 |
| error | std::runtime_error与调用端catch |

不能把Stanford库的add/remove等方法直接照搬到STL。原书要求自定义接口时以题目为准。vendor/stanford-original/cpplib保留教学库，tools/build-stanford.ps1为控制台示例专用入口；这不是GUI完整环境，本轮未安装Qt。

work.cpp是自己的作答，reference.cpp是参考，input.txt 是自己的输入，检查数据/ 是自动检查样例。Ctrl+Shift+B与文件输入、原书作答验收是不同任务。样例通过不自动改变学习状态。

各章原书题目.md统一使用PDF页码；扫描本需看真实页面，不能只凭文本抽取结果猜题号。


中文目录已适配现有 Windows 编译与 F5 任务：生成程序存放在 build 缓存，调试所需的英文路径映射直接指向原源码，不复制练习。仍在“我的作答”或题目的 work.cpp 中编辑即可；不要到 build 中找练习入口。Windows F5 与 Ubuntu 调试使用各自的工作区配置。
