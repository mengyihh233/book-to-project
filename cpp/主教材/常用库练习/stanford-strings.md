## 这份适配的明确约定

| 接口 | 本练习约定 |
|---|---|
| `integerToString(int)` | 有符号十进制；0与最小负数也可转换，不先对最小负数取反 |
| `stringToInteger(string)` | 可有首尾 ASCII 空白和一个正负号；主体必须是完整十进制数字，`12px`、空串、仅符号都失败 |
| `realToString(double)` | 仅有限值；参考使用可往返为同一 double 的简短表示，可能出现大写 E，不承诺固定小数位 |
| `stringToReal(string)` | 接受十进制与 e/E 科学计数、首尾 ASCII 空白；拒绝 nan/inf、十六进制、小数逗号和尾随杂字；超出 double 可表示范围报错 |
| `toUpperCase(string)` | 返回新字符串；只把 ASCII a-z 改为 A-Z，其余字节不动，不做 Unicode 大小写转换 |

解析语法不合法抛 `std::invalid_argument`；整数溢出、实数溢出或小到无法表示的非零实数抛 `std::out_of_range`。能够表示的次正规实数不一概拒绝。work 的 TODO 是你自己的调用练习，共享头已经可用；初始 return 2 只表示还没有写调用。

原书版本通过教学库 `error` 报错；本组明确改用标准异常。原库 realToString 的流默认有效位数与本适配的可往返格式也不完全相同，不拿两者逐字符输出当成同一契约。

## 做后核对与解析

五个普通结果依次是字符串 `"42"`、整数 7、字符串 `"23.45"`、double -125、大写字符串 `"CPP-17"`。转换不是把原变量的类型改掉，而是返回一个新值。

只读出数字前缀会把 `12px` 错当12，所以不仅要判断“转换开始成功”，也要检查是否消费了整个有效文本。空串不能当0；超范围也不能当最大值继续算。参考通过 `from_chars` 检查错误码和结束位置，再把失败转换为清楚的异常。

浮点文本显示与底层二进制值不同：普通小数可以得到简短文本，接近1的相邻 double 可能需要更多数字。参考使用 `to_chars` 的可往返格式，优先保留值，不等于银行金额格式化。`1e9999` 是溢出，`1e-9999` 无法表示为非零 double；都不是合法的0或无穷大结果。

`toUpperCase` 返回副本，原变量仍为 `"cpp-17"`。反引号、左花括号、数字、空格不属于 a-z；UTF-8 多字节也保持原样。这种 ASCII 约定适合本组数字与英文标签，不表示能把所有语言的大写转换正确。

参考共18组核对，包含上述正常用法与整数极值、首尾空白、空串、尾随杂字、正负溢出、科学计数、小数点边界、有限数往返、非法实数格式、实数上下溢、ASCII边界、副本、嵌入零字节。它验证的是这份教学适配，不把原库覆盖缺口抹掉。
