# 第18章 项目：图连通与距离

> **要干什么：** 读一张无向图，先按连通关系分组打印，再从 0 号顶点出发算出到每个顶点的最短边数。
> 这题**不给骨架**，从 `#include` 开始全自己写。README 里是一组示例，**判分用另外 7 组**。

## 1 · 需求

标准输入：

```text
6 3
0 2
2 4
1 3
```

| 行 | 内容 |
| --- | --- |
| 第 1 行 | `n`（1 ≤ n ≤ 100000）个顶点、`m`（0 ≤ m ≤ 200000）条边 |
| 接下来 m 行 | 每条边两个端点 `u v`（顶点编号 **0 到 n-1**） |

输出：先 `分量数 K`，再每行一个分量，最后一行距离。

```text
分量数 3
0 2 4
1 3
5
距离 0 -1 1 -1 2 -1
```

- 分量内顶点**升序**；分量之间按**最小顶点**升序。
- 距离是**边数**，从 0 号顶点出发；到不了输出 `-1`；到自己是 `0`。

## 2 · 关键要求

1. 用**邻接表**（`vector<vector<int>>`）存图，别开 n × n 的矩阵（10 万顶点会爆）。
2. 求分量：从每个没访问过的顶点出发做 BFS/DFS，收集这一组。
3. 求距离：**必须 BFS**。DFS 走到的不一定是最近的路，这一点最容易错。
4. 无向边要**两个方向都存**。

## 3 · 规则与边界

| 情况 | 要求 |
| --- | --- |
| 自环 `u == v` | 允许，不影响连通性，不报错 |
| 重边 | 允许，按同一条边处理 |
| 边顺序打乱 | 输出必须和输入顺序无关（升序 + 按最小顶点排） |
| 孤立顶点 | 自己是一个分量，输出单独一行 |
| m = 0 | n 个分量，每个顶点一行；距离只有 0 号是 0，其余 -1 |
| n < 1 或 n > 100000 | 返回 2，stdout 为空 |
| m < 0 或 m > 200000 | 返回 2，stdout 为空 |
| 端点不在 0..n-1 | 返回 2，stdout 为空 |
| 边没给够 | 返回 2，stdout 为空 |

## 4 · 验收清单

- [ ] 上面那组输入 → `分量数 3` / `0 2 4` / `1 3` / `5` / `距离 0 -1 1 -1 2 -1`
- [ ] `1 0` → 一个分量 `0`，距离 `0`
- [ ] 4 个顶点连成 0-1-2-3，边序打乱 → 一个分量 `0 1 2 3`，距离 `0 1 2 3`
- [ ] 有自环和重边的 3 顶点图 → 分量 `0 1` 与 `2`，距离 `0 1 -1`
- [ ] m = 0、n = 4 → 4 个分量，距离 `0 -1 -1 -1`
- [ ] n = 3、边 `0 3` → 返回 2，屏幕无输出
- [ ] n = 0 → 返回 2，屏幕无输出

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组隐藏输入，逐字比对 `stdout` 与退出码。

注意 `距离` 那行是**所有顶点**的距离，一共 n 个数，一个都不能少。
