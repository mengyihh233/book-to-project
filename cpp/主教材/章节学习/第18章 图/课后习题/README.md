| [同一个图的三种遍历顺序](第03题%20同一个图的三种遍历顺序/README.md) | 习题 3 + 4 | 固定样例比较（8 组） |

一道题里跑三遍同样的图，把三种顺序摆在一起看：

```text
递归 DFS = A B D C
栈版 DFS = A C D B      ← 栈把邻接点的顺序颠倒了
BFS     = A B C D
```

三个结果不一样**不是 bug**：递归是一条道走到黑，栈是「先全压进去再一个个弹」，
队列是一圈一圈往外扩。题目里还藏了「弹出时判重 vs 入队时判重」这个易错点。
