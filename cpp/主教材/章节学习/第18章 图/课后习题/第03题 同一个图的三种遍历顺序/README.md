# 第18章 · 习题3：同一个图的三种遍历顺序

> **要干什么：** 对同一个无向图从同一起点做三次遍历：递归 DFS、用栈模拟 DFS、用队列 BFS，把访问顺序打出来对比。

## 1 · 题目是什么

输入：

```text
n m
节点名1 节点名2 … 节点名n
u1 v1
…
um vm
起点
```

- 节点是不含空格的记号，`n` 个，互不重名；
- `m` 条无向边，每行两个节点名，两端必须在节点表里；
- 最后一行是起点。

输出的三行，节点按**空格分隔**：

```text
递归 DFS = A B D C
栈版 DFS = A C D B
BFS = A B C D
```

三者不一样是**正常的**：递归按邻接表顺序深入；栈把邻接点按顺序压进去，弹出来就是**反的**；
队列则是先来先服务，一圈一圈往外扩。

原书习题 3（[PDF 第 562 页](../../../../../../books/cpp-roberts.pdf#page=562)）。**这里是题意改写与输入输出约定**：原书用图 18-5 的递归 DFS，以及习题 3 的栈版、习题 4 的队列版，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

建图、递归 DFS、输出函数都已经给好，你要写两个函数：

- `stackDfs`：起点压栈 → 弹栈顶 → 已访问就跳过 → 标记访问 → 把邻接点按顺序压栈；
- `bfsOrder`：起点入队 → 出队 → 把未访问的邻接点标记后入队。

## 5 · 文本格式

- 三行，格式 `标签 = 节点 节点 …`，节点之间一个空格，行末无多余空格。
- n 越界、节点重名、边引用了不存在的节点、起点不在图里、读入不完整：返回 2，**stdout 为空**。

输入样例：

```text

A B C D
A B
A C
B D
C D
A
```

期望输出：

```text
递归 DFS = A B D C
栈版 DFS = A C D B
BFS = A B C D
```
