# 第12章 · 习题4：动态数组 IntArray

> **要干什么：** 实现一个自己管内存的 IntArray：越界要抛异常、扩容要保留旧值、拷贝必须是深拷贝。

## 1 · 题目是什么

- 第一行 `n`（0 ≤ n ≤ 100）条命令；第二行 `size`（1 ≤ size ≤ 1000）建数组，元素初始为 0。
- 命令：`set i v`、`get i`、`size`、`sum`、`resize k`、`deepcopy`。
- `get i` 输出该元素；`size`/`sum` 各输出一行；`set` 与 `resize` 不输出。
- `deepcopy`：拷贝一份、把副本第 0 个元素改成 99，然后输出**原数组**的和——
  只有深拷贝才能保证原数组不变。
- 下标越界、`resize` 到 0、`size` 为 0：返回 2，**stdout 为空**。

原书习题 4（[PDF 第 395 页](../../../../../../books/cpp-roberts.pdf#page=395)）。**这里是题意改写与输入输出约定**：原书用习题 4 的 IntArray 类，并合入习题 6 要求的深拷贝，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

实现构造/析构/拷贝构造/拷贝赋值，以及 `get`、`set`、`resize`、`sum`。
内存用 `new[]`/`delete[]`，拷贝要新开一块再逐元素复制。`main` 的命令循环已给。
