# 第17章 · 习题6：16 位比特串的位运算

> **要干什么：** 把两个 16 位比特串读成整数，用 &、|、^、~ 算出结果，再按比特串打印回去。

## 1 · 题目是什么

读两行，每行必须**正好 16 个字符**且只含 `0` 和 `1`：

```text
0100100001001001
0000000011111111
```

输出五行，每行是 16 个比特：

```text
x & y = 0000000001001001
x | y = 0100100011111111
x ^ y = 0100100010110110
~y = 1111111100000000
x & ~y = 0100100000000000
```

原书习题 6（[PDF 第 528 页](../../../../../../books/cpp-roberts.pdf#page=528)）。**这里是题意改写与输入输出约定**：原书用把两个 16 字符的 0/1 串转成 `unsigned short`，用位运算符算五个结果，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写两个小工具：`parseBits(串)` 校验并组装成 `unsigned short`，`toBits(值)` 打印回 16 位；
`main` 读两行、算五个结果。

**work.cpp** 里的 `BEGIN 1` … `END 1`（集合的读取 / 位串解析）和 `BEGIN 2` … `END 2`（主程序的组合与输出）。

保存后运行任务“本题：检查作答”核对。

- 五行，等号两边各一个空格，右边恰好 16 个比特字符（**高位补 0，不能省**）。
- 长度不是 16、含 `0`/`1` 以外的字符、行缺失：返回 2，**stdout 为空**。

输入样例：
