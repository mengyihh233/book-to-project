# 第17章 · 习题1：Set 的读取与并交差

> **要干什么：** 给集合类写一个能读 `{a, b, c}` 的输入运算符，再用它读两个集合并输出并、交、差。

## 1 · 题目是什么

读两行，每行一个集合，格式 `{元素, 元素, ...}`：

- 元素是不含空格、逗号、花括号的记号；逗号后可带空格，写成 `{a,b}` 也行；
- 空集写成 `{}`；
- 同一个元素写两次会被集合自动合并（这是集合的定义，不是错误）。

输出三行，元素按字典序（集合内部有序）：

```text
并集 = {a, b, c, e}
交集 = {a, c}
差集 = {b}
```

原书习题 1（[PDF 第 527 页](../../../../../../books/cpp-roberts.pdf#page=527)）。**这里是题意改写与输入输出约定**：原书用`set.h` 里与 `<<` 对称的 `>>` 重载，要求写成 `{a, b, c}`，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

集合类与 `+`（并）、`*`（交）、`-`（差）、`<<`（输出）都已经给好，
你要写 `operator>>`：整行读入 → 校验花括号 → 按逗号切开 → 逐个 `insert`。

## 5 · 文本格式

- 三行：`并集 = {...}`、`交集 = {...}`、`差集 = {...}`，空集合打印成 `{}`。
- 没有花括号、括号里出现空元素、元素里带空格、整行为空：返回 2，**stdout 为空**。

输入样例：

```text
{a, b, c}
{a, c, e}
```

期望输出：

```text
并集 = {a, b, c, e}
交集 = {a, c}
差集 = {b}
```
