三道题各练一件事：

- **集合的输入运算符**：`{a, b, c}` 这种带逗号的记法要整行读、按逗号切，`{}` 得读成空集；
  再拿它做并、交、差，输出顺序由集合内部的有序性决定，不用自己排序。
- **用集合造集合**：`createPrimeSet` 只用**已经找到的素数**试除，试到 √N 就停——这就是筛法省时间的来源。
- **位运算**：16 个字符 ↔ `unsigned short` 的互相转换，`~y` 要截回 16 位再打印，不然高位全是 1。
