# 第17章 · 习题3：素数集合

> **要干什么：** 返回 2 到 max 之间所有素数的集合，用「已经找到的素数」当除数，试到平方根就够。

## 1 · 题目是什么

输入一个整数 `max`（2 ≤ max ≤ 1000000），输出 2 到 max 之间所有素数，按升序写成集合：

```text
{2, 3, 5, 7}
```

原书习题 3（[PDF 第 527 页](../../../../../../books/cpp-roberts.pdf#page=527)）。**这里是题意改写与输入输出约定**：原书用`Set<int> createPrimeSet(int max)`，只用已找到的素数试除到 √N，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `std::set<int> createPrimeSet(int max)`：从 2 开始逐个判断，
**只用集合里已找到的素数**试除，且除数的平方超过 N 就停；`main` 读 max、调用、输出。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（集合的读取 / 位串解析）和 `BEGIN 2` … `END 2`（主程序的组合与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；补完把区里的占位注释（`// @@N@@`）或占位 `throw` 删掉。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 一行 `{p1, p2, ...}`，逗号后一个空格。
- max 小于 2 或大于 1000000：返回 2，**stdout 为空**。

输入样例：

```text
2
```

期望输出：

```text
{2}
```
