# 第17章 项目：集合运算报告

> **要干什么：** 读两个整数集合，输出并集、交集、两个差集，并判断「A 是不是 B 的子集」。
> 这题**不给骨架**，从 `#include` 开始全自己写。README 里是一组示例，**判分用另外 7 组**。

## 1 · 需求

标准输入：

```text
4
7 3 3 9
3
9 4 4
```

| 行 | 内容 |
| --- | --- |
| 第 1 行 | 集合 A 的大小 `n`（0 ≤ n ≤ 100000） |
| 第 2 行 | A 的 `n` 个整数（**可能有重复**） |
| 第 3 行 | 集合 B 的大小 `m`（0 ≤ m ≤ 100000） |
| 第 4 行 | B 的 `m` 个整数 |

输出固定 5 行：

```text
并集 3 4 7 9
交集 9
仅A 3 7
仅B 4
子集 否
```

- 每行的值是**升序、空格分隔**；集合为空时只输出标签（如 `交集`），后面不留空格。
- `子集` 判断的是 **A ⊆ B**，输出 `是` 或 `否`。

## 2 · 关键要求

1. 用**有序集合**（`std::set`）做，插入时自动去重排序。
2. 求交/差用「查表」而不是「两重循环扫」：O(n log n) 而不是 O(n²)。
3. `子集` 用「A 里每个元素是否都在 B 里」判断，空集算作任何集合的子集。

> 自动判分看不出复杂度：本项目的 7 组输入规模不大，用 `vector` 双重循环也能过。
> 但书上要求的是 10 万级数据，只有集合/排序的做法才跑得动。别拿“过了”当“对了”。

## 3 · 规则与边界

| 情况 | 要求 |
| --- | --- |
| 输入有重复 | 按集合处理，重复自动消失，不报错 |
| A 为空（n = 0） | `并集`/`交集`/`仅A` 后面的值可能为空；`子集 是` |
| B 为空（m = 0） | `并集` 等于 A，`交集`/`仅B` 空，`子集` 只在 A 也空时是 `是` |
| 负数 | 正常参与排序（`-5` 排在 `1` 前面） |
| 两组完全相同 | `仅A`/`仅B` 空，`子集 是` |
| n < 0 或 n > 100000 | 返回 2，stdout 为空 |
| m < 0 或 m > 100000 | 返回 2，stdout 为空 |
| 元素个数不够 | 返回 2，stdout 为空 |

## 4 · 验收清单

- [ ] 上面那组输入 → `并集 3 4 7 9` / `交集 9` / `仅A 3 7` / `仅B 4` / `子集 否`
- [ ] `0` + `3 / 1 2 3` → 并集 `1 2 3`，交集与仅A 只有标签，`子集 是`
- [ ] A = {1,2,2,3}，B = {3,2,1,1} → 并集与交集都是 `1 2 3`，两个差集只有标签
- [ ] 不相交的两个集合 → `交集` 只有标签
- [ ] A = {2,4,6}，B = {1,2,3,4,6} → `子集 是`
- [ ] n = -1 → 返回 2，屏幕无输出
- [ ] m = 3 但只给 2 个数 → 返回 2，屏幕无输出

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组隐藏输入，逐字比对 `stdout` 与退出码。

最容易错的两处：空集合时多打一个空格（`交集 ` 而不是 `交集`），以及 `子集` 方向写反（判断成 B ⊆ A）。

## 6 · 做完的标准

1. `set` 和 `unordered_set` 在这道题上能互换吗？哪个能保证升序输出？
2. 求交集时，遍历 A 查 B 和遍历 B 查 A，结果一样吗？代价一样吗？
3. 如果两个集合各有 10 万元素，双重循环要比较多少次？大概要跑多久？
4. `set` 插入 10 万个数的时间复杂度是多少？为什么不是 O(n)？

## 7 · 扩展（可选）

1. 支持对称差（只在其中一个集合里出现的元素）。
2. 输入不排序、要求输出也保持「A 的首次出现顺序」。
3. 判断两个集合是否相等，并给出第一个不同的元素。
