# 第10章 项目：排序代价统计

> **要干什么：** 同一个数组，数一数两种排序各做了多少次操作。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

输入：

| 行 | 内容 |
| --- | --- |
| 第 1 行 | 整数 `n`（1 ≤ n ≤ 100000） |
| 第 2 行 | n 个整数（值在 ±10⁹） |

输出两行：

```text
选择比较 10
插入移动 10
```

- **选择排序的比较次数**：内层每比较一次计数一次；
- **插入排序的元素移动次数**：每把前一个元素往后挪一格，计一次。

两种排序各用自己的副本，互不影响。

## 2 · 关键要求

**必须真的把两个排序跑一遍并计数**，不许用公式直接写 `n*(n-1)/2`。

结果一样，但这一章练的是「操作次数怎么随数据变化」，套公式等于把题目做成了算术题。

自动判分只看输出，看不出你用了公式。**自己清楚就行。**

## 3 · 边界

| 情况 | 要求 |
| --- | --- |
| `n` < 1 或 > 100000 | 返回 2 |
| 数据不足 n 个 | 返回 2 |
| `n = 1` | 两种计数都是 0 |
| 有相等元素 | 插入排序只在**严格大于**时移动（相等不换位，保持稳定） |

## 4 · 验收清单

- [ ] `5` + `5 4 3 2 1` → 选择 10，插入移动 10
- [ ] `5` + `1 2 3 4 5` → 选择 10，插入移动 **0**（已排好序，一次都不移）
- [ ] `6` + `6 5 4 3 2 1` → 选择 15，插入移动 15
- [ ] `1` + `7` → 都是 0
- [ ] `4` + `2 2 1 1` → 选择 6，插入移动 4（相等不移动）
- [ ] `3` + `3 1 2` → 选择 3，插入移动 2
- [ ] `0` → 返回 2

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

## 6 · 做完的标准

1. 选择排序的比较次数为什么**和数据无关**？它最坏和最好一样吗？
2. 插入排序在「已经有序」和「完全逆序」时，移动次数差多少？用 n 表示。
3. 如果有相等元素，为什么必须用 `>` 而不是 `>=`？改了会怎样？
4. n=100000 时，选择排序要比较多少次？这个数还在 `int` 范围内吗？
