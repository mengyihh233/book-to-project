# 第10章 · 习题5：线性查找与二分查找的比较次数

> **要干什么：** 不测时间，改数「比较了多少次」：同一批查询，线性查找和二分查找各比几次。

## 1 · 题目是什么

输入：

```text
n
a1 a2 … an      已经升序排好（允许相等）
q
x1
…
xq
```

对每个查询值输出一行 `值 线性=a 二分=b`，`a`、`b` 是**元素比较次数**：

- **线性查找**：从下标 0 开始逐个比，比一次记 1 次；相等就停；比完还没找到就是 n 次。
- **二分查找**：每次取中间元素 `mid = low + (high − low) / 2` 比一次（记 1 次）；
  相等就停；比它小就扔掉右半边，比它大就扔掉左半边；区间空了就停。

例如 `1 3 5 7 9` 里查 `5`：线性要 3 次（1、3、5），二分 1 次就中；查 `10`：线性 5 次，二分 3 次。

原书习题 5（[PDF 第 332 页](../../../../../../books/cpp-roberts.pdf#page=332)）。**这里是题意改写与输入输出约定**：原书用习题 5 的 SearchComparison：在有序矢量上统计两种查找的比较次数，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

`main` 的读入、校验、输出都已经给好，你要写两个计数函数：

- `linearComparisons`：顺序扫描，返回比较次数；
- `binaryComparisons`：折半，返回比较次数。

## 5 · 文本格式

- 每个查询一行：`值 线性=a 二分=b`，用空格分隔。
- 数组不是升序、n 或 q 越界、数字个数不足：返回 2，**stdout 为空**。

输入样例：

```text

```

期望输出：

```text
1 线性=1 二分=2
5 线性=3 二分=1
10 线性=5 二分=3
```
