# 第15章 项目：电话簿

> **要干什么：** 建一张名字到号码的表，按查询顺序回答。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入：

```text
3
alice 123
bob 456
carol 789
2
alice
dave
```

| 行 | 内容 |
| --- | --- |
| 第 1 行 | `n`（1 ≤ n ≤ 100000）条记录 |
| 接下来 n 行 | `名字 号码`，名字不含空格，号码是**纯数字串** |
| 再一行 | `m`（0 ≤ m ≤ 100000）次查询 |
| 接下来 m 行 | 每行一个名字 |

输出：每次查询一行，**查到输出号码，查不到输出 `未找到`**。

```text
123
未找到
```

## 2 · 关键要求

**必须用映射（`std::map` / `std::unordered_map`）**，不许每次查询都从头扫一遍记录。

n 和 m 都能到 10 万，逐个比对是 10¹⁰ 次，跑不完。

## 3 · 规则与边界

| 情况 | 要求 |
| --- | --- |
| 重名 | **后者覆盖前者**（最后登记的有效），不报错 |
| 名字大小写不同（`zed` / `ZED`） | 视为不同名字 |
| 号码含非数字字符 | 返回 2 |
| `n` < 1 或 > 100000 | 返回 2 |
| `m` < 0 或 > 100000 | 返回 2 |
| `m = 0` | **合法**，不输出任何内容，返回 0 |
| 查询条数不够 | 返回 2 |

## 4 · 验收清单

- [ ] 3 条记录 + 查 `alice` / `dave` → `123` / `未找到`
- [ ] 2 条记录 + `m=0` → **无输出**，返回 0
- [ ] 重名 `tom 111` 后 `tom 222`，查 `tom` → `222`
- [ ] 查 `zed` 和 `ZED` → 前一个命中，后一个 `未找到`
- [ ] `n=0` → 返回 2
- [ ] `m=100001` → 返回 2
- [ ] 号码 `12x` → 返回 2

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

`m=0` 那组要求 `stdout` **完全为空**，多一个换行都会判错。

## 6 · 做完的标准

1. `map` 和 `unordered_map` 在这道题上有什么区别？哪个更快？哪个能保证顺序？
2. 重名覆盖时，`book[name] = number` 和 `book.insert(...)` 行为一样吗？
3. 为什么号码要按字符串存，不能用 `int`？
4. 如果用 `vector<pair<string,string>>` 加线性查找，m=100000 时要比较多少次？
