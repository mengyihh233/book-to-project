| 题目 | 原书题号 | 检查方式 |
|---|---|---|
| [有序数组 StringMap（二分查找）](第01题%20有序数组%20StringMap（二分查找）/README.md) | 习题 1 + 2 + 3 | 固定样例比较（8 组） |
| [罗马数字转十进制](第04题%20罗马数字转十进制/README.md) | 习题 4 | 固定样例比较（8 组） |

StringMap 那题把三问合成一件东西：**数组始终按 key 排好序**（习题 1 的 put 顺序 + 二分 findKey），
不依赖 Stanford 库的 `Vector`（习题 2），并补上 `size`/`isEmpty`/`containsKey`/`clear`（习题 3）。
用命令序列驱动，`dump` 直接暴露内部顺序——排序写错立刻看得见。

罗马数字那题是原书习题 4 的完整实现，只是把「读一个串」改成「读 n 行」，
顺带练「先全校验、再统一输出」。
