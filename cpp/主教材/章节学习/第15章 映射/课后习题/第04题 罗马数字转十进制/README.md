# 第15章 · 习题4：罗马数字转十进制

> **要干什么：** 把罗马数字串翻译成十进制数：逐字符查表得到数值，比右边小的减、否则加。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 1000），接下来 n 行每行一个罗马数字串（1—15 个字符）。
- 只认 `I V X L C D M` 这七个字母，**小写会先统一成大写**。
- 规则：从左到右逐字符取值相加；如果某个字符的数值**小于它右边字符的数值**，这一位要减。
  例：`MCMLXIX` = 1000−100+1000+50+10−1+10 = 1969。
- 不检查「标准写法」：`IIII` 也按规则算成 4 并通过；`IL`（本来不合法）同样按规则算成 49。
- 结果必须落在 1—3999，超出算非法。

原书习题 4（[PDF 第 476 页](../../../../../../books/cpp-roberts.pdf#page=476)）。**这里是题意改写与输入输出约定**：原书用一张字符查找表 + 规则「小值在大值左边就减」，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `int romanToDecimal(const std::string& str)`：建字符→数值的查找表，按上面的规则累加；
`main` 读 n 行、逐行调用并校验结果范围，**全部合法后再逐行输出**。

## 5 · 文本格式

- 每个输入串输出一行十进制数。
- 出现非 `IVXLCDM` 的字符（大小写都算）、空行、结果不在 1—3999、n 越界：返回 2，**stdout 为空**。

输入样例：

```text
1
MCMLXIX
```

期望输出：

```text
1969
```
