# 第15章 · 习题1：有序数组 StringMap（二分查找）

> **要干什么：** 用「始终按 key 升序的键值对数组」实现一个字符串映射表，查找走二分而不是从头扫。

## 1 · 题目是什么

这一题合并原书习题 1、2、3：**有序数组 + 二分查找 findKey**，并补上
`size`、`isEmpty`、`containsKey`、`clear` 四个方法。

输入是一串命令（第一行 `m` 是条数，0 ≤ m ≤ 1000），每条一行：

| 命令 | 作用 | 输出 |
|---|---|---|
| `put key value` | 插入或更新 | 无 |
| `get key` | 取值 | 值，没有则 `(none)` |
| `remove key` | 删除（不存在不报错） | 无 |
| `containsKey key` | 查询是否存在 | `yes` / `no` |
| `size` | 元素个数 | 数字 |
| `isEmpty` | 是否为空 | `yes` / `no` |
| `clear` | 清空 | 无 |
| `dump` | 按 key 升序打印 | 每行 `key=value`，空表不输出 |

`key`、`value` 都是不含空白的记号。

原书习题 1（[PDF 第 476 页](../../../../../../books/cpp-roberts.pdf#page=476)）。**这里是题意改写与输入输出约定**：原书用图 15-3 的 StringMap：键值对数组 + findKey，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

实现 `StringMap` 的 8 个成员函数（含私有 `findKey` 用二分查找），
`main` 负责读命令、**逐条校验**（未知命令、参数个数不对都要报错），全部合法后再执行。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（数据结构的实现）和 `BEGIN 2` … `END 2`（读入、校验与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；补完把区里的占位注释（`// @@N@@`）或占位 `throw` 删掉。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 只有 `get`、`containsKey`、`size`、`isEmpty`、`dump` 会输出，其余命令安静执行。
- 未知命令、参数个数不对、空行、m 越界：返回 2，**stdout 为空**（所以要先校验完全部命令再执行）。

输入样例：

```text
4
put a 1
put c 3
put b 2
dump
```

期望输出：

```text
a=1
b=2
c=3
```
