# 第7章 · 习题10：递归逆序字符串

> **要干什么：** 读入 n 行文本，用递归把每行逆序输出。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 100），接下来 n 行，每行一段文本（可以含空格，长度 ≤ 1000）。
- 输出每行的逆序，一行一个。

原书习题 10（[PDF 第 251 页](../../../../../../books/cpp-roberts.pdf#page=251)）。**这里是题意改写与输入输出约定**：原书用递归函数 `reverse(str)`，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

实现递归 `reverseOf(s)`：s 为空返回空串，否则 `reverseOf(s.substr(1)) + s[0]`。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（递归函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

3. 通过之后自己再造两组：一组边界、一组非法，确认结果仍然对。

## 5 · 文本格式

- 每行逆序后的文本，空格也要保留。
- 行数不够、单行超过 1000 字符：返回 2，stdout 为空。

输入样例：

```text
3
hello
ab cd
x
```

期望输出：

```text
olleh
dc ba
x
```
