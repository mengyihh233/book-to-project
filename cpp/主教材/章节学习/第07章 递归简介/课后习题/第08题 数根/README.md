# 第7章 · 习题8：数根

> **要干什么：** 读入 n 个非负整数，用递归反复求数位和，直到剩下一位（数根）。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 100），接下来 n 行每行一个非负整数（≤ 10¹⁸）。
- 数根：把各位相加，结果还不是一位数就继续加。例如 1729 → 19 → 10 → 1。
- 输出每个数的数根，一行一个；0 的数根是 0。

原书习题 8（[PDF 第 250 页](../../../../../../books/cpp-roberts.pdf#page=250)）。**这里是题意改写与输入输出约定**：原书用反复求数位和直到剩下一位（digital root），
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

实现递归 `digitalRoot(x)`：x < 10 返回 x，否则先求一次数位和（可以用循环或递归），
对结果继续求数根。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（递归/迭代函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。
