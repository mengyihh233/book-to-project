# 第7章 项目：递归基础

> **要干什么：** 用递归求两个整数的最大公约数，以及 n 的阶乘。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入两行：

```text
12 18
5
```

- 第一行两个整数 `a b`；
- 第二行一个整数 `n`（0 ≤ n ≤ 20）。

输出两行：

```text
gcd 6
阶乘 120
```

## 2 · 强制要求

**两个函数都必须用递归实现**，不许用循环：

- 最大公约数：辗转相除，`gcd(a,b) = gcd(b, a%b)`，`b==0` 时返回 `a`；
- 阶乘：`n! = n × (n-1)!`，`n≤1` 时返回 1。

用循环写出来结果一样，但**这题练的是基准情形和递归收敛**，写循环等于没做。

## 3 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| `a` 和 `b` 都是 0 | 返回 2（`gcd(0,0)` 没有定义） |
| `n` < 0 或 > 20 | 返回 2 |
| `a` 或 `b` 为负 | 取绝对值后求 gcd，不报错 |
| `n = 0` | 阶乘输出 `1` |

## 4 · 验收清单

- [ ] `12 18` + `5` → `gcd 6` / `阶乘 120`
- [ ] `7 13` + `0` → `gcd 1` / `阶乘 1`
- [ ] `0 5` + `20` → `gcd 5` / `阶乘 2432902008176640000`
- [ ] `-4 6` + `4` → `gcd 2` / `阶乘 24`
- [ ] `0 0` + `3` → 返回 2
- [ ] `100 75` + `21` → 返回 2（n 越界）
- [ ] 阶乘用 `long long`，`20!` 不能溢出

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

## 6 · 做完的标准

1. 两个递归函数的**基准情形**分别是什么？漏掉会怎样？
2. `gcd` 为什么用 `%` 而不是减法？
3. `n!` 用 `int` 会在哪个 n 开始出错？
4. 递归调用在函数体最后一行（尾递归）和不在最后一行，有什么区别？
