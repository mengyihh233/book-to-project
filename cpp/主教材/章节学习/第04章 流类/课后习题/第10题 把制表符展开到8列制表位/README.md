# 第4章 · 习题10：把制表符展开到8列制表位

> **要干什么：** 把制表符展开到8列制表位。

## 1 · 题目是什么

标准输入两行：输入文件名、全新输出文件名。每行从0列开始，TAB补空格至下一个8列边界；恰好在边界时补8个空格。LF/CR重置列，CRLF逐字节保留。其他ASCII控制字符原样保留并按一个显示列计数，不模拟终端退格。输出写真实文件，标准输出（cout）为空。
正文范围：ASCII、最多16MiB；UTF-8中文路径支持不代表支持中文正文。文件不存在、输入缺行/多行、种子或字母集合错误、正文非ASCII、读写失败，退出2，stdout不发布部分结果。空文件合法。源文件不能被修改。第9/10题使用独占创建，已有输出、同名输入、输出目录不存在均报错，不覆盖文件。
手动参考运行：python tools/study.py run cpp/主教材/章节学习/第04章 流类/课后习题/第10题 把制表符展开到8列制表位/reference.cpp --input cpp/主教材/章节学习/第04章 流类/课后习题/第10题 把制表符展开到8列制表位/input.txt；WSL将前半改为python3 tools/wsl-study.py run。运行工具的cwd是源文件目录，因此sample.txt与my-result.txt指向本题文件夹。已有my-result.txt时，另选一个新输出名再运行。
lesson.h是本题参考函数，公共file_lesson.h是文件读写支持；不要直接包含本题答案代替作答。tests.cpp检查参考函数，不会标记个人完成。stdout与文件内容严格比较，末尾换行有意义。
