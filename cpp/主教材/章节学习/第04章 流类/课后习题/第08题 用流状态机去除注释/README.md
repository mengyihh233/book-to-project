# 第4章 · 习题8：用流状态机去除注释

> **要干什么：** 用流状态机去除注释。

## 1 · 题目是什么

标准输入整段ASCII源文本，标准输出去注释结果，不额外添加换行。//删除至行尾但保留LF；/*…*/删除整个块，包括块内换行，不支持嵌套。按原书允许简化，不识别字符串/字符字面量中的注释标记，也不处理预处理器续行。块未闭合视为错误，退出2且标准输出（cout）为空。它会把int//x拼成intx，因此不能直接充当生产编译器的预处理器。
这是按原书要求独立编写的实现；边界和输入输出格式是本区明确约定。除第12题允许连续重试外，多余输入行、缺少必需输入或格式错误返回2；正常退出0。输入正文以ASCII为主，文件名是UTF-8字符串字节，不做Unicode字符计数。
第8题按原始输出精确比较，最后的换行也是结果一部分；其他题移除程序打印的一次末尾换行后比较，保留前后空格。提示应写cerr。
另有tests.cpp检查参考函数接口，可直接编译运行；它不会检查或完成你的work。
本题控制台验收的源文本采用LF换行。removeComments本身按传入流的字符处理；Windows标准文本流与Linux对CRLF的处理可能不同，不把参数行的CRLF归一助手套到原始源码流上。真实文件变换题的正文处理请看第9/10题。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
void removeComments(std::istream& in, std::ostream& out);
```

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

按完整输出逐字比较；前后空格、空行与最后换行都参与检查。

```text

```

期望输出：

```text

```
