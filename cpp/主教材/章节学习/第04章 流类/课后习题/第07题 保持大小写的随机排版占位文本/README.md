# 第4章 · 习题7：保持大小写的随机排版占位文本

> **要干什么：** 保持大小写的随机排版占位文本。

## 1 · 题目是什么

标准输入两行：输入文件名、十进制uint32种子（0到4294967295，只含数字）。读真实文件并把英文字母随机替换为同大小写字母，非字母不变；CRLF归一为LF后输出到控制台，不补末尾换行。原书未指定种子协议；本区显式输入种子，保证结果可复现。相同种子和文本结果相同，这不是加密算法。
正文范围：ASCII、最多16MiB；UTF-8中文路径支持不代表支持中文正文。文件不存在、输入缺行/多行、种子或字母集合错误、正文非ASCII、读写失败，退出2，stdout不发布部分结果。空文件合法。源文件不能被修改。第9/10题使用独占创建，已有输出、同名输入、输出目录不存在均报错，不覆盖文件。
手动参考运行：python tools/study.py run cpp/主教材/章节学习/第04章 流类/课后习题/第07题 保持大小写的随机排版占位文本/reference.cpp --input cpp/主教材/章节学习/第04章 流类/课后习题/第07题 保持大小写的随机排版占位文本/input.txt；WSL将前半改为python3 tools/wsl-study.py run。运行工具的cwd是源文件目录，因此sample.txt与my-result.txt指向本题文件夹。已有my-result.txt时，另选一个新输出名再运行。
lesson.h是本题参考函数，公共file_lesson.h是文件读写支持；不要直接包含本题答案代替作答。tests.cpp检查参考函数，不会标记个人完成。stdout与文件内容严格比较，末尾换行有意义。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

按完整输出逐字比较；前后空格、空行与最后换行都参与检查。

输入样例：

```text
sample.txt
0
```

期望输出：

```text
Qpb qzr!
D zrrz, 123.
```

文件题说明：样例读取 `sample.txt`，内容如下。自动检查会在临时目录准备文件；手动运行需自己准备同名文件。

```text
Abc xyz!
A test, 123.

```
