# 第4章 · 习题12：基于整行读取实现getReal与getLine

> **要干什么：** 基于整行读取实现getReal与getLine。

## 1 · 题目是什么

先逐行读取实数，非法行提示写cerr并继续重试；合法后再读取一行标签。输出两行：格式化实数、原标签（可为空或含空格）。任何必需行遇EOF，退出2且标准输出（cout）为空，避免无限重试或半份结果。保留getReal(prompt="")和getLine(prompt="")接口；后者通过getline读取整行，不跳过合法空行。
这是按原书要求独立编写的实现；边界和输入输出格式是本区明确约定。除第12题允许连续重试外，多余输入行、缺少必需输入或格式错误返回2；正常退出0。输入正文以ASCII为主，文件名是UTF-8字符串字节，不做Unicode字符计数。
第8题按原始输出精确比较，最后的换行也是结果一部分；其他题移除程序打印的一次末尾换行后比较，保留前后空格。提示应写cerr。
另有tests.cpp检查参考函数接口，可直接编译运行；它不会检查或完成你的work。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::string realToString(double value);
std::string getLine(const std::string& prompt="");
double getReal(const std::string& prompt="");
```

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
1.25
frame 01
```

期望输出：

```text
1.25
frame 01
```
