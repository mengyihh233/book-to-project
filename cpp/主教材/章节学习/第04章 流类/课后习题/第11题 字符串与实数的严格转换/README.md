# 第4章 · 习题11：字符串与实数的严格转换

> **要干什么：** 字符串与实数的严格转换。

## 1 · 题目是什么

输入一行实数文本，调用stringToReal后再用realToString输出一行。允许首尾空白、小数和十进制科学计数法，必须整行解析成功；拒绝非有限值、溢出与尾部垃圾。classic locale固定小数点为.。输出以max_digits10有效数字保证double往返，0.1可能显示为0.10000000000000001，并非小数计算出错。此精度策略是教学约定。
这是按原书要求独立编写的实现；边界和输入输出格式是本区明确约定。除第12题允许连续重试外，多余输入行、缺少必需输入或格式错误返回2；正常退出0。输入正文以ASCII为主，文件名是UTF-8字符串字节，不做Unicode字符计数。
第8题按原始输出精确比较，最后的换行也是结果一部分；其他题移除程序打印的一次末尾换行后比较，保留前后空格。提示应写cerr。
另有tests.cpp检查参考函数接口，可直接编译运行；它不会检查或完成你的work。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
double stringToReal(const std::string& text);
std::string realToString(double value);
```

**work.cpp** 里有 2 个补全区，都是给定函数的函数体：

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
0
```

期望输出：

```text
0
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 25 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
