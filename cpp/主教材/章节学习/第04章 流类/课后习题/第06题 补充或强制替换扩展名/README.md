# 第4章 · 习题6：补充或强制替换扩展名

> **要干什么：** 补充或强制替换扩展名。

## 1 · 题目是什么

输入两行：文件名、扩展名。ext通常为.txt；已存在扩展名时保持原样，无扩展名才补充。ext前加*强制替换，单独*表示去除扩展名；空ext表示不追加。ext去掉可选*后必须为空或以点开头，且不可含路径分隔符或*。路径解析沿用第5题，不操作真实文件。
这是按原书要求独立编写的实现；边界和输入输出格式是本区明确约定。除第12题允许连续重试外，多余输入行、缺少必需输入或格式错误返回2；正常退出0。输入正文以ASCII为主，文件名是UTF-8字符串字节，不做Unicode字符计数。
第8题按原始输出精确比较，最后的换行也是结果一部分；其他题移除程序打印的一次末尾换行后比较，保留前后空格。提示应写cerr。
另有tests.cpp检查参考函数接口，可直接编译运行；它不会检查或完成你的work。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::string defaultExtension(const std::string& name, std::string ext);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `std::string defaultExtension(const std::string& name, std::string ext)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
report.txt
.txt
```

期望输出：

```text
report.txt
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 70 组样例，标准输出和退出码都逐字比对。

2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
