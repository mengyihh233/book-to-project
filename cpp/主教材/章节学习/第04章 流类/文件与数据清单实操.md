# 文件与数据清单实操：为机器视觉准备路径

这是独立设计的整合练习，不是新增原书题。先完成第4章5、6、8、11、12题。无需安装OpenCV。

准备一份manifest.txt，每行四列：图像路径、宽度、高度、曝光毫秒，先限定路径不含空格，例如`images/part.01.png 640 480 2.5`。一份样例三行：

```text
images/part.01.png 640 480 2.5
images/part.02.bmp 1280 720 1.25
data.v1/frame 320 240 5
```

## 分成四个可检查的小任务

1. getline逐行读清单，用istringstream提取四列，并检查尾部只剩空白。拒绝宽高≤0、曝光非有限或≤0、缺列及多列；打印行号便于定位。
2. 调用第5题的函数拆路径。预期前三个扩展名为.png、.bmp、空；data.v1是目录，不是第三个文件的扩展名。
3. 为三个路径各生成报告名，使用第6题的*.txt；结果为images/part.01.txt、images/part.02.txt、data.v1/frame.txt。这里只打印计划，不创建或覆盖真实文件。
4. 用第11题解析曝光并往返格式化；追加`1.2oops`、`nan`、缺列、空行作为失败样例。把错误说明写cerr，正常报告写cout。

先独立设计记录结构和输出，再考虑vector与排序。不必提前引入OpenCV或复制Windows/WSL两套工程；同一份.cpp可在两种环境编译。留意曝光单位：毫秒和秒必须显式转换。

## 为什么不能直接拿去注释函数清洗所有清单

第8题忽略引号，路径或URL中的//可能被误删；注释规则属于输入格式的一部分。此清单不定义注释，所以不要擅自调用removeComments。若设计新格式允许注释，先明确引号、转义与路径规则，再写解析器。
