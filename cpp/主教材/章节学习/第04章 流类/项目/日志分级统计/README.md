# 第4章 项目：日志分级统计

> **要干什么：** 读一份日志，按级别计数，并找出第一条错误。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入是一份日志，每行一条：

```text
INFO 服务启动
WARN 内存占用 78%
ERROR 连接数据库失败
```

- 每行以**级别**开头，级别只有三种：`INFO`、`WARN`、`ERROR`；
- 级别与消息之间**至少一个空格**；消息可以为空；
- 消息里可以有空格、数字、标点，**不参与解析**。

输出固定四行：

```text
INFO 1
WARN 1
ERROR 1
首条错误 连接数据库失败
```

- 前 3 行**顺序固定**为 INFO、WARN、ERROR，即使某个级别 0 条也要输出 `INFO 0`；
- 第 4 行只在**至少有一条 ERROR** 时输出，内容是**第一条** ERROR 的消息（消息前后的空格要去掉）；
- 一条 ERROR 都没有时，只输出前三行。

## 2 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| 输入为空（一行都没有） | 往 `stderr` 说明原因，**返回 2**，`stdout` 为空 |
| 某行级别不是那三个之一（如 `DEBUG 启动`） | 返回 2 |
| 某行只有级别、没有消息 | **合法**，算一条，消息为空 |
| 空行 | 跳过，不计入任何级别 |
| 行首有空格 | 允许，级别仍可识别 |

**「空输入」和「只有空行」不同**：前者返回 2，后者等于没有任何有效行——按「输入为空」处理，返回 2。

## 3 · 验收清单

- [ ] 三条各一个 → 前三行各 1，第四行是第一条 ERROR 的消息
- [ ] 两条 ERROR → 第四行只取**第一条**
- [ ] 没有 ERROR → 只输出三行，没有第四行
- [ ] `INFO` 后面没有消息 → `INFO` 计数 +1，不报错
- [ ] 完全空输入 → 返回 2，`stdout` 为空
- [ ] 出现 `DEBUG` → 返回 2
- [ ] 消息含空格（`ERROR 连不上 数据库 3306`）→ 第四行完整保留
