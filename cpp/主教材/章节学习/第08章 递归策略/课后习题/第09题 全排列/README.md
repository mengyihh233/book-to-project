# 第8章 · 习题9：全排列

> **要干什么：** 读入 n 个只含大写字母的字符串，递归列出每个字符串的**全部唯一排列**，按字典序输出。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 5），接下来 n 行每行一个字符串：只含大写字母，长度 1—7。
- 每个字符串输出它所有**不重复**的排列，一行一个，按字典序；多个字符串按输入顺序连排。
- 例如 `AAB` 只有 3 个不同排列：`AAB`、`ABA`、`BAA`。

原书习题 9（[PDF 第 273 页](../../../../../../books/cpp-roberts.pdf#page=273)）。**这里是题意改写与输入输出约定**：原书用`listPermutations(str)`：交换下标、不用集合，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `collectPermutations(s, start, out)`：`start` 走到末尾就把 `s` 收进集合；
否则把 `start` 与后面每个位置交换、递归、再换回来。集合会自动去重并排序。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（递归函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每个排列一行，字典序；不同输入之间不插空行。
- 空行、长度超过 7、出现非大写字母、行数不足：返回 2，**stdout 为空**。

输入样例：

```text
1
ABC
```

期望输出：

```text
ABC
ACB
BAC
BCA
CAB
CBA
```
