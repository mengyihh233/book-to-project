# 第8章 · 习题10：手机键盘记忆术

> **要干什么：** 读入 n 个数字串（2—9），列出所有可能的字母组合，按字典序输出。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 5），接下来 n 行每行一个数字串（只含 2—9，长度 1—6）。
- 键位：2=ABC、3=DEF、4=GHI、5=JKL、6=MNO、7=PQRS、8=TUV、9=WXYZ。
- 每个数字串输出所有字母组合，一行一个，按字典序；`723` 有 3×3×4=36 种。

原书习题 10（[PDF 第 273 页](../../../../../../books/cpp-roberts.pdf#page=273)）。**这里是题意改写与输入输出约定**：原书用`listMnemonics(numbers)`：每个数字映射到 3—4 个字母，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `collectMnemonics(digits, index, current, out)`：走到末尾就把 `current` 收下；
否则遍历当前数字对应的每个字母，接上、递归、再弹出。`keypad()` 已给。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（递归函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 4 · 怎么做

1. 先自己写补全区，卡住 20 分钟再去看 `solution.md`。
2. 跑「检查本题」：本题登记 5 组样例，其中 3 组正常输出、2 组是非法输入（要求退出码 2、stdout 为空）。
3. 通过之后自己再造两组：一组边界、一组非法，确认结果仍然对。

## 5 · 文本格式

- 每行一个字母组合，字典序。
- 出现 0/1、长度超过 6、空行、行数不足：返回 2，**stdout 为空**。

输入样例：

```text
1
23
```

期望输出：

```text
AD
AE
AF
BD
BE
BF
CD
CE
CF
```

## 6 · 哪个是判分的

比对本题登记的 5 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行（不判分）：** 任务“本题：运行作答”，或 `python tools/run-current.py <文件>`。
3. **核对：** 任务“本题：检查作答”，或 `python tools/check-current.py <文件>`。
