# 第8章 项目：汉诺塔定位

> **要干什么：** 给定盘子数 n 和第 k 步，说出第 k 步是哪个柱搬到哪个柱。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

输入一行两个整数 `n k`：

- `1 ≤ n ≤ 16`：盘子数（都在 A 柱，目标全搬到 C 柱，B 作中转）；
- `1 ≤ k ≤ 2ⁿ-1`：问第几步。

输出两行：

```text
步数 7
第 4 步 A->C
```

- `步数` 是 n 个盘子需要的总步数 `2ⁿ-1`；
- 第二行格式是 `第 k 步 X->Y`，柱名是大写 `A`/`B`/`C`，**注意 `第` 和 `k` 之间、`k` 和 `步` 之间各有一个空格**。

## 2 · 关键约束

**不许模拟整个移动过程。** n=16 时有 65535 步，模拟虽然也能过，但毫无意义。

正确做法是**每层递归直接判断**第 k 步落在哪一段：

```text
把上面 n-1 个从 A 搬到 B（需要 2ⁿ⁻¹-1 步）
把最大的从 A 搬到 C（第 2ⁿ⁻¹ 步）
把 n-1 个从 B 搬到 C（剩下的步数）
```

看 k 落在哪一段，就知道下一步往哪层递归、或者第 k 步就是中间那一搬。

## 3 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| `n` < 1 或 > 16 | 返回 2 |
| `k` < 1 或 > 2ⁿ-1 | 返回 2 |
| `n = 1` | 步数 1，第 1 步 `A->C` |
| 缺任一输入 | 返回 2 |

## 4 · 验收清单

- [ ] `3 1` → 步数 7，第 1 步 `A->C`
- [ ] `3 4` → 第 4 步 `A->C`（中间那一搬）
- [ ] `3 7` → 第 7 步 `A->C`
- [ ] `1 1` → 步数 1，第 1 步 `A->C`
- [ ] `4 15` → 步数 15，最后一步 `B->C`
- [ ] `0 1` → 返回 2
- [ ] `17 1` → 返回 2
- [ ] `3 8` → 返回 2（k 超过 7）
