# 第6章 项目：有理数运算

> **要干什么：** 读两个分数和一个运算符，输出最简结果。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

输入一行，形如：

```text
1/2 + 3/4
```

格式固定为 `a/b 运算符 c/d`，运算符只能是 `+ - * /`。

输出**最简分数**：

| 情况 | 输出 |
| --- | --- |
| 一般情况 | `5/4` |
| 结果是整数 | `1`（不是 `1/1`） |
| 结果是 0 | `0` |
| 负数 | `-1/4`（负号在分子，分母永远为正） |

## 2 · 强制要求

**必须定义一个分数类**，把「约分」放在构造函数里，四则运算写成成员函数或重载运算符。
不许在 `main` 里直接算 `num1*den2 + num2*den1` 再手写约分——那样这题就退化成算术练习了。

自动判分只看输出，看不出你有没有建类。**但建不建决定这题有没有练到第 6 章。**

## 3 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| 任一输入分母为 0 | 往 `stderr` 说明原因，**返回 2**，`stdout` 为空 |
| 除法的除数为 0（如 `1/2 / 0/5`） | 同上 |
| 格式不对（缺 `/`、运算符不认识） | 返回 2 |
| 结果为负数 | 负号只在分子上 |
| 可约分（如 `2/4`） | 必须约到 `1/2` |

## 4 · 验收清单

- [ ] `1/2 + 3/4` → `5/4`
- [ ] `1/2 + 1/2` → `1`（不是 `1/1`）
- [ ] `1/3 - 1/3` → `0`
- [ ] `2/3 * 3/4` → `1/2`（必须约分）
- [ ] `-1/2 + 1/4` → `-1/4`（负号在分子）
- [ ] `1/2 / 0/5` → 返回 2，`stdout` 为空
- [ ] `1/0 + 1/2` → 返回 2
- [ ] 分母为负（如 `1/-2`）→ 输出 `-1/2`

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

## 6 · 做完的标准

1. 约分放在哪一步？如果放在输出前才约，会出什么问题？
2. `1/2 + 1/2` 为什么必须输出 `1` 而不是 `1/1`？这是格式约定还是数学要求？
3. 分母为负时你怎么处理？为什么统一让分母为正？
4. 两个分数的分母相乘，什么时候会溢出 `int`？
