# 第6章 · 习题2：扑克牌 Card 类

> **要干什么：** 读入 n 张扑克牌（短串如 `10S`、`JD`、`ac`），输出规范短串、等级数值与花色全名。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 52），接下来 n 行每行一张牌。
- 等级：`A` = 1、`2`…`10`、`J` = 11、`Q` = 12、`K` = 13。
- 花色：`C` = CLUBS、`D` = DIAMONDS、`H` = HEARTS、`S` = SPADES；**输入大小写都收**。
- 每张牌输出一行：`规范短串 等级 花色名`，例如 `10S 10 SPADES`（短串统一大写）。

原书习题 2（[PDF 第 224 页](../../../../../../books/cpp-roberts.pdf#page=224)）。**这里是题意改写与输入输出约定**：原书用 `card.h` / `card.cpp` 两个文件，加一个按花色四行打印的 main，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `Card` 的短串构造函数：拆出花色字母与等级文本，校验后写进 `rank_`、`suit_`；
再补 `main` 的读入与三列输出（`toString()` 和 `suitName()` 已给）。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（Card 的短串构造函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每张牌一行：`短串 等级 花色名`，短串与花色名都大写。
- 非法牌（如 `1S`、`11H`、`AX`、`Q`）返回 2，**stdout 为空**。
- 错误说明写 `cerr`，不要混进标准输出。

输入样例：

```text
3
10s
jd
AC
```

期望输出：

```text
10S 10 SPADES
JD 11 DIAMONDS
AC 1 CLUBS
```
