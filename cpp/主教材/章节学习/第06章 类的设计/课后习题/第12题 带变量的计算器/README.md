# 第6章 · 习题12：带变量的计算器

> **要干什么：** 读入 n 行，支持 `名字 = 表达式` 赋值和表达式求值（都按从左到右），表达式可引用已定义的变量。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 100），接下来 n 行。
- 每行两种形式：`名字 = 表达式`（赋值，不输出）或 `表达式`（求值并输出）。
- 变量名由字母、数字、下划线组成；只能用**已经定义过**的变量。
- 运算仍是 `+ - * /`，**从左到右**，没有括号；结果输出两位小数。

原书习题 12（[PDF 第 228 页](../../../../../../books/cpp-roberts.pdf#page=228)）。**这里是题意改写与输入输出约定**：原书用在习题 11 的计算器上加入变量与赋值，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `evaluate()`：记号既可以是数字，也可以是变量名（查 `vars`，没有就抛异常），
其余与左到右计算器一致；再补 `main` 的行解析（判断是不是赋值、变量名校验、输出）。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（evaluate 求值）和 `BEGIN 2` … `END 2`（解析行、赋值与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 表达式行输出两位小数；赋值行**不输出**。
- 未定义变量、非法变量名、缺表达式、除数为 0、空行：返回 2，**stdout 为空**。
- 允许重复赋值（后一次覆盖前一次）。

输入样例：

```text
3
x = 3
y = 4
x * y
```

期望输出：

```text
12.00
```
