# 第6章 · 习题5：Date 类的构造与星期

> **要干什么：** 读入 n 个 ISO 日期（`YYYY-MM-DD`），校验后输出 `dd-MMM-yyyy` 与星期几。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 100），接下来 n 行每行一个 `YYYY-MM-DD`。
- 年份范围 1900—2100；月 1—12；日不超过当月天数（闰年 2 月有 29 天：
  能被 4 整除，但整百年必须能被 400 整除）。
- 输出 `dd-MMM-yyyy 星期X`：日**不补零**，月份用三字母大写英文缩写，星期用中文。
- 例如 `1969-07-20` → `20-JUL-1969 星期日`。

原书习题 5（[PDF 第 225 页](../../../../../../books/cpp-roberts.pdf#page=225)）。**这里是题意改写与输入输出约定**：原书用 `calendar.h` 里 Date 的构造函数、访问器与 `toString`，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `Date` 的构造函数：范围、月份、当月天数（含闰年）都要校验，非法就抛 `std::invalid_argument`；
再补 `main` 里的循环：解析、构造、输出（`parseIso`、`toString`、`weekday` 已给）。

## 5 · 文本格式

- 每行 `dd-MMM-yyyy 星期X`，日和年不补零。
- 非法日期（格式错、月份 13、2 月 30 日、2101 年）返回 2，**stdout 为空**。
- 星期用中文：星期日、星期一 … 星期六。

输入样例：

```text
2
1969-07-20
2000-02-29
```

期望输出：

```text
20-JUL-1969 星期日
29-FEB-2000 星期二
```
