# 第6章 · 习题1：多米诺骨牌

> **要干什么：** 读入一组多米诺骨牌，每张写成规范形式、去重、排序，最后判断是不是完整的一套。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 1000），接下来 n 行每行两个整数 a、b（0 ≤ a, b ≤ 6）。
- 骨牌翻转后是同一张：`4-1` 与 `1-4` 都写成 `1-4`。
- 输出按 left 再 right 升序，每张一行，形如 `0-0`。
- 最后两行：`不同 k 张`、`完整一套 是` 或 `完整一套 否`（0-0 到 6-6 共 28 张齐全才是「是」）。

原书习题 1（[PDF 第 223 页](../../../../../../books/cpp-roberts.pdf#page=223)）。**这里是题意改写与输入输出约定**：原书用 `domino.h` / `domino.cpp` 两个文件和图形化的 main，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写一个 `Domino` 类：两参构造函数里校验点数并规范成「小-大」，`toString()` 返回 `a-b`（已给）。
再补 `main` 里的读入、去重（`std::set`）、排序输出与统计。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（Domino 构造函数）和 `BEGIN 2` … `END 2`（读入、去重与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 4 · 怎么做

1. 先自己写补全区，卡住 20 分钟再去看 `solution.md`。
2. 跑「检查本题」：本题登记 7 组样例，其中 4 组正常输出、3 组是非法输入（要求退出码 2、stdout 为空）。
3. 通过之后自己再造两组：一组边界、一组非法，确认结果仍然对。

## 5 · 文本格式

- 每张牌一行 `a-b`（a ≤ b）。
- 统计两行：`不同 k 张`、`完整一套 是` 或 `完整一套 否`。
- 非法输入：返回 2，**stdout 必须为空**，错误说明写 `cerr`。
- 只输出这些内容，不要打印“请输入”之类的提示。

输入样例：

```text
4
4 1
1 4
0 0
6 3
```

期望输出：

```text
0-0
1-4
3-6
不同 3 张
完整一套 否
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，
比对本题登记的 7 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行（不判分）：** 任务“本题：运行作答”，或 `python tools/run-current.py <文件>`。
3. **核对：** 任务“本题：检查作答”，或 `python tools/check-current.py <文件>`。
