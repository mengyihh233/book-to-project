# 第6章 · 习题11：左到右计算器

> **要干什么：** 读入 n 行四则表达式，按**从左到右**（不考虑优先级）求值，输出两位小数。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 100），接下来 n 行每行一个表达式，记号用空格分开。
- 只有 `+ - * /` 和十进制数（可带小数），**没有括号**。
- 求值顺序是从左到右：`12 + 3 * 4` = 60（先算 12+3，再乘 4），不要按数学优先级。
- 输出每行固定两位小数，如 `60.00`。

原书习题 11（[PDF 第 227 页](../../../../../../books/cpp-roberts.pdf#page=227)）。**这里是题意改写与输入输出约定**：原书用用 TokenScanner 写的简单计算器（按从左到右求值），
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `evaluate()`：先读一个数当累计值，之后循环读「运算符 + 操作数」并立刻累算；
除数为 0、记号不认识、操作数缺失都要抛异常。再补 `main` 的整行读取与两位小数输出。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（evaluate 左到右求值）和 `BEGIN 2` … `END 2`（读取与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每行一个结果，固定两位小数。
- 除以 0、记号非法、操作数缺失、空表达式：返回 2，**stdout 为空**。
- 不要按运算符优先级；题目要的就是「按顺序按计算器」。

输入样例：

```text
1
12 + 3 * 4
```

期望输出：

```text
60.00
```
