# 第6章 · 习题7：编号生成器

> **要干什么：** 按行读入「前缀 个数」，为每个前缀连续生成编号，同一前缀跨行接着数。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 100），接下来 n 行每行 `前缀 个数`。
- 前缀 1—20 个字符、不含空白；个数 1—1000。
- 每个标签输出一行：`前缀 + 编号`，编号从 0 开始、**不补零**。
- 同一个前缀在多行出现时，编号**接着之前继续**；不同前缀各自从 0 开始。

原书习题 7（[PDF 第 226 页](../../../../../../books/cpp-roberts.pdf#page=226)）。**这里是题意改写与输入输出约定**：原书用书里 `LabelGenerator` 这类「相似但可区分」的命名工具，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `LabelGenerator::next()`：用 `counters_` 记住每个前缀下一个编号，返回标签后把计数加一；
再补 `main` 里的读入、校验与连续输出（类的声明和 `map` 都已给）。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（LabelGenerator::next）和 `BEGIN 2` … `END 2`（读入与连续输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每个标签一行，形如 `Figure0`、`P3`，编号不补零。
- 个数越界、前缀太长、行不完整：返回 2，**stdout 为空**。
- 输出顺序按输入顺序，不排序、不合并相同行。

输入样例：

```text
3
Figure 2
P 3
Figure 1
```

期望输出：

```text
Figure0
Figure1
P0
P1
P2
Figure2
```
