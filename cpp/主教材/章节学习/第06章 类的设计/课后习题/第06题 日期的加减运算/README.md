# 第6章 · 习题6：日期的加减运算

> **要干什么：** 读入 n 个「日期 天数」，把日期加上（或减去）这些天，输出结果与星期。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 100），接下来 n 行每行 `YYYY-MM-DD k`。
- `k` 是整数天，可以为负；结果必须仍在 1900-01-01 到 2100-12-31 之间。
- 输出 `dd-MMM-yyyy 星期X`（日不补零），例如 `1969-07-20` 加 1 天 → `21-JUL-1969 星期一`。
- 跨月、跨年、闰年 2 月都要对：2000-02-28 加 1 天是 2000-02-29。

原书习题 6（[PDF 第 226 页](../../../../../../books/cpp-roberts.pdf#page=226)）。**这里是题意改写与输入输出约定**：原书用 `calendar.h` 里 Date 的 `++`、`--`、`+=`、`-=` 等运算符，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `Date::operator+=`：用已给的 `toSerial` / `fromSerial` 做「日期 → 日号 → 日期」，
越界抛 `std::out_of_range`；再补 `main` 的循环（解析、构造、加天数、输出）。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（Date::operator+=）和 `BEGIN 2` … `END 2`（读入、加天数与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

## 5 · 文本格式

- 每行 `dd-MMM-yyyy 星期X`。
- 结果越界（如 2100-12-31 加 1 天）、格式错、每行不完整：返回 2，**stdout 为空**。
- 不要自己判断「这个月有几天」，交给序列日号换算。

输入样例：

```text
1
1969-07-20 1
```

期望输出：

```text
21-JUL-1969 星期一
```
