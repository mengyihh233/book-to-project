# 第6章 · 习题8：有理数的四则运算

> **要干什么：** 读入 n 个分数运算式，按最简分数输出结果（分母恒正、分母为 1 时只写整数）。

## 1 · 题目是什么

- 第 1 行 `n`（1 ≤ n ≤ 100），接下来 n 行每行 `a b op c d`，表示 a/b op c/d。
- `op` 是 `+`、`-`、`*`、`/` 之一；分数以「分子 分母」两个整数给出（分母在 op 前）。
- 分母不能为 0；`|a|`、`|b|`、`|c|`、`|d|` ≤ 10⁹。
- 结果必须约分、分母恒正；分母为 1 时只输出整数（`2`），否则输出 `num/den`（`-5/6`）。

原书习题 8（[PDF 第 227 页](../../../../../../books/cpp-roberts.pdf#page=227)）。**这里是题意改写与输入输出约定**：原书用书里的 `rational.h` 类定义与四个运算符重载，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写完 `Rational` 的两参构造函数（判零、符号归一、`std::gcd` 约分），
以及 `combine()` 里 `+ - * /` 四种情况（分子分母怎么算、除法怎么判零）。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（Rational 构造函数）和 `BEGIN 2` … `END 2`（combine 四则运算）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每条表达式输出一行：最简分数；分母为 1 时只写整数。
- 负数写作 `-1/2`，不要写成 `1/-2`。
- 分母为 0、除数为 0、运算符不认识：返回 2，**stdout 为空**。

输入样例：

```text
4
1 2 + 1 3
1 2 - 1 2
2 3 * 3 4
1 2 / 1 4
```

期望输出：

```text
5/6
0
1/2
2
```
