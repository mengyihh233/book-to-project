# 第14章 项目：括号匹配

> **要干什么：** 判断一行括号是否配对，并给出最大嵌套深度。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

输入一行，只含 `(` `)` `[` `]` `{` `}` 和空格（长度 ≤ 100000）。空格忽略。

输出两行：

```text
匹配 是
深度 2
```

- `匹配` 只有 `是` / `否` 两种；
- `深度` 是**最大嵌套层数**，从 1 开始；不匹配时统一输出 `0`。

## 2 · 关键要求

**必须用栈**（`std::string` 或自己写的栈都行）：
遇到左括号入栈，遇到右括号检查栈顶是否为对应的左括号，是就弹出，不是就失败。

不许用「计数法」——单独数 `(` 和 `)` 的个数无法区分 `([)]` 这种交叉嵌套。

## 3 · 边界

| 情况 | 要求 |
| --- | --- |
| 空行 | **匹配 是，深度 0**（空串是合法输入，不是错误） |
| 含非法字符（字母、数字） | 返回 2 |
| 只有左括号如 `((` | 匹配 否，深度 0，**返回 0** |
| 只有右括号如 `)` | 匹配 否，深度 0，返回 0 |
| 交叉嵌套 `([)]` | 匹配 否 |

**「不匹配」和「非法输入」是两件事**：前者返回 0 并输出「否」，后者返回 2 且 `stdout` 为空。

## 4 · 验收清单

- [ ] `([]{})` → 匹配 是，深度 **2**
- [ ] `((()))` → 匹配 是，深度 **3**
- [ ] `()` → 匹配 是，深度 1
- [ ] `([)]` → 匹配 否，深度 0
- [ ] `(]` → 匹配 否
- [ ] 空行 → 匹配 是，深度 **0**
- [ ] `a(` → 返回 2

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

## 6 · 做完的标准

1. 为什么「数左括号和右括号的个数」判断不了 `([)]`？
2. 栈里存的是左括号还是右括号？存右括号可以吗？
3. 扫描结束后栈不空，说明什么？
4. 深度是在入栈时更新还是出栈时更新？为什么？

## 7 · 扩展（可选）

1. 输出第一处错误的**位置**（下标）。
2. 支持 `< >` 作为第四种括号。
3. 输入多行，每行单独判断。
