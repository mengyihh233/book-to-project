# 第14章 · 习题3：模板类 Pair

> **要干什么：** 实现一个模板类 Pair，存一对同类型的值，按第一项排序输出。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 1000），接下来 n 行每行两个值：要么都是整数，要么都是不含空格的字符串。
- 同一组输入里的类型必须一致；混着来算非法。
- 输出 `(第一项, 第二项)`，按第一项升序、第一项相同再按第二项升序。

原书习题 3（[PDF 第 459 页](../../../../../../books/cpp-roberts.pdf#page=459)）。**这里是题意改写与输入输出约定**：原书用`template <class T1, class T2> class Pair`，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `template <class T> class Pair`：存两个值、提供 `first()`/`second()` 与 `toString()`（拼成 `(a, b)`）；
`main` 读入、判断类型、排序后输出。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（模板实现）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；补完把区里的占位注释（`// @@N@@`）或占位 `throw` 删掉。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每行 `(a, b)`，逗号后一个空格。
- 类型不一致、n 越界、行不完整：返回 2，**stdout 为空**。

输入样例：

```text
3
b two
z one
a one
```

期望输出：

```text
(a, one)
(b, two)
(z, one)
```
