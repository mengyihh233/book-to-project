# 第14章 · 习题2：模板排序接口

> **要干什么：** 写一个模板函数把任意可比较的元素排好序：同一份代码同时服务整数和字符串。

## 1 · 题目是什么

- 第一行 `type`（`int` 或 `string`），第二行 `n`（1 ≤ n ≤ 1000），第三行起 n 个值。
- `string` 的值不含空格；`int` 的值 |v| ≤ 10⁹。
- 输出升序结果，空格分隔，一行；字符串按字典序。

原书习题 2（[PDF 第 459 页](../../../../../../books/cpp-roberts.pdf#page=459)）。**这里是题意改写与输入输出约定**：原书用`sort.h`：给不同元素类型提供同一套排序接口，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `template <class T> void sortValues(std::vector<T>& data)`（用插入排序或选择排序都行，
不要直接调 `std::sort`），`main` 按 type 分派并输出。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（模板实现）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；补完把区里的占位注释（`// @@N@@`）或占位 `throw` 删掉。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 一行升序结果，数/串之间一个空格。
- type 不认识、n 越界、值个数不足：返回 2，**stdout 为空**。

输入样例：

```text
int
5
3 1 4 1 5
```

期望输出：

```text
1 1 3 4 5
```
