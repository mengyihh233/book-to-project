# 第3章 项目：词频统计

> **要干什么：** 读一段英文文本，输出出现次数最多的前 10 个词。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

程序从标准输入读两段内容：

| 部分 | 内容 |
| --- | --- |
| 第 1 行 | 停用词表，空格分隔，**可以是空行**（表示不排除任何词） |
| 其后全部 | 正文，可能有很多行 |

输出：词频最高的前 10 个词，每行 `词 次数`（一个空格）。

排序规则：

1. 次数多的在前；
2. 次数相同的，**按字典序升序**（`apple` 在 `banana` 前）。

## 2 · 词怎么算

- **连续的英文字母**才算一个词。数字、标点、空格、中文、下划线都是分隔符。
- 统一转成小写再统计：`The`、`THE`、`the` 是同一个词。
- 停用词按小写匹配，命中就整词丢掉，不计数。
- 大小写不同的同一词，出现在统计结果里时一律小写。

例：`Foo foo-bar FOO` 在停用词为 `foo` 时，一个词都不会留下；停用词为空时得到 `foo 3` 和 `bar 1`。

## 3 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| 输入完全为空（一个字节都没有） | 往 `stderr` 说明原因，**返回 2**，`stdout` 不输出任何内容 |
| 第 1 行是空行，正文为空 | **合法**：返回 0，`stdout` 为空 |
| 不同的词不足 10 个 | 有几个输出几个，不要补空行 |
| 超过 10 个 | 只输出前 10 行，不要输出省略号或提示 |
| 超长行（几万字符） | 不能崩，也不能只读到一半 |

**「输入为空」和「正文为空」是两件事，必须分开处理。** 这是本题最容易漏的一处。

## 4 · 验收清单

写完自己逐条打勾，**不要靠样例对答案**：

- [ ] `The quick brown fox jumps over the lazy dog. The FOX!`（停用词 `the over`）里，`fox` 是 2 次，且排在第一位
- [ ] 同一份输入去掉停用词 `the` 后，`the` 一次都不出现
- [ ] `Foo foo-bar FOO`（停用词 `foo`）→ 只有 `bar 1`
- [ ] 停用词行是空行时，程序不报错
- [ ] 空输入返回 2 且 `stdout` 为空；只有停用词行时返回 0 且 `stdout` 为空
- [ ] 造 12 个不同词、频次依次递减，输出**正好 10 行**，最后两个词不出现
- [ ] 三个词频次相同，输出顺序是字典序
- [ ] 一行 10 万字符，程序不崩

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。**

它用 7 组你看不到的输入跑你的程序，逐字比对 `stdout` 与退出码。

| 会被判错 | 不会被判错但也不对 |
| --- | --- |
| 输出多了提示语（`请输入文本：`） | 变量名不好看 |
| 少输出、多输出几行 | 用了 `unordered_map` 而不是 `map` |
| 该返回 2 却返回 0 | — |
| 次数相同却没按字典序 | — |

**「再测没见过的输入」也能用**：它会把输入做小幅改动，和参考实现比对。但这题不给样例，所以这层主要用来确认你的边界处理和参考实现一致。

## 6 · 做完的标准

不是「跑通了」，而是能回答：

1. 你怎么把一行拆成词？为什么这样处理行尾？
2. 为什么「输入为空」要返回 2，而「正文为空」返回 0？两者在代码里怎么区分？
3. 排序为什么要两个条件？只按次数排会出什么问题？
4. 如果文本有 1 GB，现在这份实现哪里会先撑不住？

## 7 · 扩展（可选，不做也算完成）

按难度递增，任选：

1. **支持中文**：不按字节切，按 UTF-8 字符切，中文词按「连续汉字」算一个词。
2. **支持自定义词数**：第一行改成 `停用词 | 10`，词数可配置。
3. **支持文件参数**：`./work text.txt` 从文件读，没有参数才读标准输入。
4. **改成长尾统计**：输出「只出现一次」的词有多少个。

扩展不参与自动判分，但写完可以放进 `我的备份/` 留档。

## 8 · 卡住了怎么办

按这个顺序，不要一开始就看参考：

1. 先把「读停用词行 → 读正文 → 按空格切词 → 计数」跑通，哪怕切词很粗糙；
2. 再补「非字母算分隔符」；
3. 再补排序与截断；
4. 最后补两种空输入的区分。

实在卡住 20 分钟以上，再看 `solution.md`（讲思路，不贴整份代码）和 `reference.cpp`。看完**合上重写一遍**，不要复制。
