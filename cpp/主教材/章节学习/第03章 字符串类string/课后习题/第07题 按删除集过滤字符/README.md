# 第3章习题7：按删除集过滤字符

> **要干什么：** 按删除集过滤字符。

## 1 · 题目是什么

原书题干（PDF117页）。这是按原题要求独立编写的教学实现；输入输出格式和资源限制属于本区验收约定，不是原书逐字程序。
输入两行：原字符串、删除字符集。返回删除这些字符后的新字符串，保持剩余顺序。大小写敏感、重复删除字符不改变结果，原字符串不修改。
文本使用ASCII，每行最多10000字节。空行是合法的空字符串，缺少一行是输入错误；多余行也拒绝。非ASCII、错误格式返回2且stdout不输出结果。ASCII限制为配合本章逐字节string模型；UTF-8中文不应按字节当作单个汉字处理。
本组检查保留输出前后空白字符，只去掉程序输出的最后一个换行；输出字符串后应打印一次换行。不要额外打印输入提示，它会影响验收。自己的实现写work.cpp，input.h可复用；lesson.h是参考答案，不要在work中包含它来替代作答。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::string removeCharacters(const std::string&, const std::string&);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `std::string removeCharacters(const std::string& str, const std::string& remove)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 4 · 怎么做

1. 先手算上面的样例，写清每个输入代表什么。
2. 在work.cpp实现，先保存，再运行。
3. 做“本题：检查作答”，看通过几组；最后再对照解析。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
counterrevolutionaries
aeiou
```

期望输出：

```text
cntrrvltnrs
```

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 12 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
