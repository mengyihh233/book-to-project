# 第3章习题19：求逆置换密钥

> **要干什么：** 求逆置换密钥。

## 1 · 题目是什么

原书题干（PDF121页）。第16、20题跨页，继续阅读下一页。以下为独立教学实现，输入输出格式和边界约定写明如下。
输入一行26字母置换密钥，输出能解码其结果的逆密钥，规范为大写。拒绝重复字母、非字母、长度不符；不通过简单倒序代替求逆。
使用ASCII逐行输入，每行最多10000字节；缺行、多余行、非法字符或超范围输入返回2，stdout不输出结果。输出仅一行答案，保留前后空白。
reference.cpp和lesson.h为参考；work.cpp为独立作答，input.h可复用。tests.cpp检查参考契约，不会自动标记个人完成。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::string invertKey(const std::string& rawKey);
```

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
QWERTYUIOPASDFGHJKLZXCVBNM
```

期望输出：

```text
KXVMCNOPHQRSZYIJADLEGWBUFT
```
