# 第3章习题10：字符与字符串替换重载

> **要干什么：** 字符与字符串替换重载。

## 1 · 题目是什么

原书题干（PDF118页）。第14题从上一页开始。以下为按原题独立编写的教学解答，输入格式和资源限制是验收约定。
输入四行：模式char或string、原字符串、搜索内容、替换内容。char模式后两行必须各有一个字符。string模式按原字符串从左到右、互不重叠地替换，不再次扫描新插入内容；允许替换为空。空搜索串拒绝，输出超过1000000字节拒绝。上述歧义与资源限制是教学验收约定。
每行最多10000个ASCII字节，保留空格；缺少行、多余行、非ASCII或不符合题目限制的输入返回2，stdout不输出结果。正常程序只输出答案及最后一次换行。work.cpp是自己的作答；input.h仅输入工具，lesson.h是参考解答。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::string replaceAll(std::string, char, char);
std::string replaceAll(const std::string&, const std::string&, const std::string&);
```

## 3 · 写在哪里

**work.cpp** 里 2 个补全区，都是给定函数的函数体：

| 补全区 | 函数 |
| --- | --- |
| `BEGIN 1` | `std::string replaceAll(std::string str, char from, char to)` |
| `BEGIN 2` | `std::string replaceAll(const std::string& str, const std::string& from, const std::string& to)` |

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉每个区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 4 · 怎么做

1. 先手算上面的样例，写清每个输入代表什么。
2. 在work.cpp实现，先保存，再运行。
3. 做“本题：检查作答”，看通过几组；最后再对照解析。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
char
nannies
n
d
```

期望输出：

```text
daddies
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 19 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。

## 7 · 做完的标准

页面显示“登记样例全部通过”，并且你能自己再造两组输入验证结果。

这只是固定样例的结果，边界情况仍要自己想一遍。

检查只比对已登记的固定样例，不是正式满分证明，也不会自动记录完成。input.txt可放自己的测试；.in是检查输入，.out是期望结果，不是让你填答案的文件。
