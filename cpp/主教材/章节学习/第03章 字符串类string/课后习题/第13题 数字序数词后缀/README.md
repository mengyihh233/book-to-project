# 第3章习题13：数字序数词后缀

> **要干什么：** 数字序数词后缀。

## 1 · 题目是什么

原书题干（PDF118页）。第14题从上一页开始。以下为按原题独立编写的教学解答，输入格式和资源限制是验收约定。
输入一个0..9223372036854775807的整数，输出数字加st/nd/rd/th。11、12、13结尾优先用th；0按本区约定为0th。signed 64-bit范围是教学扩展，负数拒绝。
每行最多10000个ASCII字节，保留空格；缺少行、多余行、非ASCII或不符合题目限制的输入返回2，stdout不输出结果。正常程序只输出答案及最后一次换行。work.cpp是自己的作答；input.h仅输入工具，lesson.h是参考解答。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::string createOrdinalForm(long long);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `std::string createOrdinalForm(long long n)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
0
```

期望输出：

```text
0th
```
