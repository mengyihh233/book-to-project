# 第3章习题15：保留句首大写的Pig Latin

> **要干什么：** 保留句首大写的Pig Latin。

## 1 · 题目是什么

原书题干（PDF119页）。第16、20题跨页，继续阅读下一页。以下为独立教学实现，输入输出格式和边界约定写明如下。
输入整行英文文本，按连续ASCII字母段翻译，原样保留非字母。无元音的词不变；元音开头加way；否则把元音前的辅音段移到末尾加ay。含元音的词先规范成小写，原词首字母大写时再把译词首字母大写；全大写/混合大小写不额外保留。元音只含a/e/i/o/u，大小写不敏感。
使用ASCII逐行输入，每行最多10000字节；缺行、多余行、非法字符或超范围输入返回2，stdout不输出结果。输出仅一行答案，保留前后空白。
reference.cpp和lesson.h为参考；work.cpp为独立作答，input.h可复用。tests.cpp检查参考契约，不会自动标记个人完成。

要实现的函数接口（不含函数体）：

```cpp
std::string lineToPigLatin(const std::string& line);
```

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
This is Pig Latin.
```

期望输出：

```text
Isthay isway Igpay Atinlay.
```
