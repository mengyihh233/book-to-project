# 解题思路与边界

检查pos后再计算str.size()-pos，从剩余长度和n取较小值；不要直接算pos+n，避免溢出。按索引累加结果；默认n=string::npos时仍正确。原书要求不用成员substr，测试里用标准成员函数当对照是另一回事。

## 自主实操

先在notes预测空串、单字符、含空格字符串的输出；手动运行input样例，再在work中独立实现。把tests.cpp中的断言改成自己设计的正常和反例输入。第7题与第8题要比较调用前后原字符串是否变化，而不仅看终端打印是否相同。

检查只做固定样例，不是完整证明。每行输入都有长度上限，适用于学习练习；不要把这里的ASCII字符串函数直接当作Unicode文本库。
