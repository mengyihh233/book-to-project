# 第3章习题1：后缀判断与重载

> **要干什么：** 后缀判断与重载。

## 1 · 题目是什么

原书题干（PDF116页）。这是按原题要求独立编写的教学实现；输入输出格式和资源限制属于本区验收约定，不是原书逐字程序。
输入两行：原字符串、后缀。输出true/false。函数另有char后缀重载，见tests.cpp；交互入口统一按字符串读入，不把单字符字符串误认为char类型。
文本使用ASCII，每行最多10000字节。空行是合法的空字符串，缺少一行是输入错误；多余行也拒绝。非ASCII、错误格式返回2且stdout不输出结果。ASCII限制为配合本章逐字节string模型；UTF-8中文不应按字节当作单个汉字处理。
本组检查保留输出前后空白字符，只去掉程序输出的最后一个换行；输出字符串后应打印一次换行。不要额外打印输入提示，它会影响验收。自己的实现写work.cpp，input.h可复用；lesson.h是参考答案，不要在work中包含它来替代作答。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
bool endsWith(const std::string&, const std::string&);
bool endsWith(const std::string&, char);
```

## 3 · 写在哪里

**work.cpp** 里 2 个补全区，都是给定函数的函数体：

| 补全区 | 函数 |
| --- | --- |
| `BEGIN 1` | `bool endsWith(const std::string& str, const std::string& suffix)` |
| `BEGIN 2` | `bool endsWith(const std::string& str, char suffix)` |

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉每个区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

> **本题有两份作答：** `work.cpp` 是补写版（给好骨架，只补补全区），`from-scratch.cpp` 是从零写（只有题头）。**两份都能判分**——网页上文件下拉选哪个，就判哪个。


## 4 · 怎么做

1. 先把边界想清楚：后缀比原串长一定不匹配；后缀是空串算匹配；两者完全相同时也匹配。
2. 在 `BEGIN 1` 里实现主版本，删掉占位 `throw`，返回 `true` 或 `false`。
3. 保存后运行一次，确认输出是小写的 `true` / `false`。
4. 再写 `BEGIN 2`：可以构造一个单字符的字符串复用上面的实现，也可以直接用 `text.back()` 比较。
5. 点「检查本题」，13 组全过再看解析。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
hello.cpp
.cpp
```

期望输出：

```text
true
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 13 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
