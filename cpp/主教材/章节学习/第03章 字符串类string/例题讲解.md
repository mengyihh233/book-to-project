# 第3章例题讲解：让字符串边界看得见

原书对应PDF101—106的输入与string操作，以及PDF111的回文讨论。下面的演示与练习均独立编写，不是逐字转载原书程序。

## 1. 读一个词还是整行

原书的姓名示例指出cin >> name只读到空白前，getline(cin,name)能保留整行。试着输入Ada Lovelace，先预测两个读法分别拿到什么。混合使用>>和getline时，前一次输入留下的换行可能使getline读到空行；先明确输入格式，必要时ignore到行尾。不要为“去掉换行”无条件使用std::ws：它也会吃掉本来有意义的开头空格和空行。

本章原书作答使用逐行输入。空行与文件结束不同：getline读到空行返回成功，遇到无数据的EOF才失败。

## 2. 字符、字符串与成员函数

'x'是char，"x"是字符串字面量，std::string("x")是string对象。习题1的两个endsWith重载靠参数类型选择。str.length()与str.size()给出同一字节长度；不是length(str)。UTF-8中文通常占多个字节，本组明确只验收ASCII，不把字节长度称为汉字个数。

## 3. 索引与半开区间

长度为n时，真正的字符索引是0..n-1。读取或写入前先确认索引；这里用at来演示越界异常。substr的位置可以等于n并返回空串，但不能大于n。练习用[first,last)表示字符串区间，长度是last-first。

std::string::size_type通常是无符号类型；空串的size()-1会下溢。逆序循环可写for(size_t i=s.size(); i>0; --i)，循环体访问s[i-1]，不要写i>=0当终止条件。

## 4. 值、引用与返回副本

复制字符串后修改副本，不改变原对象。第7题removeCharacters返回新对象，第8题removeCharactersInPlace通过引用修改原对象，二者的终端输出可以相同，但接口行为不同。测试必须同时观察调用前后的原变量。

当removeCharactersInPlace(s,s)两个实参指向同一对象时，如果删除集也引用s，它会在修改过程中变化；本区把删除集按值保存，这是有意设计的别名保护，不是每个参数都应随意复制。

## 5. find失败不是下标

先保存auto pos=s.find(...);仅在pos!=string::npos时访问s[pos]。npos不是普通有效位置。自写substr时先检查pos，再计算size-pos；不能先算pos+n，极大数可能溢出。

## 6. 回文例题怎样接到习题

原书PDF111先比较成对字符，再讨论逆序副本法。已有第3章回文配套练习仍保留。可以先完成字符过滤与大小写规范化，再组合成忽略标点的句子回文；这一组合是后续第11题的准备，现已补第11题单行与空行终止交互两种入口。
