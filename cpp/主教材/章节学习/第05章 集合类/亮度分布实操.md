# 从容器统计到机器视觉：亮度分布

这是独立整合练习，不新增原书题号。先做第5章1—4题，再写brightness-work.cpp；brightness-example.cpp是可运行参考，复用原书题的参考函数。没有安装新库，不需要先准备真实相机。

## 输入与统计口径

brightness-input.txt第1行是像素个数，后续每行一个0..255整数灰度。数量1..10000；错误或缺少/多余数据退出2，stdout为空。例子0、0、255、255的均值127.5，总体标准差127.5；若四个值全为128，均值128、标准差0。只看均值可能遗漏明显的双峰分布。

参考输出先列pixels/mean/stddev，均值与标准差都以原始0..255强度计算，显示3位小数。后面11行分箱先将每个像素转换为0..100亮度百分比，采用四舍五入整数`(x*100+127)/255`，再复用第4题的十位区间和100独立箱。例子0s=2、100=2，其余0。

百分比舍入会丢精度，不能把这11箱当成OpenCV的256箱灰度直方图；它用于理解容器和区间映射。像素强度标准差不是噪声强度的充分证明，也不代表物理亮度已标定。

## WSL / Linux

```bash
cd 仓库根目录
python3 tools/wsl-study.py run cpp/主教材/章节学习/第05章 集合类/brightness-example.cpp --input cpp/主教材/章节学习/第05章 集合类/brightness-input.txt
```

结合Shell练习检查原始数据，以下命令只读：

```bash
sed '1d' cpp/主教材/章节学习/第05章 集合类/brightness-input.txt | sort -n | uniq -c
sed '1d' cpp/主教材/章节学习/第05章 集合类/brightness-input.txt | wc -l
```

第一个命令应显示0和255各2次，第二个应为4。首行是声明数量，要排除；wc -l数换行，通用数据若末行没有LF不能把它直接等同于记录数。真正的C++解析还需检查声明数量与有效记录一致。
