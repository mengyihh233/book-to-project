# 第5章 · 习题5：hist.h通用直方图库与多文件编译

> **要干什么：** hist.h通用直方图库与多文件编译。

## 1 · 题目是什么

第1行minimum maximum width三个整数，范围两端都包含、width为正，最多200个箱；第2行元素数0..10000，后续每行一个范围内int32值。输出每箱low..high: 加一个空格及星号，最后一箱截断到maximum。可选择任意int32最小/最大值，只要箱数合规；支持空数据、负范围和单点范围。公共API见hist.h，控制台格式是本区约定。
格式与资源上限是本区教学约定。使用C++17标准库与受限IntGrid适配原书集合；不是Stanford完整库。按行协议支持LF/CRLF；数值必须整行/整行列合法，缺行、多行、尾部垃圾或越界退出2，标准输出（cout）为空；合法输入退出0。
本题是多文件库练习：给定work.cpp调用框架，请实现我的作答/hist.h与我的作答/hist.cpp。选根目录work.cpp进行编译、运行、作答检查；不要选没有main的hist.cpp。构建器给work.cpp只链接我的作答/hist.cpp，参考/tests才链接根目录hist.cpp，避免无意带入答案。
矩阵行列与图像坐标实操。tests.cpp检查参考接口，不会完成个人work。输出空白保留，不额外打印输入提示到stdout。

## 2 · 实现什么

整个 `work.cpp` 由你写：读入第 1 段要求的数据，算出结果，按第 5 段的格式输出；`main` 也要自己写。

## 3 · 写在哪里

**写在这里**：[work.cpp](work.cpp)。**检查**：保存后运行任务“本题：检查作答”。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 41 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
