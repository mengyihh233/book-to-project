# 第5章 · 习题4：0到100分的文字直方图

> **要干什么：** 0到100分的文字直方图。

## 1 · 题目是什么

输入第1行分数个数0..10000，后续每行一个0..100整数。输出11行，标签字段右对齐宽4，再跟:和一个空格，再按频数打印星号。0s到90s分别代表十个区间，100单独一行；负数、大于100或小数均拒绝。空集合输出全零直方图。
原书使用Stanford Vector<T>；本区明确适配为C++17 std::vector<T>，保留题目行为，不声称装好了Stanford整套集合库。函数签名使用std::vector，见lesson.h。ASCII正文，每组/总记录按上述上限；数值行允许首尾空白，拒绝非有限、超范围、缺行、多余行与尾部垃圾，失败退出2且标准输出（cout）为空。第1题每行最多10000字节。
第2/3题按标量浮点容差比较，第1/4题保留输出空白逐字符比较。tests.cpp只检查参考接口，固定样例不替代自己的边界测试，工具不会修改学习完成状态。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
std::array<std::size_t,11> histogram(const std::vector<int>& scores);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `std::array<std::size_t,11> histogram(const std::vector<int>& scores)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
0
```

期望输出：

```text
  0s: 
 10s: 
 20s: 
 30s: 
 40s: 
 50s: 
 60s: 
 70s: 
 80s: 
 90s: 
 100: 
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 14 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
