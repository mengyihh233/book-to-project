# 第5章 · 习题9：检查已完成数独的行列与九宫格

> **要干什么：** 检查已完成数独的行列与九宫格。

## 1 · 题目是什么

输入首行rows cols，随后每行一行整数矩阵。必须为9×9，否则退出2；单元须为int32，完整读取后检查是否恰好由1..9组成且每行、每列、每个3×3宫内不重复，输出true/false。0、负数、10等是无效解，返回false；本题只检查完成的解，不求解空白数独。
本区以受限IntGrid替代Stanford Grid；第10题原书Grid<bool>用0/1 IntGrid显式适配。尺寸、输入格式和错误码是教学约定。支持LF/CRLF；缺行、多行、尾部垃圾、非整数或维度越界退出2且标准输出（cout）为空。空形状规则按上述题目约定，不自动把空网格当数独。
输出严格比较。tests.cpp只检查参考接口，不自动标记个人学习完成。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
bool checkSudokuSolution(const IntGrid& puzzle);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `bool checkSudokuSolution(const IntGrid& puzzle)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 50 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
