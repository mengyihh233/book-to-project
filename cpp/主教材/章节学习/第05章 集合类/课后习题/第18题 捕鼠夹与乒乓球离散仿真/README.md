# 第5章习题18：捕鼠夹与乒乓球离散仿真

> **要干什么：** 捕鼠夹与乒乓球离散仿真。

## 1 · 题目是什么

原书25×25个位置，每个首次触发释放2球，初始空中1球。每轮全部旧球落下，然后新球进入下一轮，直到空中为0。统计轮数、触发百分比、空中球峰值。本区增加总落地数用于守恒检查。
两种教学输入：首行trace side，随后每轮一行落点编号，数量必须恰等于本轮空中球数；或首行random side seed，自动生成所有落点且没有后续行。side为1..25，原书规模用25；seed为0..4294967295。位置按行编号0..side²−1，允许重复。固定种子和小网格是教学适配，随机发生器及局限见推导。
输出第一行rounds、triggered、peak、landings；第二行percent保留六位小数。结束后不接受多余行。LF/CRLF均可，最后一行可无换行；缺行、额外落点、越界、格式错误退出2，标准输出（cout）为空。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

按完整输出逐字比较；前后空格、空行与最后换行都参与检查。

输入样例：

```text
trace 1
0
0 0
```

期望输出：

```text
rounds=2 triggered=1 peak=2 landings=3
percent=100.000000
```
