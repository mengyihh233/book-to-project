# 第5章 · 习题11：保持行优先顺序的Grid reshape

> **要干什么：** 保持行优先顺序的Grid reshape。

## 1 · 题目是什么

输入首行旧rows cols（0..100），随后旧矩阵逐行数据，最后一行newRows newCols（0..100）。按行优先序保留前min(旧容量,新容量)个值，变小丢弃尾部，变大在尾部补0。输出新形状及逐行矩阵；任一维为0时不读取/输出数据行，仍保留形状。它与清空数据的resize、把行列对换的transpose不同。
本区以受限IntGrid替代Stanford Grid；第10题原书Grid<bool>用0/1 IntGrid显式适配。尺寸、输入格式和错误码是教学约定。支持LF/CRLF；缺行、多行、尾部垃圾、非整数或维度越界退出2且标准输出（cout）为空。空形状规则按上述题目约定，不自动把空网格当数独。
输出严格比较。tests.cpp只检查参考接口，不自动标记个人学习完成。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
void reshape(IntGrid& grid, int newRows, int newCols);
```
