# 解析：查找、分词与信息损失

用字母→码Map编码；遍历表生成码→字母Map。编码遇到ASCII字母才处理；解码逐字节收集点和连字符，遇到空格/制表符提交token，末尾再提交一次。连续间隔产生的空token跳过。查询反向Map用find，找不到要报错，不能悄悄插入默认值。

input.txt的输出：

```text
... --- ...
SOS
.- -...
AB
```

`decode(encode(s))`只能还原大写ASCII字母序列，不能恢复原句的大小写、词间空格或标点。`.x-`忽略x后为A，但斜线不会自动变成空格。只支持26个字母，所以`.....`在本题中无效。

会话先验证再输出：前一行有效、后一行无效时，整个调用退出2，stdout为空。空行是真正的空字符串，带空格的一行不是结束符。EOF也可结束。实现与原书交互方式的适配和全部限制见README。
