# 第5章习题19：摩斯码与双向Map

> **要干什么：** 摩斯码与双向Map。

## 1 · 题目是什么

按每行首字符决定翻译方向：ASCII字母开头编码，点或连字符开头解码，空行结束；EOF也正常结束。不提前去掉首字符前的空格。只处理原书26个字母，忽略其他字符，编码统一大写、码之间一个空格；解码按空格/制表符分隔，输出连续大写字母。其他字符被忽略，不创造新分隔；空行后内容不再处理。
本区增加明确的错误处理：未知码、无法判断方向、超限退出2，stdout为空；先缓冲整个会话再输出，没有交互提示。每行最多10000字节、最多1000条非空输入、正文总量最多1MiB。LF/CRLF均可，最后一行可无换行。这些限制与批量输出是教学协议，不是原书对交互界面的额外要求。
morse_table.h仅提供字母表，可在自己的work中使用。不要包含lesson.h代替作答。先手算input.txt，再写work.cpp并记notes.md，最后看解析和参考。答案通过不表示个人已完成。
