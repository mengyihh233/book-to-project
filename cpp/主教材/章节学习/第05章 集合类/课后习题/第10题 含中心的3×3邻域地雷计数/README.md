# 第5章 · 习题10：含中心的3×3邻域地雷计数

> **要干什么：** 含中心的3×3邻域地雷计数。

## 1 · 题目是什么

输入首行rows cols（0..100），随后逐行输入0/1网格，1代表地雷。输出首行同样形状，再输出每个格子周围3×3区域的地雷总数，越界位置忽略；按原书特别要求，中心格自身也包含在区域内。全1的3×3网格中，中心9、边6、角4。非0/1单元退出2。
本区以受限IntGrid替代Stanford Grid；第10题原书Grid<bool>用0/1 IntGrid显式适配。尺寸、输入格式和错误码是教学约定。支持LF/CRLF；缺行、多行、尾部垃圾、非整数或维度越界退出2且标准输出（cout）为空。空形状规则按上述题目约定，不自动把空网格当数独。
输出严格比较。tests.cpp只检查参考接口，不自动标记个人学习完成。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
void fixCounts(const IntGrid& mines, IntGrid& counts);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `void fixCounts(const IntGrid& mines, IntGrid& counts)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

保留前后空白字符，只忽略一个最后的换行；内部空格、行序不能随意改。

输入样例：

```text
0 0
```

期望输出：

```text
0 0
```
