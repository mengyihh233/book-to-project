# 第5章习题15：旋转栈顶n个元素

> **要干什么：** 旋转栈顶n个元素。

## 1 · 题目是什么

第一行是ASCII可打印字符（最多10000字节），从栈底写到栈顶，空格也占一个元素。第二行n k，均非负，n不能超过栈大小，k不超过int64最大值。只旋转栈顶n个，使原栈顶元素向栈底方向循环移动k次。n=0定义为空操作。输出旋转后栈底到栈顶的整行。
本区用std::stack/std::queue适配原书Stanford Stack/Queue；函数接口名称按原书保留，输入限制、错误码和文本协议是教学约定。LF/CRLF按行读取；格式错误退出2且标准输出（cout）为空，不把格式错误当作合法false。文本换行规范化为LF。

提示：用原书ABCD（D在顶）先算roll(4,1)=DABC、roll(3,2)=ACDB、roll(2,4)=ABCD。然后才写辅助容器。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
void roll(std::stack<char>& values, int n, long long k);
```

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `void roll(std::stack<char>& values, int n, long long k)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

按完整输出逐字比较；前后空格、空行与最后换行都参与检查。

输入样例：

```text
ABCD
4 1
```

期望输出：

```text
DABC
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 23 组样例，标准输出和退出码都逐字比对。

2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
