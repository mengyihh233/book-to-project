# 第5章习题14：检查三类括号是否匹配

> **要干什么：** 检查三类括号是否匹配。

## 1 · 题目是什么

输入恰好一行文本（最多100000字节），只检查()、[]、{}，其他字节忽略。输出true或false。空文本行匹配；完全缺失输入属于格式错误。
本区用std::stack/std::queue适配原书Stanford Stack/Queue；函数接口名称按原书保留，输入限制、错误码和文本协议是教学约定。LF/CRLF按行读取；格式错误退出2且标准输出（cout）为空，不把格式错误当作合法false。文本换行规范化为LF。
在学习区根目录检查：
WSL终端：
运行自己的输入：python tools/study.py run cpp/主教材/章节学习/第05章 集合类/课后习题/第14题 检查三类括号是否匹配/work.cpp --input cpp/主教材/章节学习/第05章 集合类/课后习题/第14题 检查三类括号是否匹配/input.txt；WSL改用python3 tools/wsl-study.py run。网页VS Code与电脑共用这份文件，详见联合学习。
提示：每遇左括号就入栈；遇右括号时只与栈顶比较。先用([)]证明数量相等还不够。

## 2 · 实现什么

要实现的函数接口（不含函数体）：

```cpp
bool bracketsMatch(const std::string& text);
```

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `bool bracketsMatch(const std::string& text)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

成功返回0。登记的非法输入通常要求返回2、标准输出（cout）为空，错误说明写到标准错误（cerr）；各题原约定优先。不要输出“请输入”等额外提示。

按完整输出逐字比较；前后空格、空行与最后换行都参与检查。

输入样例：

```text
abc
```

期望输出：

```text
true
```

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 两处是同一个工具，比对本题登记的 20 组样例，标准输出和退出码都逐字比对。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。自动比较登记的输入、输出与退出码；只检查自己的作答。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。

## 7 · 做完的标准

页面显示“登记样例全部通过”，并且你能自己再造两组输入验证结果。
