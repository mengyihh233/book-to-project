# 第5章习题16：各自队列与最短队列选择

> **要干什么：** 各自队列与最短队列选择。

## 1 · 题目是什么

每个收银员一条等待队列；新顾客选择等待人数最少者，并列选小编号，之后不换队。服务中的人不计队长。
原书使用随机到达与服务时长；本区适配为固定轨迹，以便两题使用同一批顾客。首行T C：仿真T秒（0..10000）、C个收银员（1..32）。随后恰好T行，每行0表示无人到达，或1 S表示到达一人、服务时长S秒（1..10000）。从t=0开始，每秒最多一人，顾客按到达顺序编号。没有随机种子参数。
每秒先入队，再依次处理收银员：若本秒原先忙，则剩余时长减1；否则才从队列接人并设置时长。减到0的这一秒只算完成，下秒才接下一位。这是图5-5的if/else-if顺序。T秒结束就停止，不自动排空。
输出arrived/started/finished/waiting/busy，随后累计total_wait与queue_area，以及六位小数的mean_wait/mean_queue。started统计开始服务数；finished统计真正完成数。等待均值只含已开始顾客；等待人数不含服务中顾客；分母0时展示0。
Stanford Vector/Queue适配为std::vector/std::queue。queue_trace.h提供读取、数据结构和打印，不含策略算法，可复用。输入协议与限制是教学约定；错误格式、缺行、多行、非法范围退出2，stdout为空；按行兼容LF/CRLF。
