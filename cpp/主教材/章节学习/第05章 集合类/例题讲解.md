# 第5章：先理解集合，再记接口

[正文PDF148页](../../../../books/cpp-roberts.pdf#page=148) · [原书1—19题](课后习题/README.md)

本章集合是存放一组值的抽象数据类型，不只指Set；包含Vector、Grid、Stack、Queue、Map、Set等。选择容器先问：要按下标访问、按先进先出处理、按键查值，还是去重？不能因为名字相似就混用。

## 本学习区的明确适配

原书接口属于Stanford库，本区第1—4题使用C++17标准库std::vector完成相同任务，不引入一个假的万能vector.h，也不声称安装了Stanford全部类。

| 原书Vector概念 | 标准库写法 | 易错点 |
|---|---|---|
| Vector<int> | std::vector<int>，头文件<vector> | 大小写不同、命名空间不同 |
| add(x) | push_back(x) | 只在末尾添加，不代表插入任意位置 |
| get(i)/set(i,x) | at(i)/at(i)=x | at检查边界，operator[]通常不检查 |
| insert(i,x) | insert(begin()+i,x) | 标准库传迭代器，不是直接传整数下标 |
| remove(i) | erase(begin()+i) | 删除后后续元素前移，旧迭代器可能失效 |
| size()/isEmpty() | size()/empty() | size是无符号类型，避免size()-1在空容器下溢 |

预留capacity不等于已有size；reserve(10)后仍不能写v[0]。初学先用push_back、at和范围for，理解边界后再优化。

## 从第4章接过来

第1题把一行一元素的流读成容器，空行表示组边界；再次调用应替换旧组。第2/3题分析容器里的数据，第4题把分布显示出来。先写出空组、EOF、非法元素和100分边界的预期，避免“看起来有星号”就认为正确。

平均值和标准差描述不同方面。总体标准差的除数n由原书题目给定；样本估计常用n−1，是另一个问题。浮点输入要拒绝尾部垃圾和非有限值；输出17位有效数字主要用于往返和验收，不要求报告给用户时总显示这么多位。

## 机器视觉实操连接

用一组帧的亮度/曝光作为vector<double>，比较两个分布的均值、总体标准差及分箱。两组均值相同也可能分布完全不同，例如全是50和一半0一半100。先用自造数值完成，再接入OpenCV读图；不要直接把有符号char字节当成像素强度。
