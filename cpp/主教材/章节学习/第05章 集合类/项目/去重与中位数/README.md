# 第5章 项目：去重与中位数

> **要干什么：** 读一批整数，去重、排序，输出不同值的个数、中位数、最小、最大。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入：

| 行 | 内容 |
| --- | --- |
| 第 1 行 | 整数 `N`（1 ≤ N ≤ 100000） |
| 之后 | N 个整数，可以分多行，范围 -10⁹ 到 10⁹ |

输出四行：

```text
不同 4
中位数 2.5
最小 1
最大 9
```

- `不同` = **去重后**的元素个数；
- `中位数` = 去重并排序后的中位数，**保留 1 位小数**：
  - 个数为奇数 → 中间那个；
  - 个数为偶数 → 中间两个的**平均值**；
- `最小` / `最大` 是整数，取去重后的值（和不去重结果一样）。

## 2 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| `N` ≤ 0 或 > 100000 | 往 `stderr` 说明原因，**返回 2**，`stdout` 为空 |
| 实际给的整数少于 N 个 | 返回 2（不能拿默认值凑） |
| 整数多于 N 个 | 忽略多余的 |
| 全部相同（如 `5 5 5`） | 不同 1，中位数 5.0 |
| 只有一个元素 | 不同 1，中位数就是它（带 `.0`） |

## 3 · 验收清单

- [ ] `5` + `3 1 3 2 9` → 不同 4，中位数 2.5，最小 1，最大 9
- [ ] `1` + `7` → 不同 1，中位数 7.0
- [ ] `4` + `5 5 5 5` → 不同 1，中位数 5.0
- [ ] `2` + `1 2` → 中位数 1.5
- [ ] `3` + `-5 -1 -3` → 排序后 -5 -3 -1，中位数 -3.0
- [ ] `0` → 返回 2，`stdout` 为空
- [ ] `3` + 只有两个数 → 返回 2
- [ ] 中位数是 `2.5` 不是 `2.50`，也不是 `2`
