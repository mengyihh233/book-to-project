# 第13章 · 习题4：编辑器缓冲区

> **要干什么：** 实现一个带光标的文本缓冲区：插入、前后移动、删除、按位置打印。

## 1 · 题目是什么

- 第一行 `n`（0 ≤ n ≤ 200）条命令，命令逐行给出：
  - `insert <字符>`：在**光标前**插入该字符，光标右移一位；
  - `forward` / `backward`：光标右/左移一位，到头就不动；
  - `delete`：删除**光标前**的一个字符并把光标左移；光标在开头时什么都不做；
  - `print`：输出缓冲区内容，并在光标处插一个 `|`；
  - `length`：输出当前字符数。
- 只有 `print` 和 `length` 有输出，其余命令不打印。

原书习题 4（[PDF 第 425 页](../../../../../../books/cpp-roberts.pdf#page=425)）。**这里是题意改写与输入输出约定**：原书用EditorBuffer 的数组表示与六个编辑命令，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

实现 `EditorBuffer` 的 `insert`、`forward`、`backward`、`deleteCharacter`、`length`、`text`、`cursor`
（内部用一个 `std::string` + 光标下标就够），`main` 的命令循环已给。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（EditorBuffer 的成员函数）和 `BEGIN 2` … `END 2`（命令循环与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；补完把区里的占位注释（`// @@N@@`）或占位 `throw` 删掉。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- `print` 输出一行：文本中光标处有 `|`，例如空缓冲区是 `|`。
- `length` 输出一行整数。
- 未知命令、缺少参数：返回 2，**stdout 为空**。

输入样例：

```text
4
insert a
insert b
print
length
```

期望输出：

```text
ab|
2
```
