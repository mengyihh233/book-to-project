# 第13章 项目：位统计

> **要干什么：** 对一组非负整数做位运算统计。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入：

```text
3
1 2 4
```

- 第一行 `n`（1 ≤ n ≤ 100000）；
- 第二行 n 个**非负整数**（0 ≤ x ≤ 2147483647）。

输出四行：

```text
按位或 7
按位与 0
1的个数 3
最高位 2
```

| 项 | 含义 |
| --- | --- |
| `按位或` | 所有数做按位或 |
| `按位与` | 所有数做按位与 |
| `1的个数` | 所有数的二进制表示中 1 的总个数 |
| `最高位` | **最大值**的最高位位置，从 0 开始数；最大值为 0 时输出 `-1` |

## 2 · 关键要求

**必须用位运算实现**，`1的个数` 不许用 `to_string` 转二进制再数：

```cpp
while (value) { value &= value - 1; ++count; }   // 每次消掉最低位的 1
```

`最高位` 也不许用 `<cmath>` 的 `log2`（浮点精度会在 2 的幂附近出错）。

## 3 · 边界

| 情况 | 要求 |
| --- | --- |
| `n` < 1 或 > 100000 | 返回 2 |
| 出现负数 | 返回 2（本题只接受非负） |
| 全部为 0 | 按位或 0，按位与 0，1的个数 0，最高位 **-1** |
| 只有 1 个数 | 按位或 = 按位与 = 它本身 |

## 4 · 验收清单

- [ ] `3` + `1 2 4` → 或 7，与 0，1的个数 3，最高位 2
- [ ] `1` + `0` → 或 0，与 0，1的个数 0，最高位 **-1**
- [ ] `2` + `5 3` → 或 7，与 1，1的个数 4（101 + 011），最高位 2
- [ ] `2` + `8 8` → 或 8，与 8，1的个数 2，最高位 3
- [ ] `3` + `2147483647 0 1` → 或 2147483647，与 0，1的个数 **32**，最高位 30
- [ ] `0` → 返回 2
- [ ] `2` + `-1 5` → 返回 2

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

## 6 · 做完的标准

1. `按位与` 的初始值为什么是全 1（`0xFFFFFFFF`），而不是 0？
2. `value & (value - 1)` 每次消掉的是哪一位？循环几次就是几个 1？
3. `最高位` 从 0 开始数，那 `8` 的最高位是几？`2147483647` 呢？
4. 为什么 `最高位` 不能用 `log2`？举一个会出错的例子。
