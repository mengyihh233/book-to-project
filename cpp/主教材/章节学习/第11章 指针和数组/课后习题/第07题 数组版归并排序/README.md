# 第11章 · 习题7：数组版归并排序

> **要干什么：** 读入 n 个整数，用归并排序（数组 + 下标）升序输出。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 100000），第二行 n 个整数（|值| ≤ 10⁹）。
- 输出排序后的 n 个数，空格分隔，末尾换行。

原书习题 7（[PDF 第 361 页](../../../../../../books/cpp-roberts.pdf#page=361)）。**这里是题意改写与输入输出约定**：原书用把图 10-3 的归并排序从 `vector` 改成数组 + 指针，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `mergeSort(int* data, int left, int right, int* buffer)`：长度 ≤ 1 直接返回；
否则对半递归，再合并到 `buffer`，最后搬回 `data`。`main` 负责读入与输出（缓冲区已给）。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（要实现的函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

2. 跑「检查本题」：本题登记 5 组样例，其中 4 组正常输出、1 组是非法输入（要求退出码 2、stdout 为空）。
3. 通过之后自己再造两组：一组边界、一组非法，确认结果仍然对。

## 5 · 文本格式

- 一行，数之间一个空格，末尾换行。
- n 越界、数字个数不足：返回 2，**stdout 为空**。

输入样例：

```text
5
3 1 4 1 5
```

期望输出：

```text
1 1 3 4 5
```
