# 第11章 · 习题3：任意进制的整数转换

> **要干什么：** 实现带基数的整数转字符串、字符串转整数：支持 2—36 进制，10 以上用大写字母。

## 1 · 题目是什么

- 第一行 `n`（1 ≤ n ≤ 100），接下来 n 行，每行三种形式之一：
  - `to <十进制整数> <基数>`：输出该数在给定进制下的写法；
  - `from <数字串> <基数>`：输出它对应的十进制整数。
- 基数范围 2—36；10 以上依次用 `A`—`Z` 表示 10—35。
- 负数在 `to` 里保留负号，在 `from` 里也允许以 `-` 开头。

原书习题 3（[PDF 第 360 页](../../../../../../books/cpp-roberts.pdf#page=360)）。**这里是题意改写与输入输出约定**：原书用`integerToString` 与 `stringToInteger` 的重载版本（带基数参数），
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写 `intToString(value, base)` 与 `stringToInt(text, base)` 两个函数（声明已给），
`main` 负责读命令并分派。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（要实现的函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每条命令输出一行。
- 基数越界、出现该进制不合法的数字、命令不认识、行不完整：返回 2，**stdout 为空**。

输入样例：

```text
3
to 255 16
to 10 2
from 1F 16
```

期望输出：

```text
FF
1010
31
```
