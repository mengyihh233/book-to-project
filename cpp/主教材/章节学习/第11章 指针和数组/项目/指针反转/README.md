# 第11章 项目：指针反转

> **要干什么：** 用指针把数组原地反转。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入：

```text
5
1 2 3 4 5
```

- 第一行 `n`（1 ≤ n ≤ 100000）；
- 第二行 n 个整数。

输出一行：反转后的序列，**空格分隔，行末换行**。

```text
5 4 3 2 1
```

## 2 · 关键要求

**全程用指针，不许用下标运算符 `a[i]`。** 读入、反转、输出都走 `*p` 和 `p+1`。

自动判分看不出你用没用下标——**但这一章练的就是指针算术，用下标等于没做。**

## 3 · 边界

| 情况 | 要求 |
| --- | --- |
| `n` < 1 或 > 100000 | 返回 2 |
| 数据不足 n 个 | 返回 2 |
| `n = 1` | 原样输出 |
| 有重复元素 | 正常反转，不做去重 |

**必须记得 `delete[]`**：程序结束前释放。泄漏在短程序里看不出来，但这是本章的硬要求。

## 4 · 验收清单

- [ ] `5` + `1 2 3 4 5` → `5 4 3 2 1`
- [ ] `1` + `7` → `7`
- [ ] `4` + `-1 0 1 2` → `2 1 0 -1`
- [ ] `6` + `1 1 2 2 3 3` → `3 3 2 2 1 1`
- [ ] `2` + `10 -10` → `-10 10`
- [ ] `0` → 返回 2
- [ ] `3` + 只有两个数 → 返回 2
- [ ] 输出是 `5 4 3 2 1`，**末尾没有多余空格**

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

末尾多一个空格也会判错。

## 6 · 做完的标准

1. 你的反转用了几个指针？`first < last` 和 `first != last` 有什么区别？
2. `reverse(data, data + n)` 这种「左闭右开」的约定，为什么比传 n 更好？
3. 如果 n 是奇数，中间那个元素会被交换几次？
4. `delete[]` 漏了会怎样？在这道题里看得出来吗？
