# 第9章 项目：N 皇后解数

> **要干什么：** 给定 n，输出 n 皇后问题有多少种摆法。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

输入一个整数 `n`（1 ≤ n ≤ 10），输出一行：

```text
解数 92
```

n 皇后：在 n×n 棋盘上放 n 个皇后，任意两个不同行、不同列、不同斜线。

## 2 · 关键约束

**必须用回溯**：逐行放，放不下就换列，整行都不行就退回上一行。

不许用「枚举所有排列再检查」——n=10 时是 10! = 3628800 种排列，虽然也能跑，
但那不是回溯，剪枝的意义就没了。

## 3 · 边界

| 情况 | 要求 |
| --- | --- |
| `n` < 1 或 > 10 | 返回 2 |
| `n = 2` 或 `n = 3` | **没有解，输出 `解数 0`，返回 0**（这不是错误） |
| `n = 1` | `解数 1` |

**「无解」和「输入非法」是两件事**：前者是合法的 `0`，后者才是返回 2。

## 4 · 验收清单

- [ ] `1` → `解数 1`
- [ ] `4` → `解数 2`
- [ ] `8` → `解数 92`
- [ ] `10` → `解数 724`
- [ ] `2` → `解数 0`（返回 0，不是 2）
- [ ] `0` → 返回 2
- [ ] `11` → 返回 2

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对。

n=10 要在 1 秒内跑完，如果你的程序超时，说明剪枝没做对。

## 6 · 做完的标准

1. 回溯的三步是什么？你的代码里「撤销选择」那一步在哪？
2. 为什么斜线判断是 `abs(列差) == 行差`？
3. 如果不用 `col_` 数组记已放列，而是每次重新扫描棋盘，复杂度会差多少？
4. n=2 和 n=3 为什么一定无解？（能说出理由，不用跑代码）

## 7 · 扩展（可选）

1. 输出**所有**摆法（每行一个 n 位数字串），而不只是数量。
2. 用位运算优化斜线判断（`cols | diag1 | diag2`）。
3. 加一个计数器，输出搜索了多少个节点，比较 n=8 和 n=10 的差距。
