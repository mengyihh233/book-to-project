# 第9章 · 习题4：洪水填充区域大小

> **要干什么：** 读入一张黑白像素图，求从某个白点出发能连成一片的白色像素个数。

## 1 · 题目是什么

- 第一行 `r c`（1 ≤ r,c ≤ 20）；接下来 r 行，每行 c 个字符：`.` 白色、`#` 黑色。
- 最后一行 `sr sc`：起点（从 0 开始）。
- 输出从起点出发、上下左右相连的白色像素总数（含起点）；起点本身是黑色则输出 0。

原书习题 4（[PDF 第 299 页](../../../../../../books/cpp-roberts.pdf#page=299)）。**这里是题意改写与输入输出约定**：原书用用递归把相连的同色区域整片填满（paint bucket），
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

写递归 `flood(grid, seen, r, c, x, y)`：越界、黑点、已访问都返回 0；
否则标记并返回 `1 + 四个方向之和`。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（递归搜索函数）和 `BEGIN 2` … `END 2`（读入与输出）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；写完删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 一行一个整数。
- 行列越界、起点越界、行数不足：返回 2，**stdout 为空**。

输入样例：

```text

...
...
...

```

期望输出：

```text

```
