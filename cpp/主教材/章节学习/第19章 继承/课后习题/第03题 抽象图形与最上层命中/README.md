# 第19章 · 习题3：抽象图形与最上层命中

> **要干什么：** 用抽象基类 + 纯虚函数管住三种图形，再对查询点找出「最上层」那个命中的图形。

## 1 · 题目是什么

输入图形按**从下到上**的顺序给出（后面的盖住前面的），坐标都是整数：

```text
n
rect x y w h          左上角 (x, y)，宽 w 高 h
circle cx cy r        圆心 (cx, cy)，半径 r
tri x1 y1 x2 y2 x3 y3 三个顶点
…
m
px py                 查询点，m 个
```

边界算「包含」：点在矩形边上、圆上、三角形边上都算命中。

对每个查询点输出一行，`#下标` 是它在输入里的位置（从 0 开始）：

```text
(5, 5) -> #2 rect
(20, 20) -> (none)
```

原书习题 3（[PDF 第 604 页](../../../../../../books/cpp-roberts.pdf#page=604)）。**这里是题意改写与输入输出约定**：原书用图 19-5 的 GObject 层次：纯虚函数 `contains` + 习题 5 的 `getElementAt`，
本区改成从标准输入读、标准输出写，方便自动比对；题目的核心要求不变。

## 2 · 实现什么

抽象基类 `Shape`（纯虚 `name()`、纯虚 `contains()`、虚析构）、三个子类的构造与读入、
`main` 的建表都已经给好。你要写两段：

- 三个子类的 `contains`：矩形比边界，圆比 `dx² + dy² <= r²`，三角形用叉积判同侧；
- 查询循环：**从后往前**扫，第一个命中的就是最上层。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` … `END 1`（三个子类的纯虚实现）和 `BEGIN 2` … `END 2`（从后往前找最上层命中）。
头文件、类定义、`main` 骨架都已给出，**只补这两个区**；补完把区里的占位注释（`// @@N@@`）或占位 `throw` 删掉。

保存后运行任务“本题：检查作答”核对。

## 5 · 文本格式

- 每个点一行：`(px, py) -> #下标 类型名`，没有命中写 `(px, py) -> (none)`。
- 宽高或半径不大于 0、三点共线、未知图形类型、n 或 m 越界、读入不完整：返回 2，**stdout 为空**。

输入样例：

```text
2
rect 0 0 10 10
circle 10 10 5
5
5 5
10 10
15 15
0 0
20 20
```

期望输出：

```text
(5, 5) -> #0 rect
(10, 10) -> #1 circle
(15, 15) -> (none)
(0, 0) -> #0 rect
(20, 20) -> (none)
```
