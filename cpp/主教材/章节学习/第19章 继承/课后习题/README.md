# 第19章 · 原书课后习题

| 题目 | 原书题号 | 检查方式 |
|---|---|---|
| [抽象图形与最上层命中](第03题%20抽象图形与最上层命中/README.md) | 习题 3 + 5 | 固定样例比较（9 组） |

原书这两问是画在图形窗口里的，本区没有图形库，所以**保留题目的骨架、去掉画图**：

- 习题 3 的 `virtual bool contains(double x, double y) = 0;` 原样保留，三个子类各写一份；
- 习题 5 的 `getElementAt(x, y)`（返回最上层的图形）改成「从后往前扫，第一个命中的就是」——
  这正是「后面的图形画在上面」的另一种说法。

判分样例覆盖了：点在矩形/圆/三角形的**边上**、点在外面、图形重叠时取最上层、
三角形顶点按顺时针给（叉积法不该受影响）。
