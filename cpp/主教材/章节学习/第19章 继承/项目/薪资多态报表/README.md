# 第19章 项目：薪资多态报表

> **要干什么：** 三种雇员（月薪、时薪、提成）各自算应发工资，统一用基类指针结算并打印报表。
> 这题**不给骨架**，从 `#include` 开始全自己写。README 里是一组示例，**判分用另外 7 组**。

## 1 · 需求

标准输入：

```text
3
S lin 1250000
H mei 1800 170
C zhao 400000 2500000 8
```

| 行 | 内容 |
| --- | --- |
| 第 1 行 | 员工人数 `k`（1 ≤ k ≤ 100000） |
| 接下来 k 行 | `类型 名字 参数...` |

三种类型：

| 类型 | 参数 | 应发工资 |
| --- | --- | --- |
| `S` | 月薪 | 就是月薪 |
| `H` | 时薪 小时数 | 前 160 小时按原价，**超出部分 1.5 倍** |
| `C` | 底薪 销售额 百分比 | 底薪 + 销售额 × 百分比 ÷ 100 |

**所有金额单位都是「分」**（1250000 分 = 12500.00 元）。

输出每个员工一行，最后一行合计：

```text
lin S 12500.00
mei H 3150.00
zhao C 6000.00
合计 21650.00
```

## 2 · 关键要求

1. 写一个基类 `Employee`，至少两个**虚函数**：算工资的 `pay()` 和返回类型字母的 `kind()`。
2. 三种雇员各自 `public` 继承并 `override`，主程序只拿**基类指针**遍历结算。
3. 金额一律用**整型**（`long long`，单位分）。别用 `double` —— 提成和加班都要**整除向下取整**，浮点会给出别的答案。
4. 打印时把分转成 `元.角分`（`109` 分 → `1.09`，`0` 分 → `0.00`）。

> 自动判分看不出你是不是真的用了虚函数：写 `if (type == "S") ... else if ...` 也能过。
> 但这一章练的就是继承和多态，README 第 6 节的问题会戳穿偷懒写法。

## 3 · 规则与边界

| 情况 | 要求 |
| --- | --- |
| 加班 | 小时 ≤ 160 无加成；超出部分 `时薪 × 3 × 超出小时 ÷ 2`，整除向下取整 |
| 提成 | `销售额 × 百分比 ÷ 100`，整除向下取整（250 分 × 5% = 12 分） |
| 小时 = 0 | 合法，应发 0.00 |
| 月薪 = 0 | 合法，应发 0.00 |
| 输出顺序 | **按输入顺序**，不排序 |
| 未知类型（如 `X`） | 返回 2，stdout 为空 |
| 金额 < 0 或 > 10⁹ | 返回 2，stdout 为空 |
| 小时 < 0 或 > 1000 | 返回 2，stdout 为空 |
| 百分比 < 0 或 > 100 | 返回 2，stdout 为空 |
| k < 1 或 k > 100000 | 返回 2，stdout 为空 |

## 4 · 验收清单

- [ ] 上面那组输入 → 三行 + `合计 21650.00`
- [ ] `1` + `C dan 100 250 5` → `dan C 1.12`（250 × 5 ÷ 100 = 12，不是 12.5）
- [ ] `1` + `H eve 100 161` → `eve H 161.50`（多 1 小时按 150 分算）
- [ ] `2` + `S zed 0` 和 `H zero 0 0` → 两行 `0.00`，合计 `0.00`
- [ ] 类型写成 `X` → 返回 2，屏幕无输出
- [ ] 月薪 `-1` → 返回 2，屏幕无输出
- [ ] 人数 `0` → 返回 2，屏幕无输出

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组隐藏输入，逐字比对 `stdout` 与退出码。

小数位必须**正好两位**：`4000.00` 不能写成 `4000` 或 `4000.0`。

## 6 · 做完的标准

1. `pay()` 声明成 `virtual` 之后，`Employee*` 调它和 `Employee` 对象调它有什么区别？
2. 基类的析构函数为什么必须是 `virtual`？不写会漏掉什么？
3. 如果只给 `pay()` 加 `virtual` 而不写 `override`，编译器能帮你抓到签名写错吗？
4. 为什么金额不能直接用 `double`？举一个会算出不同结果的例子。
5. 时薪类型里，如果把 `rate * 3 * overtime / 2` 写成 `rate * 3 * overtime / 2.0`，结果会差多少？
