# 第2章习题13：放射性衰变

> **要干什么：** 从10000个原子开始，每年每个原子有50%概率衰变。只补 survivorsAfterYear，返回一年后的存活数。

## 1 · 题目是什么

原书题干 PDF96页。衰变题在下一页继续。这里提供针对原题的独立教学实现，未照搬原文程序。
输入 seed。固定从10000个原子开始，每年每个尚存原子独立以50%概率衰变，输出 year remaining，包含初始第0年，直到0。初始行、种子和1000年保护上限为教学约定。
先读题目、手算或预测，再在work.cpp补全；做完后再看solution。random_tools.h只提供输入校验和随机工具，不包含题目解法；参考答案是reference.cpp。异常输入写stderr并返回2，正常返回0。

## 2 · 实现什么

只补 `int survivorsAfterYear(int atoms, std::mt19937& engine)` 的函数体，返回一年后仍存活的原子数。

给定 `main` 负责年份循环、初始第0行、数量归零时停止及1000年保护。`halfEvent(engine)` 返回 true 表示该原子衰变。随机引擎与原书概念一致；固定 seed 与映射是本区为复现结果采用的约定。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `int survivorsAfterYear(int atoms, std::mt19937& engine)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 4 · 怎么做

1. 区分两层循环：给定 `main` 管“年”；你补的函数管“一年中的每个原子”。
2. 新建存活计数器，在 `BEGIN 1 / END 1` 内对开始时的 `atoms` 个原子各调用一次 `halfEvent(engine)`，只统计返回 false 的试验。最后返回计数并删除占位 `throw`。
3. 不要直接将数量除以2，也不要在逐个试验时改写循环上界 `atoms`。种子只在 main 初始化一次。
4. 保存、运行后核对 seed=0 的前两行：`0 10000`、`1 4990`；再检查全部样例。随机模拟中相邻两年数量可以相同，但不能增加。
