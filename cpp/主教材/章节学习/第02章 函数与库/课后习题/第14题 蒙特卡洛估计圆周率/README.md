## 4 · 怎么做

1. 用一个整数计数器记录圆内点，循环恰好 `trials` 次。
2. 每次先抽 x，再抽 y：各取一个 `unitReal(engine)`，用 `2*u - 1` 映射到边长为2的正方形内。两个坐标必须分别抽样。
3. 判断 `x*x + y*y < 1` 并更新计数，最后返回数量，删除占位 throw。主程序用 `4.0 * inside / trials` 输出估计值。
4. 种子0应得到 `7937 3.1748`。保存、检查；再换种子观察误差。正方形面积为4、单位圆面积为π，所以圆内比例近似π/4，单次结果不必恰好等于π。
