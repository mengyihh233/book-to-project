# 第2章习题2：引用参数返回英尺与英寸

> **要干什么：** 把米换算成英尺加英寸，用引用参数带回两个结果。

## 1 · 题目是什么

读入非负米数m（0到10^9），用引用参数同时返回整数英尺数feet与剩余英寸inches。1英尺=12英寸，1英寸=0.0254米；feet取完整英尺，余量换算为英寸。输出feet inches两个数值，以空格分隔。本题按相对误差1e-6、绝对误差1e-12比较，不强求固定小数位。

原书位置：PDF 第 94 页。本页是这道题在本区的完整题意，以本页为准。

## 2 · 实现什么

```cpp
void metersToFeetInches(double meters, long long& feet, double& inches);
```

函数声明、`main`、输入检查都已经写好了，**不要重写 main**。

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `void metersToFeetInches(double meters,long long&feet,double&inches)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

## 4 · 怎么做

1. 计算完整英尺数，再将剩余长度换算为英寸。
2. 通过feet、inches两个引用参数将结果带回。
3. 输入超出题目范围时抛出异常。
4. 删掉占位的那句 throw。

## 5 · 文本格式

1. 只往 `cout` 写结果，**不要加“请输入”“结果是”这类提示语**。
2. 正常结束返回 0；输入不合法（如多余数据）时返回 2，`cout` 保持为空，说明写到 `cerr`。
3. 检查时逐字比对标准输出和退出码，所以空格、换行、大小写都要一致。

输入样例：

```text

```

期望输出（就是检查时逐字比对的内容）：

