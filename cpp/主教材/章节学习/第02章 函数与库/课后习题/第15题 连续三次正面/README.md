# 第2章习题15：连续三次正面

> **要干什么：** 只补抛硬币模拟函数，区分总次数与连续正面次数。

## 1 · 题目是什么

原书题干 PDF98页。这里提供针对原题的独立教学实现，未照搬原文程序。
输入 seed。逐行输出HEADS/TAILS，第一次连续3次正面时停止，最后输出TOTAL与次数。以引擎值小于2^31为正面；种子、英文输出和1000000次保护上限为教学约定。
先读题目并预测结果，再在work.cpp补全；做完再看solution。random_tools.h只提供输入校验和随机工具，不包含题目解法；参考答案是reference.cpp。异常输入写stderr并返回2，正常返回0。

## 4 · 怎么做

1. 先在纸上跟踪 `HEADS、HEADS、TAILS、HEADS`：总次数为4，但末尾连续正面只有1。
2. 在 `BEGIN 1 / END 1` 新建总次数与连续次数两个变量；只要尚未三连正面，就调用一次 `halfEvent(engine)` 并输出本次结果。
3. 正面让连续次数增加，反面打断连续记录；每次抛掷都使总次数增加。不要把“累计三个正面”当成停止条件。
4. 参考已有主程序的异常风格，在1000000次保护上限处抛 `std::runtime_error`；完成后返回总次数并删除占位 throw。
5. 种子0最后三次应为 HEADS，最终行应为 `TOTAL 14`。保存后检查全部样例，再换种子观察总次数如何变化。
