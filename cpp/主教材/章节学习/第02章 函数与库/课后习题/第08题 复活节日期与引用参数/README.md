# 第2章习题8：复活节日期与引用参数

> **要干什么：** 用一个 void 函数，通过两个引用参数返回月份和日期；输入和主程序已给定。

## 1 · 题目是什么

原书题干与算法（PDF95页）。参考程序按图2-18实现原题接口void findEaster(int year, string& month, int& day)，这里用std::string。正文是自主教学讲解，原书题干请打开PDF阅读。
输入一个1700..1899的整数年份，输出March day或April day；例如1818输出March 22。范围、英文月份、空格输出与失败退出码2为本区验收契约。原书的简化算法不能无条件用于2026年。

- work.cpp：自己的作答，不包含参考头文件；notes.md：复盘。

## 4 · 怎么做

1. 先检查 `year` 属于1700..1899；范围外抛出 `std::out_of_range`，由 main 输出错误并返回2。
2. 按原题简化算法计算整数：`a = year % 19`、`b = year % 4`、`c = year % 7`；`d = (19*a + 23) % 30`；`e = (2*b + 4*c + 6*d + (year < 1800 ? 3 : 4)) % 7`。
3. 若 `d + e <= 9`，月份为 March，日期为 `22 + d + e`；否则为 April，日期为 `d + e - 9`。把结果赋给引用参数，删除占位 throw。
4. 手算1818年应得到 March 22。保存后运行、检查；该简化算法不扩展到当前年份。思考：去掉参数中的 `&`，为什么 main 里的值不会得到修改？
