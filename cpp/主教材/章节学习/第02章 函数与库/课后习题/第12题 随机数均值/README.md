# 第2章习题12：随机数均值

> **要干什么：** 输入 count seed，调用 unitReal(engine) 抽样 count 次并返回均值。只补 sampleMean 函数体。

## 1 · 题目是什么

原书题干 PDF96页。这里提供针对原题的独立教学实现，未照搬原文程序。
输入 count seed，count 为1..1000000，seed 为0..4294967295。输出均值（10位小数）。原题让用户指定样本数量；seed、范围与输出精度为可复现实验约定。
先读题目、手算或预测，再在work.cpp补全；做完后再看solution。random_tools.h只提供输入校验和随机工具，不包含题目解法；参考答案是reference.cpp。异常输入写stderr并返回2，正常返回0。

## 2 · 实现什么

只补 `double sampleMean(std::uint32_t count, std::mt19937& engine)` 的函数体，返回 count 个随机数的均值。

给定部分负责：输入范围、随机引擎初始化、10位小数输出和非法输入返回2。`random_tools.h` 提供跨平台可复现的随机映射；不要换成 `rand()` 或其他分布器。

## 3 · 写在哪里

**work.cpp** 里的 `BEGIN 1` 到 `END 1` 之间，也就是 `double sampleMean(std::uint32_t count, std::mt19937& engine)` 的函数体。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

保存后运行任务“本题：检查作答”核对。

## 4 · 怎么做

1. 读函数声明：`count` 是抽样次数；`engine` 是同一个随机引擎的引用，函数返回 `double`。
2. 在 `BEGIN 1 / END 1` 内用浮点累加器和循环，每次调用一次 `unitReal(engine)`；返回总和除以次数。删除占位 `throw`。
3. 用 `1 0` 验证一次抽样；用 `1000 0` 观察均值接近0.5。相同 seed 与 count 结果应相同，但有限次抽样不保证恰好0.5。
4. 保存后运行、检查。`main` 已处理输入、异常和输出精度，无需改写；不要把样例值写死。
