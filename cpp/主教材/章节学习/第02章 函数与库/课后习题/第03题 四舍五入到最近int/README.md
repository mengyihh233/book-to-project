# 第2章习题3：四舍五入到最近int

> **要干什么：** 把小数四舍五入到最近的整数。

## 1 · 题目是什么

实现roundToNearestInt函数，读入一个有限实数，四舍五入到最近的int；正负半整数均向远离零方向取整，例如2.5→3、-2.5→-3。结果不能超出int范围。main读入、调用函数并输出一个整数。

原书位置：PDF 第 94 页。本页是这道题在本区的完整题意，以本页为准。

## 4 · 怎么做

1. 分别考虑正数与负数恰好落在0.5的情况。
2. 返回最近int。
3. 先确认舍入后的值没有超出int范围。
4. 删掉占位的那句 throw。

## 5 · 文本格式

1. 只往 `cout` 写结果，**不要加“请输入”“结果是”这类提示语**。

3. 检查时逐字比对标准输出和退出码，所以空格、换行、大小写都要一致。

输入样例：

```text

```

期望输出（就是检查时逐字比对的内容）：

