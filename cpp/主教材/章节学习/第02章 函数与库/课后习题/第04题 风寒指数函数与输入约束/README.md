# 第2章习题4：风寒指数函数与输入约束

> **要干什么：** 按公式算风寒指数，并挡住不合理的温度和风速。

## 1 · 题目是什么

实现windChill(t,v)。输入两个有限数：华氏温度t和英里/小时风速v。t≤40且v≥0；v=0时结果为t，其余用35.74+0.6215t−35.75×v^0.16+0.4275t×v^0.16计算体感温度。域外输入或非有限结果报错。输出一个数值。

原书位置：PDF 第 94 页。本页是这道题在本区的完整题意，以本页为准。

double windChill(double t, double v);

## 4 · 怎么做

1. 先处理无风和温度/风速的合法范围。
2. 按题目给出的公式计算。
3. 检查最终数值是否有限。
4. 删掉占位的那句 throw。

## 5 · 文本格式

1. 只往 `cout` 写结果，**不要加“请输入”“结果是”这类提示语**。
2. 正常结束返回 0；输入不合法（如多余数据）时返回 2，`cout` 保持为空，说明写到 `cerr`。
3. 检查时逐字比对标准输出和退出码，所以空格、换行、大小写都要一致。

输入样例：

```text
40 0
```

期望输出（就是检查时逐字比对的内容）：

```text
40
```
