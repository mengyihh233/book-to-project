# 第2章习题7：逐次逼近平方根

> **要干什么：** 不用 sqrt，用反复逼近算出平方根。

## 1 · 题目是什么

实现iterativeSqrt(x)，读入一个非负有限数x，不调用sqrt，通过迭代逼近平方根。x=0时结果为0；正数可从猜测值g出发，用(g+x/g)/2改进，设置合理停止条件。main调用函数并输出一个数值；负数和非有限输入报错。

## 4 · 怎么做

1. 单独处理x=0与非法负数。
2. 为正数选择初始猜测。
3. 反复改进猜测值并设置停止条件。
4. 不用sqrt直接求解。
5. 删掉占位的那句 throw。
