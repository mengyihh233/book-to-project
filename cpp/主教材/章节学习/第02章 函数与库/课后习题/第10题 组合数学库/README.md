# 第2章习题10：组合数学库

> **要干什么：** 补全一个有两个函数的小型数学库，再用给定主程序调用它。

## 1 · 题目是什么

计算从 n 个不同对象中取 k 个的排列数 P(n, k) 和组合数 C(n, k)。排列考虑顺序，组合不考虑顺序。例如从 5 人中选 2 人，排列数是 20，组合数是 10。

本区约定 `0 ≤ k ≤ n ≤ 1000000`，结果必须能用 `long long` 表示。`k = 0` 时，两种结果都是 1。参数不合法或结果超出范围时抛出异常，由给定主程序报告错误。

原书位置：PDF 第 96 页。本页是题意改写和本区输入输出约定；重点是**头文件声明接口，源文件实现接口，主程序使用接口**。

## 2 · 实现什么

在 `combinatorics` 命名空间里补全两个函数：

| 函数 | 应完成的功能 |
| --- | --- |
| `long long permutations(long long n, long long k)` | 直接连乘 n、n−1、…、n−k+1，得到排列数。可复用第9题的思路。 |
| `long long combinations(long long n, long long k)` | 得到不计顺序的组合数；避免先算阶乘或排列数而使中间值溢出。 |

`main`、读入、调用与输出已经给定，**不用重写 `work.cpp`**。

## 4 · 怎么做

1. 手算 `P(5, 2) = 20`、`C(5, 2) = 10`，理解“是否考虑顺序”。
2. 填 `BEGIN 1`：检查 n、k 的范围，直接连乘；乘法前判断是否会超出 `long long` 上限。
3. 填 `BEGIN 2`：利用 `C(n, k) = C(n, n−k)` 减少计算；逐步约去分母，保证整数计算不发生中间溢出。已提供 `<numeric>`，需要时可用 `std::gcd` 约分。
4. 保存库文件后，直接运行“本题：运行作答”或“本题：检查作答”。工具会自动找到 `work.cpp`，把它和**自己的库实现**一起编译。

## 5 · 文本格式

输入一行 `P n k` 或 `C n k`，分别选择排列或组合；输出一行整数。给定主程序已处理文本格式，不要另加“请输入”等提示语。

输入样例：

```text
P 52 2
```

期望输出：

```text
2652
```

若输入 `C 52 2`，应输出 `1326`。正常返回 0；非法输入或结果溢出时返回 2，`cout` 为空，错误说明写到 `cerr`。
