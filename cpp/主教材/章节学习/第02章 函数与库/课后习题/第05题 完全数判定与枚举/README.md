# 第2章习题5：完全数判定与枚举

> **要干什么：** 判断完全数，并找出 1 到 9999 的全部完全数。

## 1 · 题目是什么

完全数是一个正整数，其所有小于自身的正因子之和等于自身，例如6=1+2+3。实现isPerfect(n)，用循环枚举1到9999中的完全数。main不读输入，按从小到大输出一行，以空格分隔；不要将整组答案写死。

原书位置：PDF 第 95 页。本页是这道题在本区的完整题意，以本页为准。

```cpp
bool isPerfect(int n);
```

## 4 · 怎么做

1. 累计小于n的正因子，判断因子和是否等于n。
2. 正确处理n≤1，返回true或false。
3. 枚举与输出已由main完成。
4. 删掉占位的那句 throw。

## 5 · 文本格式

1. 只往 `cout` 写结果，**不要加“请输入”“结果是”这类提示语**。
2. 正常结束返回 0；输入不合法（如多余数据）时返回 2，`cout` 保持为空，说明写到 `cerr`。
3. 检查时逐字比对标准输出和退出码，所以空格、换行、大小写都要一致。

本题不需要输入。

期望输出（就是检查时逐字比对的内容）：

