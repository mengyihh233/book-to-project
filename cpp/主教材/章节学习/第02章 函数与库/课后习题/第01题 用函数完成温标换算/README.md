# 第2章习题1：用函数完成温标换算

> **要干什么：** 把摄氏温度换算成华氏温度。

## 1 · 题目是什么

读入一个有限摄氏温度C，按F=C×9/5+32计算华氏温度。将换算写成celsiusToFahrenheit函数；main只负责读入、调用、输出。输入只有一个数，不接受多余数据；结果必须有限。

原书位置：PDF 第 94 页。本页是这道题在本区的完整题意，以本页为准。

## 2 · 实现什么

```cpp
double celsiusToFahrenheit(double c);
```

函数声明、`main`、输入检查都已经写好了，**不要重写 main**。

函数声明、输入和 `main` 都已给定，**不要重写 main**。完成后删掉区里的占位 `throw`。

## 4 · 怎么做

1. 将摄氏温度按题目公式换算为华氏温度，返回计算结果。
2. 对非有限结果抛出异常。
3. 不要在换算函数内读入或输出。
4. 删掉占位的那句 throw。

## 5 · 文本格式

1. 只往 `cout` 写结果，**不要加“请输入”“结果是”这类提示语**。
2. 正常结束返回 0；输入不合法（如多余数据）时返回 2，`cout` 保持为空，说明写到 `cerr`。
3. 检查时逐字比对标准输出和退出码，所以空格、换行、大小写都要一致。

输入样例：

```text
0
```

期望输出（就是检查时逐字比对的内容）：

```text
32
```
