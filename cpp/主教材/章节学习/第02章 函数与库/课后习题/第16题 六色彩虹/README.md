# 第2章习题16：六色彩虹

> **要干什么：** 六色彩虹。

## 1 · 题目是什么

在天蓝背景上画红、橙、黄、绿、蓝、紫六条彩虹拱带，内部仍为天空色。为配合本区采样，所有椭圆中心为(0.5W,1.35H)；从外到内编号b=0..6，半轴分别是W×(0.9−0.035b)、H×(1.2−0.055b)。颜色依次为#e53935、#fb8c00、#fdd835、#43a047、#1e88e5、#8e24aa、#87ceeb；最后一个为天空内部。尺寸和配色是本区教学约定。

## 2 · 实现什么

```cpp
void draw(Canvas& canvas);
```

## 3 · 写在哪里

**写在这里**：[work.cpp](work.cpp)的draw(Canvas& canvas)函数体。保留main和canvas.h。

输入W H，各200到1600；空输入默认640×400。程序输出SVG文本；“本题：运行作答”会将它保存为运行结果/work.svg，不会自动弹出窗口。非法输入写cerr并返回2；不输出图形。
