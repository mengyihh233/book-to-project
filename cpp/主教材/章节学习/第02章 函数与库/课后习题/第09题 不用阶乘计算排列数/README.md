# 第2章习题9：不用阶乘计算排列数

> **要干什么：** 不用阶乘，直接连乘算出排列数 P(n, k)。

## 1 · 题目是什么

实现permutations(n,k)，直接计算n×(n−1)×…×(n−k+1)，不先分别计算阶乘。输入两个整数n k，满足0≤k≤n≤1000000；k=0时空乘积为1。main输出结果，若结果超出有符号64位整数范围则报错。

原书位置：PDF 第 96 页。本页是这道题在本区的完整题意，以本页为准。

## 4 · 怎么做

1. 从1开始，循环连乘所需的k个因子。
2. k=0时应返回1。
3. 检查参数范围与long long乘法溢出，不使用阶乘比值。
4. 删掉占位的那句 throw。

## 5 · 文本格式

1. 只往 `cout` 写结果，**不要加“请输入”“结果是”这类提示语**。
2. 正常结束返回 0；输入不合法（如多余数据）时返回 2，`cout` 保持为空，说明写到 `cerr`。
3. 检查时逐字比对标准输出和退出码，所以空格、换行、大小写都要一致。

输入样例：

```text
52 2
```

期望输出（就是检查时逐字比对的内容）：

```text
2652
```
