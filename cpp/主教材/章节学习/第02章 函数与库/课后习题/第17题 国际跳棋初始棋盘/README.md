# 第2章习题17：国际跳棋初始棋盘

> **要干什么：** 国际跳棋初始棋盘。

## 1 · 题目是什么

画居中的8×8棋盘及初始棋子，不实现走棋。棋盘边长S=0.85×min(W,H)，格长=S/8；左上格浅色#fff3e0，深格#6d4c41。上三行的深格放红子#c0392b，下三行深格放黑子#30343b，各12枚；中间两行无子。棋子在格中心，半径为格长的0.36，背景白色。尺寸配色是本区教学约定。

## 2 · 实现什么

```cpp
void draw(Canvas& canvas);
```

## 3 · 写在哪里

**写在这里**：[work.cpp](work.cpp)的draw(Canvas& canvas)函数体。保留main和canvas.h。

> **本题有两份作答：** `work.cpp` 是补写版（给好骨架，只补补全区），`from-scratch.cpp` 是从零写（只有题头）。**两份都能判分**——网页上文件下拉选哪个，就判哪个。


## 4 · 怎么做

按第 1 段的要求先手算一组输入，再写实现，最后按第 6 段检查。

## 5 · 文本格式

输入W H，各200到1600；空输入默认640×400。程序输出SVG文本；“本题：运行作答”会将它保存为运行结果/work.svg，不会自动弹出窗口。非法输入写cerr并返回2；不输出图形。

## 6 · 哪个是判分的

**只有一个：这里的“检查本题”，或 VS Code 任务“本题：检查作答”。** 本题是图形题，这个入口会自动转到图形专项检查。

1. 打开本题自己的作答文件，保存修改。
2. **运行：** Ctrl+Shift+B，或“任务：运行任务” → **本题：运行作答**。这一步不判题。
3. **核对：** “任务：运行任务” → **本题：检查作答**。使用图形专项检查；不会把SVG文本当作普通数值输出。

input.txt是手动测试输入；检查数据不是填答案的位置。无需自己挑选判分脚本，“本题：检查作答”会读取本题规则。
