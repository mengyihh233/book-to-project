# 第2章 项目：成绩分布统计

> **要干什么：** 读一批 0—100 的成绩，算出平均分、及格率、优秀率、最高最低。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

标准输入：

| 行 | 内容 |
| --- | --- |
| 第 1 行 | 一个整数 `N`，学生人数（1 ≤ N ≤ 1000） |
| 之后 N 行 | 每行一个整数成绩，0 ≤ 成绩 ≤ 100 |

输出五行：

```text
平均 72.0
及格率 80.0%
优秀率 20.0%
最高 95
最低 55
```

- 平均分、及格率、优秀率都保留 **1 位小数**；
- 及格 = 成绩 ≥ 60，优秀 = 成绩 ≥ 90；
- 最高、最低是**整数**，不带小数；
- 百分比后面带 `%`，前面不留空格。

## 2 · 强制要求

**必须拆成至少三个函数**，不许把所有逻辑堆在 `main`：

| 函数 | 职责 |
| --- | --- |
| 读入 | 读 N 与 N 个成绩，遇到非法值要能报错 |
| 统计 | 算平均、及格数、优秀数、最高、最低 |
| 输出 | 按上面的格式打印 |

自动判分只看输出，看不出你有没有拆函数——**但拆不拆决定了这题有没有练到东西**。做完自己对照。

## 3 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| `N` ≤ 0 或 > 1000 | 往 `stderr` 说明原因，**返回 2**，`stdout` 为空 |
| 任何成绩 < 0 或 > 100 | 同上 |
| 实际给的成绩行数少于 N | 同上（读不到就是错，不能拿默认值凑） |
| 成绩行数多于 N | 忽略多余的，不报错 |
| 成绩行里有非数字（如 `8a`） | 返回 2 |

## 4 · 验收清单

- [ ] `5` + `90 80 70 60 50` → 平均 70.0，及格率 80.0%，优秀率 20.0%，最高 90，最低 50
- [ ] `1` + `100` → 平均 100.0，及格率 100.0%，优秀率 100.0%
- [ ] `1` + `0` → 平均 0.0，及格率 0.0%，优秀率 0.0%
- [ ] `0` → 返回 2，`stdout` 为空
- [ ] `1` + `101` → 返回 2
- [ ] `3` + 只有两行成绩 → 返回 2
- [ ] 全部 60 分 → 及格率 100.0%，优秀率 0.0%（边界值要算对）
- [ ] 平均分是 `70.0` 而不是 `70` 或 `70.00`

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对输出与退出码。

注意百分比：`80.0%` 不是 `80%`，也不是 `80.0 %`。

## 6 · 做完的标准

1. 平均分为什么会算成整数？怎么避免？
2. 及格率 100% 和 0% 这两个边界，你的代码有没有单独想过？
3. 如果 N 很大（1000），你的读入函数会不会越界？
4. 三个函数之间的数据怎么传？用返回值、引用参数，还是全局变量？各自的问题是什么？
