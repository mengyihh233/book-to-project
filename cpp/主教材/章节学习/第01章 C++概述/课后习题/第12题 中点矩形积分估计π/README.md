# 第1章习题12：中点矩形积分估计π

> **要干什么：** 中点矩形积分估计π。

## 1 · 题目是什么

不读取数据。将半径2的四分之一圆沿x轴分10000个等宽矩形，取每段中点高度求面积，输出π的近似值；绝对误差不超过10^-6。不要把结果再乘4。
