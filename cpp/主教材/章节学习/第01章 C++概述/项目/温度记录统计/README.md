# 第1章 项目：温度记录统计

> **要干什么：** 读一串摄氏温度，算出个数、平均、最高、最低、极差。
> 这题**不给样例、不给骨架**，从 `#include` 开始全自己写。

## 1 · 需求

从标准输入逐行读温度记录：

| 行 | 内容 |
| --- | --- |
| 若干行 | 每行一个摄氏温度（可带小数，可为负） |
| 最后一行 | `END` 三个字母，表示结束 |

输出五行，**每行都是「标签 + 空格 + 数值」**，数值统一保留 **2 位小数**：

```text
个数 3
平均 20.17
最高 21.50
最低 19.00
极差 2.50
```

## 2 · 边界与错误

| 情况 | 要求 |
| --- | --- |
| 第一行就是 `END`（一条记录都没有） | 输出 `个数 0`，其余四行不输出，返回 0 |
| 某行不是数字（如 `abc`、`12a`） | 往 `stderr` 说明原因，**返回 2**，`stdout` 不输出任何内容 |
| 温度低于 -273.15 | 同上，返回 2 |
| 缺少 `END`（输入读到结尾也没见到） | 返回 2 |
| `END` 之后还有内容 | 忽略，不报错 |

**「一条记录都没有」和「输入坏了」是两件事**：前者是合法的空结果，后者必须返回 2。

## 3 · 验收清单

- [ ] `20` / `21.5` / `19` / `END` → 个数 3，平均 20.17，最高 21.50，最低 19.00，极差 2.50
- [ ] 只有一个 `END` → 只输出 `个数 0`，返回 0
- [ ] `-40` / `0` / `100` / `END` → 最低 -40.00，极差 140.00
- [ ] 某行写 `abc` → 返回 2，`stdout` 为空
- [ ] 某行写 `-300` → 返回 2
- [ ] 输入没有 `END` → 返回 2
- [ ] 小数位数固定两位：`20` 要输出成 `20.00`，不是 `20`

## 4 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组看不见的输入，逐字比对 `stdout` 与退出码。

| 会被判错 | 不会被判错 |
| --- | --- |
| 输出多了提示语（`请输入温度：`） | 用 `double` 还是 `long double` |
| 小数位数不固定 | 循环写法不同 |
| 该返回 2 却返回 0 | 变量名不好看 |

## 5 · 做完的标准

1. 为什么「空记录」返回 0，而「读不到 END」返回 2？
2. `cin >> x` 读到 `END` 时会怎样？你怎么判断这一行是数字还是结束标记？
3. 极差为什么不能直接用 `最高 - 最低` 的两个原始值算完再格式化？

## 6 · 扩展（可选）

1. 支持华氏度输入：`20F` / `20C`，内部统一转摄氏。
2. 输出中位数（要先排序）。
3. 支持一次处理多个文件（命令行参数）。

## 7 · 卡住了怎么办

1. 先把「读到 END → 累加 → 输出个数和平均」跑通；
2. 再补最高/最低/极差；
3. 再补 `setprecision` 固定两位；
4. 最后补三种错误判断。
