# 第20章 项目：等差区间与过滤

> **要干什么：** 用一个能 range-for 遍历的区间对象生成等差数列，按策略筛掉不要的数，边遍历边统计。
> 这题**不给骨架**，从 `#include` 开始全自己写。README 里是一组示例，**判分用另外 7 组**。

## 1 · 需求

标准输入（两行）：

```text
10 5 4
odd
```

| 行 | 内容 |
| --- | --- |
| 第 1 行 | `起点 步长 个数` |
| 第 2 行 | 过滤策略，见下表 |

数列是 `起点, 起点+步长, 起点+2×步长, ...`，一共 `个数` 个。策略：

| 策略 | 留下什么 |
| --- | --- |
| `all` | 全都留 |
| `even` | 能被 2 整除（含负数） |
| `odd` | 不能被 2 整除 |
| `pos` | 大于 0 |
| `neg` | 小于 0 |

输出固定 5 行：

```text
序列 15 25
和 40
个数 2
最大 25
最小 15
```

一个都没留下时：

```text
序列
和 0
个数 0
最大 无
最小 无
```

## 2 · 关键要求

1. 写一个 `Range` 类，内部带一个**迭代器类型**（`operator*` / `operator++` / `operator!=`），并提供 `begin()` 与 `end()`，让它能直接用在 range-for 里。
2. 遍历过程中**边生成边判断边统计**，不要把整个数列先塞进 `vector` 再筛。
3. 和可能超过 `int`（见验收清单第 5 条），用 `long long`。

> 自动判分看不出你有没有写迭代器：一个 `for (int i = 0; i < count; ++i)` 也能算对。
> 但这章讲的就是「把迭代方式抽出来」，第 6 节的问题会问到这个设计。

## 3 · 规则与边界

| 情况 | 要求 |
| --- | --- |
| 个数 = 0 | 合法：`序列` 只有标签，和 0、个数 0、最大/最小 `无` |
| 步长为 0 | 合法：`个数` 个相同的起点值 |
| 步长为负 | 合法：数列递减，`最大` 是第一个留下的，`最小` 是最后一个 |
| 负数偶数 | `-14` 是偶数，`-7` 不是（按能否被 2 整除判断） |
| `pos` 遇上 0 | 0 不算正数，会被筛掉 |
| 起点或步长 \|值\| > 10⁹ | 返回 2，stdout 为空 |
| 个数 < 0 或 > 100000 | 返回 2，stdout 为空 |
| 策略不在五种里 | 返回 2，stdout 为空 |
| 少一行策略 | 返回 2，stdout 为空 |

## 4 · 验收清单

- [ ] 上面那组输入 → `序列 15 25` / `和 40` / `个数 2` / `最大 25` / `最小 15`
- [ ] `-5 3 4` + `all` → `序列 -5 -2 1 4`，和 `-2`，最大 `4`，最小 `-5`
- [ ] `0 0 3` + `pos` → 只有 `序列`，和 0，个数 0
- [ ] `0 -7 5` + `neg` → `序列 -7 -14 -21 -28`，和 `-70`，最大 `-7`，最小 `-28`
- [ ] `999999937 1 3` + `all` → 和 `2999999814`（用 `int` 会算错）
- [ ] 策略写 `foo` → 返回 2，屏幕无输出
- [ ] 个数写 `-1` → 返回 2，屏幕无输出

## 5 · 哪个是判分的

**只有一个：这里（或 VS Code）的「检查本题」。** 7 组隐藏输入，逐字比对 `stdout` 与退出码。

`序列` 那行的空格位置也算：标签后面每个值前**一个空格**，末尾不留空格。

## 6 · 做完的标准

1. `begin()` 和 `end()` 返回的是同一个类型吗？`end()` 里的值为什么可以随便定，只要下标对上？
2. range-for 展开之后到底是哪三句话？（提示：`auto it = begin(); it != end(); ++it`）
3. 如果 `Range` 里存 `count` 而不是存 `begin/end` 两个迭代器，`end()` 里为什么还要算一次值？
4. 「内部迭代」（`for_each` 传函数）和「外部迭代」（自己写循环）各自的优缺点是什么？

## 7 · 扩展（可选）

1. 加一个 `Filter` 视图，把「策略」做成可传入的谓词（函数指针或 `std::function`）。
2. 加一个 `take(n)`，只保留前 n 个满足条件的元素。
3. 支持用 `std::accumulate` / `std::count_if` 完成统计，与自己手写的循环对比代码长度。
