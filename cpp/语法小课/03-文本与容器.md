## 字符串、查找与截取

原书联系：[3.1 使用字符串作为抽象数据](../../workbench/chapter.html?chapter=3#page=100)。原书主题的中文提炼，示例与实操为自编配套。

std::string管理文本，size得到长度，find查找位置，substr提取子串。下标从0开始；对空串或越界下标不能盲目访问。

find失败返回std::string::npos，不能直接把它当普通位置使用。字符串相加连接内容，数字加字符串前要显式转成文本。

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "image_007.png";
    auto dot = name.find('.');
    if (dot != std::string::npos) std::cout << name.substr(dot + 1) << '\n';
}
```

**容易混淆：** find找不到返回npos，不是0；下标0表示恰好在开头找到。

数组把一批同类型元素按顺序放在一起，下标从0开始。std::array的长度属于类型并在编译期固定，vector适合运行时增长；先根据数据是否需要增长来选工具。

元素个数为3不意味着能访问下标3，最后有效下标是2。先检查范围，再访问；范围for可以减少手写下标错误。std::array是本小课的现代C++补充，不冒充原书历史接口。

```cpp
#include <iostream>
#include <array>
int main() {
    std::array<int, 3> values{2, 4, 6};
    std::cout << values.size() << " " << values.at(1) << '\n';
}
```

## 数组思维与vector

原书联系：[5.1 Vector 类](../../workbench/chapter.html?chapter=5#page=149)。原书主题的中文提炼，示例与实操为自编配套。

vector是可增长的顺序容器，适合保存一批同类数据。size是元素个数，有效下标到size()-1，空容器没有第0项。

push_back追加元素。范围for适合逐个读；若要修改元素，写auto&而不是复制一个auto值。at在越界时抛出异常，operator[]不负责边界检查。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> values{2, 4};
    values.push_back(6);
    int sum = 0;
    for (int x : values) sum += x;
    std::cout << values.size() << " " << sum << '\n';
}
```

**容易混淆：** reserve预留容量但不增加size；访问不存在的元素前先resize或push_back。

## map、set与键值查找（按需补充）

原书联系：[5.4 Map 类](../../workbench/chapter.html?chapter=5#page=169)。原书主题的中文提炼，示例与实操为自编配套。

map把唯一的键映射到值，set只保存不重复的键。字典计数可用map[key]++，但它会在键缺失时插入默认值。

只想检查存在性时用find，不要用[]悄悄修改容器。迭代器与end比较后，才可以读取对应元素。

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> count;
    ++count["cpp"]; ++count["cpp"];
    std::cout << count["cpp"] << " " << count.size() << '\n';
}
```

**容易混淆：** map的[]在键不存在时会插入；只查询是否存在时先用find。

## 算法、迭代器与lambda（按需补充）

原书联系：[20.1 使用迭代器](../../workbench/chapter.html?chapter=20#page=610)。原书主题的中文提炼，示例与实操为自编配套。

算法通常通过[begin,end)区间访问元素：包含begin，不包含end。sort排序，find查找，count_if统计符合谓词的元素。

lambda可以就近表达一个判断或变换。先理解输入范围和谓词含义，再组合算法；容器改变后要重新核对迭代器有效性。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v{3, 1, 2};
    std::sort(v.begin(), v.end());
    auto n = std::count_if(v.begin(), v.end(), [](int x) { return x >= 2; });
    std::cout << v.front() << " " << n << '\n';
}
```

**容易混淆：** 标准算法通常使用左闭右开区间[begin,end)，end不是最后一个元素。
