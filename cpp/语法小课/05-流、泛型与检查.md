## 词、整行与严格转换

原书联系：[4.2 格式化输入](../../workbench/chapter.html?chapter=4#page=127)。原书主题的中文提炼，示例与实操为自编配套。

>>通常读取一个按空白分隔的词，getline读取整行。混用时要处理先前留下的换行；不要无条件丢弃一整行真实数据。

从字符串解析数字时，不只检查读入成功，还要判断是否允许尾随字符。输入“12abc”不能在要求完整整数时被当作12接受。

```cpp
#include <iostream>
#include <sstream>
#include <string>

int main() {
    std::istringstream in("42 camera ready");
    int id = 0;
    std::string name;
    in >> id;
    std::getline(in >> std::ws, name);
    std::cout << id << ":" << name << '\n';
}
```

**容易混淆：** 格式化读取>>可能留下换行，紧接getline前先明确怎样处理该分隔符。

### 先预测

getline(in >> std::ws, name)中的ws做什么？

1. 跳过前导空白
2. 删除所有行内空格
3. 把输入转成Windows路径

## 文件流与打开失败

原书联系：[4.3 数据文件](../../workbench/chapter.html?chapter=4#page=128)。原书主题的中文提炼，示例与实操为自编配套。

ifstream读文件，ofstream写文件；文件路径相对程序当前工作目录解析，不一定相对源码所在目录。读写前都要检查打开是否成功。

示例只读取当前目录的可选sample.txt；没有文件时输出missing。实际练习在本题工作目录操作，不直接拿私人资料做测试。

```cpp
#include <iostream>
#include <fstream>

int main() {
    std::ifstream in("sample.txt");
    if (!in) std::cout << "missing\n";
    else std::cout << "opened\n";
}
```

**容易混淆：** 相对文件路径以程序当前工作目录为起点，不一定以源文件目录为起点。

## 模板与类型要求（按需补充）

原书联系：[20.1 使用迭代器](../../workbench/chapter.html?chapter=20#page=610)。现代C++补充，链接为关联原书主题，并非原书同名接口。

函数模板把同一结构的操作用于不同类型。模板不是无需约束的万能代码；类型必须支持实现中用到的比较、复制或其他操作。

函数模板定义在main外，template<class T>为这次操作引入类型参数T。调用时编译器根据实参推导T；选用模板前先确认不同类型上的操作语义一致。

```cpp
#include <iostream>

template<class T>
T larger(T a, T b) {
    return a < b ? b : a;
}

int main() {
    std::cout << larger(2, 5) << " " << larger(2.5, 1.5) << '\n';
}
```

**容易混淆：** 模板代码需要在实例化时可见；初学时不要随意拆进普通cpp实现文件。

### 先预测

要让larger用于自定义类型，至少需要什么？

1. 支持实现里用到的比较等操作
2. 类型名一定叫int
3. 必须继承std::vector

## 边界测试与assert（按需补充）

原书联系：[6.3 有理数](../../workbench/chapter.html?chapter=6#page=206)。原书主题的中文提炼，示例与实操为自编配套。

测试要围绕规则挑正常、边界和错误输入。先写预期，再运行核对；只看一条输出不能证明所有输入都正确。

assert适合程序内部不变量和开发期检查；定义NDEBUG可能禁用它，因此不能依赖assert完成输入校验或必须执行的业务动作。

```cpp
#include <iostream>
#include <cassert>

int main() {
    auto square = [](int x) { return x * x; };
    assert(square(0) == 0);
    assert(square(-3) == 9);
    std::cout << "checks passed\n";
}
```

**容易混淆：** assert可能在定义NDEBUG的构建中关闭，不能代替用户输入检查。

### 先预测

可以把必须执行的更新只写在assert里吗？

1. 可以，assert总会运行
2. 不可以，它可能被禁用
3. 只在Windows上可以
