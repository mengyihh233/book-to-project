## 条件、逻辑与边界

原书联系：[1.8.3 if 语句](../../workbench/chapter.html?chapter=1#page=39)。原书主题的中文提炼，示例与实操为自编配套。

if/else根据布尔条件选择分支。&&要求两边同时成立，||要求至少一边成立，!取反；写清区间的左右边界。

&&和||短路求值，可先判断前置条件再访问数据。例如先确认字符串非空，再读首字符。不要把0 <= x <= 10当成数学连写。

```cpp
#include <iostream>

int main() {
    int x = 10;
    if (x >= 0 && x < 10) std::cout << "inside\n";
    else std::cout << "outside\n";
}
```

**容易混淆：** =是赋值，==才是比较；判断区间用0<=x && x<=100，不写0<=x<=100。

判断x处于闭区间[0,10]应写什么？

2. x >= 0 && x <= 10
3. x > 0 || x < 10

### 代码填空

两个边界必须同时成立

```cpp

```

## 循环、累加与停止

原书联系：[1.8.6 for 语句](../../workbench/chapter.html?chapter=1#page=44)。原书主题的中文提炼，示例与实操为自编配套。

for适合明确次数或区间的循环；while适合以条件决定何时停止。累加器先初始化，循环体每次应朝终止条件推进。

区分<和<=，留意循环变量变化。空区间应有合理结果；break退出当前循环，continue跳过本次剩余语句。

```cpp
#include <iostream>

int main() {
    int sum = 0;
    for (int i = 1; i <= 4; ++i) sum += i;
    std::cout << sum << '\n';
}
```

**容易混淆：** 先确定初值、继续条件和更新；循环体内忘记更新可能使循环无法停止。

3. i == 4


## 函数、返回值与作用域

原书联系：[2.3 在 C++ 中定义函数](../../workbench/chapter.html?chapter=2#page=56)。原书主题的中文提炼，示例与实操为自编配套。

函数把一个有明确输入输出的动作封装起来。形参在函数内是局部名字；返回值把结果带给调用方。定义必须在调用前可见，或者提前给出声明。

普通函数定义在main外。返回类型、函数名、形参列表和函数体各司其职；调用时传入实参，并使用返回的结果。

```cpp
#include <iostream>

double square(double x) {
    return x * x;
}

int main() {
    std::cout << square(3) << '\n';
}
```

**容易混淆：** 函数体不能直接嵌套定义另一个普通函数；定义放在外层，调用放在需要的位置。

3. 函数名后加分号就得到结果

## 函数接口：形参、实参与返回值

原书联系：[2.3.1 函数原型](../../workbench/chapter.html?chapter=2#page=56)。原书主题的中文提炼，示例与实操为自编配套。

把函数看成一份约定：调用时提供什么，返回什么，哪些输入不允许。声明让调用方知道函数名、参数和返回类型；定义给出具体实现。形参是函数定义中的名字，实参是调用时交进去的表达式。

先写清接口，再写算法。一个函数尽量完成一件能说清的事；返回结果让调用者继续组合，不把所有函数都写成直接打印。局部形参的名字不会自动变成调用方变量。

```cpp
#include <iostream>
int twice(int value); // 声明
int main() {
    int n = 4;
    std::cout << twice(n + 1) << '\n';
}
int twice(int value) { // 定义
    return value * 2;
}
```

**容易混淆：** 返回与打印是两种操作；实参名字不需要和形参名字相同。

## 值传递、引用与const

原书联系：[2.5 引用参数](../../workbench/chapter.html?chapter=2#page=64)。原书主题的中文提炼，示例与实操为自编配套。

值传递得到参数的副本，修改它不会改变调用方的对象。T&引用能指向原对象，通过引用修改会影响调用方。

只读大对象可用const T&避免复制并表达不修改。引用参数需要明确是否会修改；不要返回指向已结束局部对象的引用。

```cpp
#include <iostream>

void change(int& x) {
    x += 2;
}

int main() {
    int value = 4;
    change(value);
    std::cout << value << '\n';
}
```

**容易混淆：** 按值传参得到副本；只有确实需要修改调用方时，才使用可写引用。

## 重载与默认参数：让调用清楚（按需补充）

原书联系：[2.3.2 重载](../../workbench/chapter.html?chapter=2#page=57)。原书主题的中文提炼，示例与实操为自编配套。

重载允许同名函数通过参数列表区分用途。调用时编译器根据实参选择匹配版本；仅返回类型不同不能构成重载。先确保调用含义清楚，再考虑增加版本。

默认参数在调用方省略末尾实参时使用。通常在调用可见的声明里给出一次默认值，别在声明和定义里重复指定；也别用复杂默认行为让调用者猜测。

```cpp
#include <iostream>
int add(int a, int b = 1) { return a + b; }
double add(double a, double b) { return a + b; }
int main() {
    std::cout << add(4) << " " << add(4, 3) << " "
              << add(1.5, 2.0) << '\n';
}
```

**容易混淆：** 只改返回类型不能形成重载；混用int与double可能导致调用不明确。

3. 随机值
