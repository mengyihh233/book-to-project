## 库、头文件、命名空间与接口

原书联系：[2.2 库](../../workbench/chapter.html?chapter=2#page=54)。原书主题的中文提炼，示例与实操为自编配套。

库提供一组可复用的能力。作为库的使用者，先读清函数的输入、返回值和前提，再调用；暂时不必重写它的内部算法。原书强调使用接口和实现接口是两种视角。

#include把头文件内容带入当前翻译单元，帮助编译器看见声明；std::指出名字属于标准命名空间。头文件不等于所有实现，某些库还需要链接实现。自己定义库时也要区分对外声明与内部实现。

```cpp
#include <iostream>
#include <algorithm>
int main() {
    std::cout << std::max(3, 7) << '\n';
}
```

**容易混淆：** include不是函数调用；头文件可见不等于所需实现已链接。

## 数学库：读懂函数接口再调用

原书联系：[2.2 库](../../workbench/chapter.html?chapter=2#page=54)。原书主题的中文提炼，示例与实操为自编配套。

标准库函数是带有明确约定的工具。先看参数含义、返回类型和有效范围，再用小输入预测；原书的数学函数表就是练习这种阅读方式的好入口。

本节挑sqrt、floor、ceil与abs：重点理解平方根的输入前提，以及负数时向下取整和向上取整的方向。三角函数使用弧度，后续需要时再查，不要求现在背完整张表。

```cpp
#include <iostream>
#include <cmath>
int main() {
    std::cout << std::sqrt(9.0) << " "
              << std::floor(-1.2) << " "
              << std::ceil(-1.2) << '\n';
}
```

**容易混淆：** floor(-1.2)为-2，向0截断则为-1；三角函数通常使用弧度。

## 字符库：分类与大小写

原书联系：[3.3 <cctype> 库](../../workbench/chapter.html?chapter=3#page=108)。原书主题的中文提炼，示例与实操为自编配套。

字符分类函数回答某个字节是否属于一类，例如isdigit检查数字字符，isalpha检查字母；返回非0表示满足条件，不应要求一定等于1。toupper和tolower执行大小写转换。

把普通char传入cctype前转成unsigned char，避免负char带来的未定义行为。这组工具不等同于Unicode文本处理；此处用基本英文、数字和标点练接口。

```cpp
#include <iostream>
#include <cctype>
int main() {
    unsigned char c = 'a';
    bool digit = std::isdigit(static_cast<unsigned char>('7')) != 0;
    std::cout << static_cast<char>(std::toupper(c)) << " " << digit << '\n';
}
```

**容易混淆：** 分类函数以0与非0表示真假，不保证真恰好是1；本课不处理完整Unicode分类。
