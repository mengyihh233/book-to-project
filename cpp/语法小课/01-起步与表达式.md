## 表达式、语句与代码块

原书联系：[1.8 语句](../../workbench/chapter.html?chapter=1#page=39)。原书主题的中文提炼，示例与实操为自编配套。

表达式产生一个值或表示一次计算，例如2+3；语句描述一次动作，例如把结果赋给变量。分号结束多数简单语句，大括号把多条语句组成代码块。先分清值、动作和执行顺序。

注释是写给读者的说明，不参与程序执行。缩进帮助看清层次，但C++主要根据分号和大括号识别结构。程序由明确的小步骤组成，别依赖“看起来像一组”。

```cpp
#include <iostream>
int main() {
    int total = 2 + 3; // 先计算，再保存
    { total += 4; }
    std::cout << total << '\n';
}
```

**容易混淆：** if或for后误加一个分号，会先执行空语句；缩进不能改变它的含义。

## 变量、常量与类型

原书联系：[1.5 变量](../../workbench/chapter.html?chapter=1#page=24)。原书主题的中文提炼，示例与实操为自编配套。

变量保存有类型的值。先初始化再使用；int适合整数，double适合带小数的值，bool表示真假，char表示单个字符。

const表示初始化后不能重新赋值；auto根据初始化表达式推导类型，它不会自动把整数改成小数。

```cpp
#include <iostream>

int main() {
    const int rows = 3;
    auto columns = 4;
    int cells = rows * columns;
    std::cout << cells << '\n';
}
```

**容易混淆：** 局部变量的名字不自动在别的函数可见；作用域结束后不能再用这个名字。

## 类型：能存什么、能做什么

原书联系：[1.6.1 数据类型的概念](../../workbench/chapter.html?chapter=1#page=27)。原书主题的中文提炼，示例与实操为自编配套。

原书理解类型的关键是：一类可表示的值，以及这些值上允许的操作。int、double、bool、char分别表达整数、小数近似、真假和单个字符；std::string是标准库提供的文本类型。

先按数据含义选类型，再看范围与精度。int的位宽不应靠猜；可用numeric_limits查范围。浮点是近似表示，字符不等于整段文本，bool不是任意数字的存储盒。

```cpp
#include <iostream>
#include <string>
int main() {
    int count = 3;
    double price = 2.5;
    bool ready = true;
    char grade = 'A';
    std::string name = "box";
    std::cout << count << " " << price << " " << ready << " " << grade << " " << name << '\n';
}
```

**容易混淆：** char保存一个字符单元，不是一整段文本；中文文本先用string保存，不能把UTF-8字节个数当汉字数。

## 初始化、赋值与常量

原书联系：[1.5.1 变量声明](../../workbench/chapter.html?chapter=1#page=24)。原书主题的中文提炼，示例与实操为自编配套。

初始化在对象被创建时给出初值；赋值在对象已经存在后改变它的值。局部基本类型不要读未初始化的值。int count{}会把count初始化为0。

const用于表达创建后保持不变的值。用清楚的初值建立程序起点，再追踪后续赋值。花括号初始化还能拒绝一些窄化转换；发现报错时应先想信息是否会丢失。

```cpp
#include <iostream>
int main() {
    int count{};
    const int step = 2;
    count = count + step;
    std::cout << count << '\n';
}
```

**容易混淆：** int n;没有为局部n建立可读取的初值；int n{};才明确从0开始。

## 读取输入与检查失败

原书联系：[1.4.4 主程序](../../workbench/chapter.html?chapter=1#page=22)。原书主题的中文提炼，示例与实操为自编配套。

std::cin >> value会跳过前导空白并尝试读取指定类型。读取失败后不能继续把变量当成有效业务输入；应检查流状态。

示例用istringstream模拟键盘输入，便于重复验证；实际程序可把in换成std::cin。负数是否合法还需要按题意单独判断。

```cpp
#include <iostream>
#include <sstream>

int main() {
    std::istringstream in("6 7");
    int a = 0, b = 0;
    if (in >> a >> b) std::cout << a + b << '\n';
}
```

**容易混淆：** 输入失败后不能把变量当作读取成功；先检查流状态再计算。

## 算术、转换与比较

原书联系：[1.7 表达式](../../workbench/chapter.html?chapter=1#page=32)。原书主题的中文提炼，示例与实操为自编配套。

整数除法得到整数商，小数部分被舍去；先转换一个操作数为double，才能得到浮点除法。把结果接到double变量里不会追溯改变已经发生的整数运算。

比较用==，赋值用=。取余%用于整数；除数为0必须在运算前排除。浮点数通常需要容差比较。

```cpp
#include <iostream>

int main() {
    int a = 7, b = 2;
    std::cout << a / b << " " << static_cast<double>(a) / b << '\n';
}
```

**容易混淆：** 5/2先进行整数除法；事后赋给double仍然是2，需在除法前改变操作数类型。
