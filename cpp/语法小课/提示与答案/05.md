# 流、泛型与检查：提示与答案

[回本组教程](../05-流、泛型与检查.md)

先做练习，再核对。小测答案不代替实际程序验收。

## 词、整行与严格转换

提示：先明确空白是否属于数据，再选择ws、ignore或纯getline。

小测：1。std::ws消费前导空白，内部空格保留；若空行本身有意义，不能随意使用。

示例约定环境的输出：

```text
42:camera ready
```

代码填空：`getline`。getline保留行内空格，不读取末尾分隔换行。

## 文件流与打开失败

提示：先打印或核对终端当前目录，再检查路径和文件权限。

小测：2。相对路径根据进程工作目录解释；修改源码位置不会自动改变工作目录。

示例约定环境的输出：

```text
missing
```

代码填空：`ifstream`。ifstream用于文件输入，还要检查打开是否成功。

## 模板与类型要求

提示：先用int与double核对，再想自定义类型的<应具有什么语义。

小测：1。泛型实现仍依赖具体操作，类型必须满足这些要求。

示例约定环境的输出：

```text
5 2.5
```

代码填空：`class` 或 `typename`。class与typename在这个类型参数声明位置都可用。

## 边界测试与assert

提示：先对照项目README的输入契约，再添加边界；不要把参考实现通过当成自己通过。

小测：2。NDEBUG可禁用assert。必须执行的动作要放在assert之外。

示例约定环境的输出：

```text
checks passed
```

代码填空：`assert`。assert可能被NDEBUG禁用，不能承载必须执行的动作。
