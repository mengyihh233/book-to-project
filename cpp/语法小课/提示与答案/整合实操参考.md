## 起步：类型、计算顺序与库调用

这是整合参考的独立演示，包含main；阅读后只把相关声明和函数体片段融入自己的文件，不要追加第二个main或覆盖已有作答。对应基础语法.cpp的菜单1和2。std::max返回较大值，负数也按数值大小比较。

```cpp
#include <iostream>
#include <string>
#include <algorithm>
int main() {
    // 先算、再存、再更新；注释说明目的。
    int total = 2 + 3;
    total += 4;
    std::cout << total << '\n';
    // 按含义选类型，boolalpha只改变真假输出格式。
    int count = 3;
    double price = 2.5;
    bool ready = true;
    char grade = 'A';
    std::string name = "box";
    std::cout << count << ' ' << price << ' ' << std::boolalpha
              << ready << ' ' << grade << ' ' << name << '\n';
    int progress{};             // 初始化为0
    const int step = 2;
    progress = progress + step; // 已存在对象的赋值
    std::cout << progress << '\n';
    std::cout << std::max(3, 7) << ' ' << std::max(-2, -5) << '\n';
}
```

预期输出：

```text
9
3 2.5 true A box
2
7 -2
```

## 函数：声明、返回、重载与默认参数

这是整合参考的独立演示，包含main；阅读后只把相关声明和函数体片段融入自己的文件，不要追加第二个main或覆盖已有作答。把声明放在文件外层、定义放在其他函数外，把测试调用放进lesson_functions，运行菜单3。此处只测试小整数，不能推断任意int乘2都不溢出。

```cpp
#include <iostream>
int twice(int value); // 调用前让编译器看见接口
int add(int a, int b = 1);
double add(double a, double b);
int main() {
    // 返回值可继续参与表达式，不依赖函数内部打印。
    std::cout << twice(0) << ' ' << twice(-3) << ' '
              << twice(-3) + 1 << '\n';
    std::cout << add(4) << ' ' << add(4, 3) << ' '
              << add(1.5, 2.0) << '\n';
}
int twice(int value) { return value * 2; }
int add(int a, int b) { return a + b; } // 定义不重复默认值
double add(double a, double b) { return a + b; }
```

预期输出：

```text
0 -6 -5
5 7 3.5
```

## 对象：一份类型定义，逐步增加能力

这是整合参考的独立演示，包含main；阅读后只把相关声明和函数体片段融入自己的文件，不要追加第二个main或覆盖已有作答。在objects.cpp保留一个Counter定义，构造小课与方法小课连续扩展它；有显式带参构造后，此版本用Counter a(0)，不再写Counter a。计数器只演示对象状态，不模拟账户的全部约束。

```cpp
#include <iostream>
struct Point { int x; int y; };
class Counter {
    int value_;
public:
    explicit Counter(int start) : value_(start) {}
    void add() { ++value_; }
    int value() const { return value_; }
};
int main() {
    Point p{2, 3}, q{5, 6};
    p.x = 7;
    std::cout << p.x << ' ' << p.y << ' ' << q.x << ' ' << q.y << '\n';
    Counter zero(0), three(3);
    std::cout << zero.value() << ' ' << three.value() << '\n';
    Counter a(0), b(0);
    a.add();
    std::cout << a.value() << ' ' << b.value() << '\n';
    const Counter frozen(4);
    std::cout << frozen.value() << '\n'; // 查询不修改对象
}
```

预期输出：

```text
7 3 5 6
0 3
1 0
4
```

## 同类函数一起练：容器、数学与字符

这是整合参考的独立演示，包含main；阅读后只把相关声明和函数体片段融入自己的文件，不要追加第二个main或覆盖已有作答。这里合起来便于核对；实际作答仍把容器段放containers.cpp、数学段放math.cpp、字符段放characters.cpp。字符表列顺序为原字符、是字母、是数字、大写、小写。

```cpp
#include <iostream>
#include <array>
#include <vector>
#include <cmath>
#include <cctype>
int main() {
    std::array<int, 3> fixed{2, 4, 6};
    std::vector<int> growing{2, 4, 6};
    std::cout << fixed.size() << ' ' << fixed.at(1) << '\n';
    for (int x : fixed) std::cout << x << ' ';
    std::cout << '\n';
    growing.push_back(8);
    std::cout << fixed.size() << ' ' << growing.size() << '\n';
    std::cout << std::sqrt(9.0) << ' ' << std::floor(-1.2) << ' '
              << std::ceil(-1.2) << ' ' << std::abs(-3.0) << '\n';
    for (char c : {'A', 'a', '7', '!'}) {
        auto u = static_cast<unsigned char>(c);
        std::cout << c << ' ' << (std::isalpha(u) != 0) << ' '
                  << (std::isdigit(u) != 0) << ' '
                  << static_cast<char>(std::toupper(u)) << ' '
                  << static_cast<char>(std::tolower(u)) << '\n';
    }
}
```

预期输出：

```text
3 4
2 4 6 
3 4
3 -2 -1 3
A 1 0 A a
a 1 0 A a
7 0 1 7 7
! 0 0 ! !
```
