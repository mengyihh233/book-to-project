# C++学习

**日常按章节学习。语法小课用于补基础，不是另一套必须重复完成的主线。**

```text
C++学习
  主教材
    章节学习
    第01章、 第02章……
      README.md       本章首页：先读什么、练什么
      原书阅读.md     阅读教材
      章内练习        本章重点综合练
      课后习题        按原书题号选题
        第01题
          README.md   本题要求
          work.cpp    在这里写代码
          input.txt   手动测试输入
  语法小课            基础概念不熟时查
  常用库练习          同一库放在一起练
  综合项目            学完相关章节再整合
  我的笔记            自己记录
```
